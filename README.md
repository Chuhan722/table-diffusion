# residual-evolution 残差驱动有限种群概率演化，基础框架

独立实现"残差驱动的有限种群概率演化"新方法的第一版基础框架。
本仓库与旧仓 /home/chuhan/projects 完全隔离，不 import 旧仓任何代码，参考实现直接复制进 tests/reference。

## 方法一句话

当前表与查询目标的残差 e 决定每个合法转移的真实增益 G，熵校准把增益变成方向分布 P，解析步长 h 把方向分布变成一次性抽样核 K，期望损失满足精确恒等式 E[L'] = L - hD + h^2 C。

## 第一版参数决策

1. 候选集直接用全集，每个单行块枚举全部合法状态，不做裁剪。
2. alpha = 0.5，即要求平均增益达到最大可达增益总和的一半。
3. 参考分布 R 保持比例 0.9，其余合法后继均分 0.1。
4. 其余严格按文档设计实现，文档未交代的复杂板块一律最简实现，代码注释标明"最简占位"。

## 有限编辑候选，规模化第一版

按补充设计文档的预算表，每行每轮至多 32 条非保持路径，
单字段修改至多 8 字段乘 2 替代值，供体复制至多 8，联合修改至多 4，支持探索至多 4。
生成器签名不接收残差与目标，菜单随机性对固定菜单的下降保证取平均后仍成立。
菜单每轮刷新，本轮冻结不停机，连续冻结超过重试上限才停。

test_300x10 实测，初始损失 19673.5，约 60 轮压到 2.0，初始比万分之一，
每轮约半秒，剩余误差是四个查询各差正负一的交错结构，
单行菜单六十次刷新无正增益，这正是配对板块要解决的补偿死角。

## 配对板块，自动发现需要联合更新的行对

按补充设计文档第二部分实现，配对依据是修改影响互相补偿而不是记录相似。
每行从菜单挑至多 4 个方向各异的代表动作，负分动作只要方向组空着照样入选，
按查询编号加方向建登记本，相反方向检索搭档，每行至多 8 个加 1 个随机搭档，
每对拼至多 16 个联合动作，交换 8 即互换两行某字段的值，组合 8 即两边代表动作搭配，
配对评分 Gamma 为联合支持最大增益减两个单行最大增益，正分对贪心绑定至多 32 对，
双行块完整保留两边全部单边动作，块内联合抽样块间独立，引擎数学零改动。
触发时机为冻结重试轮，平时纯单行菜单，卡住即上一轮整张菜单无一正增益动作。
锚点测试，文档例 Gamma 恰为 0.5 逐位对上，打乱行序仍自动找回补偿对。

test_300x10 实测，配对把 2.0 死角打到三种子 0，0.5，0，
两个种子 50 查询全对，另一个剩单查询差一，
其修复需要三行以上循环补偿，是双行块的真实边界，如实记录。

## 重复记录压缩与查询依赖索引，大规模数据的两级加速

按补充设计文档第四部分第六条与第二条实现，面向重复行多的大表。
相同状态的行菜单增益与倾斜概率完全相同，压缩后每组只算一次，
M 与 D 按重数加权，跨行交互 C 的总漂移为重数加权和，自交叉扣除同样加权，
期望损失恒等式在加权矩下逐字成立，测试里对多项计数完整枚举精确对上。
抽样绝不用一个共同开关让组内行一起变，按多项分布抽各后继的数量，
这与组内每行独立按同一核抽样精确同分布，方差与跨行相关性都不变。
查询依赖索引给每条查询记下依赖字段，编辑注册只重算受影响列，
未涉及列直接从来源行复制，与全量求值逐位一致，随机两百例对拍全过。
卡住时配对板块回退行级菜单与行级核，慢一轮不影响正确性。

合成重复表基准，16200 行 300 种状态 50 查询，
每轮 24.0 秒降到 3.9 秒，约 6.1 倍，两版首轮损失逐位一致，
test_300x10 分组加配对端到端照常归零。

## 组核矢量化与稀疏化，消灭逐组小数组开销

分组后热点变成几千次逐组小 numpy 调用，三步改成拼接大数组一次算完。
第一步熵校准平铺，所有组的增益拼成一条长数组配段偏移，
共享 beta 二分用分段 logsumexp，maximum.reduceat 加 add.reduceat 实现，
与逐块二分同括根同轮数，随机例相对误差 1e-9 内一致。
第二步查询条件预编译成算子码与字段下标，注册求值不再做字符串分发与线性查找，
菜单规范化改为保序 unique 加首现排序，与字典去重逐项一致。
第三步核构造不再物化几亿元素的增量大矩阵，
增益的线性项用势能差，phi 等于特征矩阵乘加权残差，一次矩阵向量积，
二次项只依赖状态对与固定权重，跨轮字典缓存，权重不变时永不过期，
漂移用稀疏矩阵乘特征矩阵，源行泄漏率单独扣除，
keep_deltas 开关保留显式路径供测试对拍，缓存复跑逐位不变有测试把守。

累计效果，合成重复表基准每轮 24.0 秒降到 0.4 秒，约 60 倍。
nltcs 同形状合成基准，16181 行 16 二值字段 1001 条二三阶查询，
每轮 2.1 秒降到稳态 1.07 秒，40 轮损失 192 万降到 2.1 万。

## 评价指标，严格按 AIM 与 GSD 文献定义

AIM 式，McKenna 等 VLDB 2022，workload 取全部 k 阶边缘表，
单边缘误差为边缘计数表 L1 距离除以行数，对 workload 平均。
GSD 式，Liu Vietri Wu ICML 2023，统计查询按比例口径，报平均与最大绝对误差。
评价与生成严格分离，保留查询 1024 条只进评价脚本，加载时强制校验与生成查询语义零交集。

三种子实测，随机基线到演化终表，
GSD 式 measured 50 平均误差 0.0710 降到 0.0005，最大恰为一行计数 1/300，
GSD 式 heldout 1024 平均误差 0.0128 降到 0.0067，没见过的三四阶查询误差近乎减半，
AIM 式全部二阶边缘平均 0.662 降到 0.296，全部三阶边缘平均 0.981 降到 0.610，
被查询覆盖的结构打满，未覆盖边缘的改进有限，与查询驱动的机理一致。

综合误差分把四组子指标统一到 0 到 1 后等权平均，越小越好，
GSD 两组本身是比例误差，AIM 两组除以 2 恰为总变差距离 TVD，
四组各占四分之一，拟合，泛化，二阶结构，三阶结构，
真实表自评恒 0，随机基线 0.2263 ± 0.0022，演化终表 0.1150 ± 0.0008，误差近乎减半。

```bash
# 全部测试，锚点断言、对拍、编辑候选与提供器

# AIM 与 GSD 式评价，真实表自评、随机基线与任意合成表对比

```

## 红线

1. 不逐行更新残差，一轮内所有块共用同一个旧残差。
2. 抽样只认最终核 K，不抽完再变异、不按新表损失接受拒绝回退筛选。
3. 合法性在支持构造阶段解决，不做抽后修复。
4. 相同后继必须先合并参考质量再倾斜。
5. 保持状态必须在支持中出现一次。
