# residual-evolution 残差驱动有限种群概率演化，基础框架

独立实现"残差驱动的有限种群概率演化"新方法的第一版基础框架。
本仓库与旧仓 /home/chuhan/projects 完全隔离，不 import 旧仓任何代码，参考实现直接复制进 tests/reference。

## 方法一句话

当前表与查询目标的残差 e 决定每个合法转移的真实增益 G，熵校准把增益变成方向分布 P，解析步长 h 把方向分布变成一次性抽样核 K，期望损失满足精确恒等式 E[L'] = L - hD + h^2 C。

## 第一版参数决策

1. 候选集直接用全集，每个单行块枚举全部合法状态，不做裁剪。
2. alpha = 0.5，即要求平均增益达到最大可达增益总和的一半。
3. 参考分布 R 保持比例 0.9，其余合法后继均分 0.1。
4. 其余严格按文档设计实现，文档未交代的复杂板块一律最简实现，代码注释标明"最简占位"。

## 目录结构

- src/resevo/state.py 表状态与账本，贡献矩阵、整表答案、残差、损失
- src/resevo/candidates.py 候选集枚举与参考分布构造
- src/resevo/gain.py 查询增量与转移增益
- src/resevo/tilt.py 熵校准，二分求共享 beta，方向分布 P
- src/resevo/stepsize.py 整代矩 b v D C 与解析步长 h
- src/resevo/engine.py 引擎组装，核构造、一次性抽样、多轮循环
- tests/ 与模块一一对应的锚点断言测试
- tests/reference/ 复制来的参考实现，对拍用
- docs/锚点数据.md 文档四条记录小表例子的全部纸面演算值
- scripts/ 端到端对账与冒烟脚本

## 运行

```bash
./.venv/bin/python -m pytest tests/ -q
```

依赖见 requirements.txt，venv 由 uv 创建。

## 红线

1. 不逐行更新残差，一轮内所有块共用同一个旧残差。
2. 抽样只认最终核 K，不抽完再变异、不按新表损失接受拒绝回退筛选。
3. 合法性在支持构造阶段解决，不做抽后修复。
4. 相同后继必须先合并参考质量再倾斜。
5. 保持状态必须在支持中出现一次。
