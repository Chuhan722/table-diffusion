## 四、读法

1. 整体方法（各用各的停法）：二阶 0.67 / 0.68 / 0.78 / 0.90 / 1.03；比生成器（同停法）：0.71 / 0.80 / 0.91 / 0.94 / 0.97。两行之差 = GSD 跑到底比它自己地板停多学（或少学）的噪声：ε = 0.3 / 1 差 12～14 个百分点，ε = 0.1 / 3 差 3～4 个百分点，ε = 10 反向 6 个百分点（GSD 跑到底比其地板停好 5.9%）。
2. ε = 10 整体方法我们略输（1.03）：地板停在 ε=10 比跑到底差 3.5%，GSD 跑到底则拿到了这一截。这是统一 1.0 倍规则的代价，如实写。
3. 时间：我们到地板的秒 对 GSD 整场搜索秒，原始口径 1/170～1/27，净口径 1/65～1/11。GSD 的原始秒含其实现的记账开销（原版行为），净秒已扣。
4. 本比较不新跑任何东西：我们臂的表就是第六十二/六十三步的地板×1 快照（与硬地板停逐位相同），GSD 臂的表就是其终表。
