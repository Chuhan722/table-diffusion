# Issue #53：两档自适应 α 正式结果

日期：2026-08-19

## 1. 结论

本实验完成了 `test_300x10` 与 `nltcs`、三种 α 策略、5 个配对随机种子的 30 条冻结轨迹：

```text
fixed_alpha_16          固定 α=16，主要基准
fixed_alpha_12          固定 α=12，机制对照
adaptive_alpha_16_12    α16 正常档；停滞后短暂 α12，再恢复 α16
```

30/30 条轨迹均由 `early_stopped`（早停）正常结束，没有
`resource_cap_reached`（资源上限结束）。自适应臂在两套数据的 5/5 个随机种子上都实际触发，
因此这不是“状态机没有工作”的无效实验。

正式结果不支持当前两档自适应策略：

- `test_300x10`：自适应 measured L1（已测查询归一化绝对误差）均值比固定 α16 高 8.29%，
  只有 1/5 个配对随机种子更好；离线安全、多样性、有效性和计算量门禁均通过，但主要的稳定测量
  改善门禁失败。
- `nltcs`：自适应 measured L1 均值比固定 α16 高 17.40%，只有 3/5 个配对随机种子更好；
  1-way 安全误差高 33.96%，计算量高 17.71%，主要拟合、离线安全和计算门禁同时失败。
- 固定 α12 也没有提供可替代解释：`test_300x10` 的均值虽低 5.70%，但只有 3 胜、1 平、1 负，
  未达到冻结的至少 4/5 严格改善；`nltcs` 的 measured L1 高 23.80%，并同时损害 1-way、
  未测 3-way 和计算量。

冻结分类为：

```text
test_300x10 mechanism    no_supported_alpha12_strategy
nltcs mechanism          no_supported_alpha12_strategy
cross-dataset response   no_shared_adaptive_support
```

本实验不修改公共默认值，不选择自适应 α 作为当前 baseline，也不把回滚、best checkpoint（历史最好
检查点）或分支择优事后加入“无门控”算法。

## 2. 研究问题与设计动机

此前固定 α 响应曲线已经确认：在 scale-invariant donor（尺度不变供体选择）下，α 是方向稳定的
供体集中度控制量。α 从 16 降到 12 时，两套数据的有效供体比例都会增加、单行最大供体概率都会下降；
但 α=`12/16/24` 没有一个固定值同时通过两套数据的完整质量—计算门禁。

因此本实验只回答：

> 以 α=16 为正常档，在当前轨迹真实停滞后临时切到 α=12 两个自然工作刻度，再恢复 α=16，
> 能否比一直使用 α=16 更稳定地改善 terminal-current（终态当前表）质量，同时保住离线安全、
> 多样性和计算量？

固定 α12 只作为机制对照，用于区分“短暂探索有效”和“从头到尾使用较低 α 有效”，不是重新扫描
固定 α，也不允许根据正式结果增加 α=14、18、24 或追加随机种子。

## 3. 无门控两档状态机

状态机冻结为：

```text
normal alpha             16
stall trigger            连续 2 个无进展 natural-work ticks
escape alpha             12
escape duration          恰好 2 个 natural-work ticks
early-stop patience      P=6 natural-work ticks
```

`natural work`（自然工作量）继续使用现有定义：

```text
normalized_work       = cumulative applied participating rows / N
completed_work_ticks  = floor(normalized_work)
```

每条轨迹从 α16 开始。只有当前 squared loss（平方损失）严格低于历史最好才算进展；相等、回到旧最好、
供体集中度改变或 α 切换都不算。第 2 个连续无进展刻度结束的那一轮仍使用 α16，从下一轮开始使用
α12；探索持续到后续两个自然工作刻度完成，再恢复 α16。

α 切换不清零、不暂停或延长 P=6。同一个没有新最好的 progress epoch（进展阶段）最多触发一次探索；
探索期间若产生严格新最好，P=6 正常清零，但已经开始的 α12 段仍完成恰好两个刻度。若一直没有新
最好，正常时间线为：

```text
无进展 tick 1-2   α16；第 2 tick 后安排探索
无进展 tick 3-4   α12
无进展 tick 5-6   恢复 α16；第 6 tick 后 early_stopped
```

本设计仍然是无门控算法：每个有限 proposal（提案）都成为下一张 current table，不根据损失拒绝、
回滚或重试；历史最好只用于进展计数和诊断，最终统一输出触发 A/B/C 时的 terminal current table。
状态机只决定未来使用哪个 α，不否定已经发生的状态转移。

## 4. 冻结矩阵、输入与信息隔离

```text
datasets  = [test_300x10, nltcs]
arms      = [fixed_alpha_16, fixed_alpha_12, adaptive_alpha_16_12]
seeds     = [328, 329, 330, 331, 332]
cases     = 2 × 3 × 5 = 30
```

每个“数据集 × seed”的三臂共享相同 marginal（边缘）初始化随机流；初始表 SHA-256 和初始化后
主随机数状态必须一致。同一个 seed 分片内按以下顺序串行执行：

```text
test/fixed16 -> test/fixed12 -> test/adaptive
-> nltcs/fixed16 -> nltcs/fixed12 -> nltcs/adaptive
```

`test_300x10` 继续使用更新后的 `measured_50query_30_15_5.json`：30 条 2-way、15 条 3-way、
5 条 4-way，没有 measured 1-way。`nltcs` 使用 479 条 2-way 与 522 条 3-way，也没有 measured
1-way。两套数据均使用 relative residual（相对残差）、floor=8、rho=0.01、P=6、C=6000、
scale-invariant donor、`initial_rms` 方向归一化、eta=0.5、mu=0.01、Gibbs=0 和
terminal-current 输出。

正式生成只读取 schema、measured 查询及答案、初始化 marginal 和在线早停/状态机信息；不读取
原始参考表、held-out（留出）答案或离线误差，不消耗隐私预算。30/30 终表全部物化并聚合后，评价器
才加载固定 SHA-256 的参考表，分别计算 1-way、安全高阶查询、TVD（总变差距离）、多样性与有效性。

## 8. α12 探索是否真的改变了 donor

α12 的机制作用符合预期。以下是 5 个自适应 seed 的逐 case 阶段均值再取平均：

| 数据 | 阶段 | 单行最大供体概率 | 有效供体比例 |
|---|---|---:|---:|
| test | α16 正常段 | 0.567376 | 0.0129639 |
| test | α12 探索段 | 0.472487（-16.73%） | 0.0192531（+48.52%） |
| nltcs | α16 正常段 | 0.0410106 | 0.0931481 |
| nltcs | α12 探索段 | 0.0275533（-32.81%） | 0.126604（+35.92%） |

因此，负结果不能解释为 α 没有改变供体分布。α12 确实让供体选择明显变平、有效供体明显增多。

触发和新最好位置如下：

| 数据 | 逐 seed escapes | 总探索段 | α12 段内首次新最好 | 恢复 α16 后首次新最好 | 未观察到新最好 |
|---|---|---:|---:|---:|---:|
| test | 1 / 1 / 2 / 1 / 2 | 7 | 1 | 1 | 5 |
| nltcs | 1 / 4 / 1 / 1 / 1 | 8 | 0 | 3 | 5 |

15 个探索段中只有 1 个在 α12 期间刷新最好；4 个在恢复 α16 后、下一探索前刷新；10 个没有观察到
新最好。test 自适应平均使用 2.8 个 α12 自然工作刻度，nltcs 为 3.1973；nltcs/seed329 因多次
恢复后产生新最好而触发 4 段探索，共使用约 7.9862 个 α12 工作刻度。

## 9. 自适应相对固定 α16 的冻结门禁

| 数据 | measured 均值变化 | 配对更好/更差 | 离线安全 | 多样性 | 有效性 | work 变化 | 正式分类 |
|---|---:|---:|---|---|---|---:|---|
| test | +8.29% | 1 / 4 | 通过 | 通过 | 通过 | -5.95%，通过 | `no_stable_measured_gain` |
| nltcs | +17.40% | 3 / 2 | 失败 | 通过 | 通过 | +17.71%，失败 | `no_stable_measured_gain` |

test 的四组离线安全均在固定 α16 的 1.05 倍以内：1-way 为 1.0313 倍、未见 2-way 为 1.0226 倍、
留出 3-way 为 1.0037 倍、留出 4-way 为 0.9979 倍；两项多样性相对固定 α16 分别为 1.0365 和
1.0622。该数据上的失败集中在 primary measured L1：均值更高且只有 1/5 配对更好。

nltcs 的未测 3-way、全部 4-way 和 binned joint TVD（分箱联合总变差）分别为固定 α16 的
1.0379、0.9612 和 0.9693 倍，均通过；但 1-way safety 为 1.3396 倍，超过 1.05 安全带。
两项多样性通过，计算量却从 19.2030 增至 22.6035。计算增加几乎全部来自 seed329：该 seed 的
自适应工作量为 39.0026，而固定 α16 为 22.0003；其余四个 nltcs seed 的停止工作量与固定 α16
相同。

## 10. 固定 α12 机制对照

固定 α12 使用与自适应完全相同的门禁，相对固定 α16 独立判定：

| 数据 | measured 均值变化 | 配对更好/更差/平 | 主要附加问题 | 正式分类 |
|---|---:|---:|---|---|
| test | -5.70% | 3 / 1 / 1 | 未达到至少 4/5 严格改善；其余门禁通过 | `no_stable_measured_gain` |
| nltcs | +23.80% | 1 / 4 / 0 | 1-way 1.5485 倍；未测 3-way 1.0622 倍；work 1.2188 倍 | `no_stable_measured_gain` |

因此 test 上存在“固定低 α 的均值略有吸引力但不稳定”的描述性信号；nltcs 则明确不支持一直使用
低 α。两套数据都不能用固定 α12 的成功替代当前自适应时序失败，冻结机制解释均为
`no_supported_alpha12_strategy`。

## 11. 为什么扩大探索没有改善终态

本实验中的“探索”不是增加候选数量并择优，而是把每行的 donor 抽样分布变平，然后把生成状态连续
写回 current table。每轮仍只有一条实际状态路径，没有探索分支、接受门、回滚或 best 输出：

```text
α12 让 donor 更分散
-> 约 2 个自然工作刻度持续写回当前表
-> 无论期间变好或变坏都继续生效
-> 恢复 α16
-> 输出 P=6 触发时的 terminal current table
```

rho=0.01 时，两个自然工作刻度通常约为 200 raw rounds（原始轮次），不是两轮轻微扰动。若探索没有
刷新最好，α12 占用无进展 tick 3-4，之后只有 tick 5-6 的 α16 恢复窗口就正常早停。该策略会提高
访问不同状态的概率，但同时提高离开已有低损失结构的概率；在不择优的单路径无门控过程中，“更分散”
不等于“最终状态更好”。

nltcs/seed330 是最明显的终态漂移：自适应历史最好 squared loss 为 13559.5，与固定 α16 相同，
但自适应 terminal loss 为 96146，固定 α16 terminal loss 为 17162.5；对应 L1 为 0.000500210
与 0.000263194。nltcs/seed331 也从历史最好 15195 漂到 terminal 51647，而固定 α16 terminal 为
28647。两条轨迹的 α12 段和恢复段都没有刷新最好。

nltcs/seed329 展示了探索偶尔可能帮助的另一面：四个 α12 段本身都没有刷新最好，但前三段在恢复
α16 后产生了新最好，自适应 L1 0.000290915 优于固定 α16 的 0.000323081；代价是 work 从
22.0003 增至 39.0026。test/seed330 是唯一在 α12 段内刷新最好者，但最终 L1 仍从固定 α16 的
0.00266667 退化到 0.00353333，说明一次内部 squared-loss 新最好不保证之后的 terminal L1 更好。

这些结果支持的最窄解释是：当前“2 tick 触发、2 tick α12、P=6 不暂停”的动作没有把普通随机
停滞稳定转换为更好的 terminal-current 区域。它不证明所有自适应 α 都无效，也不能据此把结果后
回滚塞回原无门控算法；回滚会变成新的分段接受门，必须作为另一种算法单独冻结和比较。

## 14. 结论边界与下一步

当前可以确认：

1. α12 在运行中确实按预期扩大供体覆盖；
2. 2/2/6 两档状态机在两套数据、全部随机种子上实际触发；
3. 当前时序没有带来稳定 measured 改善，nltcs 还出现 1-way 与计算风险；
4. 固定 α12 也没有成为跨数据替代方案；
5. 无门控、terminal-current 输出下，扩大探索不会自动转化为“尝试后保留更好结果”。

当前不能确认：

1. 所有自适应 α 都无效；
2. α=12、16 是所有数据或未来带噪阶段的最佳上下档；
3. 失败只由探索幅度、持续时间、触发信号或恢复窗口中的某一个因素单独造成；
4. 回滚或 best 输出可以在不改变算法身份的情况下解决问题；
5. 5-seed 无噪声 development 结果可以外推为公共 API 或 DP 系统结论。

本阶段到此形成完整的固定 α 响应与两档自适应负结果证据链。后续若继续无门控路线，应另写结果前
协议研究不同的未来转移调度；若研究回滚、影子分支或择优，则必须明确改为有门控算法，单独比较。
