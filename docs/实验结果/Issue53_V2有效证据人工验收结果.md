## 3. 正相关主判定

表中“覆盖率”指 2000 次重复中 `sample_mean ± 1.96*正式保守MCSE` 覆盖真均值 0 的比例；“方差比”
是估计长期方差与理论长期方差之比的中位数。覆盖率必须位于 `92.5%..97.5%`，方差比必须位于
`0.80..1.25`。

| n | iid 覆盖率 / 方差比 | phi=0.5 覆盖率 / 方差比 | phi=0.8 覆盖率 / 方差比 | 三类共同通过 |
|---:|---:|---:|---:|---|
| 16 | 94.70% / 0.817 | 82.35% / 0.461 | 62.10% / 0.137 | 否 |
| 32 | 94.45% / 0.900 | 85.30% / 0.611 | 70.25% / 0.247 | 否 |
| 64 | 94.65% / 0.944 | 88.85% / 0.744 | 80.30% / 0.407 | 否 |
| 128 | 95.25% / 0.962 | 91.45% / 0.821 | 84.40% / 0.534 | 否 |
| 256 | 95.90% / 0.981 | 92.55% / 0.896 | 88.45% / 0.668 | 否 |
| 512 | 95.95% / 0.982 | 92.75% / 0.915 | 90.45% / 0.759 | 否 |
| 1024 | 96.00% / 0.997 | 93.05% / 0.942 | **92.30%** / 0.834 | 否 |
| 2048 | 94.65% / 0.997 | 94.15% / 0.958 | **93.70%** / 0.878 | 是 |
| 4096 | 95.65% / 0.992 | 93.55% / 0.973 | **93.65%** / 0.917 | 是 |

每个长度的正式 ESS 比例中位数都严格保持 `iid > phi=0.5 > phi=0.8`。所有长度的数值失败、非有限
输出、契约违规和正式 ESS 超过实际 round 的计数均为 0。

`1024` 的唯一关键失败是 `phi=0.8` 覆盖率 `92.30% < 92.50%`；其长期方差比 `0.834` 已通过。
虽然只差 0.2 个百分点，协议禁止看结果后放宽，因此不能把下限改成 1024。`2048` 与其后的 4096
全部通过，所以按“自身及所有更大长度都通过”的预注册规则选择 2048。

## 4. 负相关与固定边界

`phi=-0.5` 在九个长度的 raw ESS/n 中位数为 `2.265..2.945`，均大于 1；正式保守 ESS/n 的最大值
始终为 1。负相关控制九个长度全部通过。

固定边界的 11 项检查全部通过：缺号、重复、乱序、非有限与布尔输入拒绝；常数与周期偶合 fail
closed；平移/正缩放不变；单尖峰有限且 ESS 有上限；趋势输出没有收敛或停止字段。

另用不导入 runner 的一次性重算独立核验 36 个 family×length cell、覆盖率、方差门禁、ESS 排序、
负相关控制、最少历史选择和 scientific SHA-256，全部一致。

## 5. 结论边界与下一步

本结果只支持下面一句话：

```text
在预注册的平稳高斯 AR(1) 压力范围（最强正相关 phi=0.8）内，
重叠批均值 + b=floor(sqrt(n)) 从 2048 个连续 outer round 起通过当前 ESS/MCSE 数值验收。
```

它不说明真实生成轨迹已经平稳，不证明任意更慢或非平稳过程都被覆盖，也不能直接产生
`stable/converged/stop`。`2048` 仍是一个较高的计算资格下限：若接受该保守代价，下一步才是冻结
正式接口的 `insufficient_history=2048` 并补测试；若认为代价不可接受，必须保留本次结果为有效证伪
依据，另写新协议研究其他统一估计器，不能把本协议事后改成 1024。
