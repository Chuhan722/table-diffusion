# 锚点数据，文档四条记录小表例子的全部纸面演算值

来源为参考资料 method.tex 与 implementation.tex，实现与测试必须逐数字对上这里的值。
浮点对账容差，小例子用绝对容差 1e-12，标注约等号的长小数按文档给出的位数比对。

## 1. 问题设定

1. 两个二元字段 A 和 B，状态集合按顺序编号，00=0，01=1，10=2，11=3。
2. 三个计数查询，a1 为 A=1 的行数，a2 为 B=1 的行数，a3 为 A 且 B 的行数。
3. 贡献向量，a(00)=(0,0,0)，a(01)=(0,1,0)，a(10)=(1,0,0)，a(11)=(1,1,1)。
4. 初始表四条记录，四种状态各一条，行序 [00,01,10,11]，即编号 [0,1,2,3]。
5. 目标 y=(3,1,1)，权重 W=I。

## 2. 账本基准值

1. 当前答案 q=(2,2,1)。
2. 残差 e=y-q=(1,-1,0)。
3. 损失 L=(1/2)e^T W e=1。
4. 手算单步锚，把 01 改成 10 后 q=(3,1,1)，残差 (0,0,0)，损失 0，该步真实增益为 1。

## 3. 增益矩阵，行=源状态，列=目标状态

|      | 00   | 01   | 10   | 11   |
|------|------|------|------|------|
| 00   | 0    | -1.5 | 0.5  | -1.5 |
| 01   | 0.5  | 0    | 1    | 0    |
| 10   | -1.5 | -3   | 0    | -2   |
| 11   | -1.5 | -2   | 0    | 0    |

每行最大增益为 0.5, 1, 0, 0。

## 4. 熵校准

1. M=各行最大增益之和=1.5。
2. alpha=0.5，delta=alpha*M=0.75。
3. 参考分布 R，保持 0.9，其余三个合法后继各 (1-0.9)/3=1/30。
4. D(beta) 数值表：
   D(0)=-0.366667，D(1)=0.065895，D(2)=0.261787，D(3)=0.493206，
   D(3.9814026412)=0.75，D(4)=0.754670，D(8)=1.316503。
5. 唯一根 beta*≈3.981402641214968。

## 5. 整代矩与解析步长

1. 行离开速率 b≈(0.213419, 0.696332, 0.000107527, 0.0358140)。
2. 方向增益 D=0.75。
3. 跨行交互 C≈0.1548345932。
4. h_feas=1/max b=1/0.696332，D/(2C)≈2.42>h_feas，故 h=h_feas≈1.4360970925。

## 7. 期望损失与上升概率

1. 精确恒等式 E[L']=L-hD+h^2 C=0.242254152907815…，
   80 位参考 0.2422541529078151916992875510628251631065…。
2. 256 种下一代完整枚举的平均损失必须等于上式。
3. 下一代损失高于当前损失 1 的总概率≈2.27002%。
4. 解析上界 L-(1/2)hD=1-0.75h/2，须不小于 E[L']。

## 8. 期望改行数上限变体 B_max=0.25

1. H=Σ r_B(u)c_B(u)，本例全部单行块 c=1，故 H=Σb=0.945672…。
2. h=min(h*, B_max/H)≈0.2643622352。
3. 期望改变行数=0.25。
4. E[L']≈0.8125493094。

## 9. 微小增益反例，保持 0.9 与 alpha=0.5 的组合行为

单条二元记录单查询，唯一非保持动作增益 ε>0 时 M=ε，delta=ε/2。
解得 beta=log(9)/ε，P(非保持)=1/2，b=1/2，C=0，h_feas=2，h=2，变化概率恒为 1。

| ε     | beta            |
|-------|-----------------|
| 1e-1  | ≈21.9722        |
| 1e-3  | ≈2197.2246      |
| 1e-6  | ≈2197224.5773   |

## 10. 一维方向反例，方向对不代表增益正

单查询 e=0.2，动作使查询加 1，则线性项 0.2，真实增益 G=0.2-0.5=-0.3。
只看方向正负会误判，必须带二次项。

## 11. 三行速率步长例子

三个单行块，速率与增益使 D=3/2，C=3，h_feas=1，则 D/(2C)=1/4<1，h*=1/4，
E[L']=L-hD+h^2C=L-3/8+3/16=L-3/16，L=1/2 时 E[L']=5/16。

## 12. 双行块补偿例子

1. 表 S=(00,11)，目标 y=(1,1,0)，权重 W=diag(2,2,1)，损失 L=1/2。
2. 全部单行增益为负：00→01 和 00→10 为 -1，00→11 为 -7/2，11→00 为 -3/2，11→01 和 11→10 为 -1/2。
3. 单行核在此停滞，M=0。
4. 联合动作 (00,11)→(01,10)，d1=(0,1,0)，d2=(0,-1,-1)，d1^T W d2=-2，
   G12=G1+G2-d1^T W d2=-1-1/2+2=1/2>0。
5. 配对优先级 Γ=M12-M1-M2=1/2。
6. 两行完整支持块的软熵核，保持 0.9，alpha=0.5，E[L']≈0.0040808634。

## 13. 属性边缘测试锚

联合分布 P(00)=P(11)=1/2 时两个属性边缘都均匀，
但按边缘独立拼接会产生 01 与 10，只有按联合分布抽样才保持原核。
