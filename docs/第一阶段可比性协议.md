# 第一阶段可比性协议：纯生成器消融（adult 单数据集）

定稿 2026-10-11。本阶段只回答一个问题：**在完全相同的带噪测量下，我们的生成器比别人的生成器好还是差，差在哪**。
选择器 / 预算分配 / 最佳配置（第二阶段）与整机对比（第三阶段）一律推后，第一阶段全部完成前不开。
10-10 汇报的主表（全测 vs AIM 官方）同时换了题单和生成器，不是消融证据，冻结不再引用。

## 0. 总则

1. 一次只比两个方法：我们的生成器 vs 一个对手的生成器，其余全部变量一致。
2. "一致"的定义：同一数据集、同一 ρ/δ/账本、**同一份带噪测量文件（同一次噪声抽样）**、同 N、同字段域、同噪声种子配对。两臂读的是同一个 JSON，不是"同分布的另一份噪声"。
3. 对手吃什么统计量，我们就吃什么：和 GSD 比吃 GSD 的全二阶边际；和 PGM 比吃 AIM 为 PGM 选出的那组测量。不给我们加任何对手没有的信息（不加一阶、不加选择器）。
4. 判定规则（事先定死）：按噪声种子配对，3 种子，主轴相对差 3 种子均 |Δ| ≤ 2% 记平手，否则记胜/负；副轴只作解释。
5. 阅卷统一用 `scripts/score_any.py`（原 /tmp/score_any.py，10-11 收进仓库），3 种子均用 `logs_eps/alloc/summarize.py`，配对表用 `logs_eps/stage1/grade_stage1.py`。

## 2. 实验 1A：我们 vs GSD（GSD 的统计量）

- **同一文件**：`data/adult_alloc{tag}base_s{seed}/measured_2way.json`（tag ∈ 0p1/0p3/1/3/10，seed 1–3），105 对全二阶加噪边际，σ₂ = 348.38 / 126.14 / 41.47 / 15.31 / 5.43，不含一阶题（base 卷一阶那 0.1% 预算两臂同样弃用）。
- **GSD 臂**（已有，不重跑）：`results/baseline2/adult_eps{tag}_gsd_seed{seed}.csv`，命令见 `logs_eps/baseline2/launch_E_a6000.sh` run_gsd：域来自真表 CSV，N 来自考卷，带噪二阶表作目标，early-stop 1e-4。
- **我们臂**（本阶段新跑）：`results/stage1/adult_eps{tag}_ours2way_seed{seed}.csv`，命令 = launch_E run_alloc 逐字，只改三处：
  `--data adult_alloc{tag}base_s{seed} --exam measured_2way.json`（同文件）、
  去掉 `--init-oneway`、换成 `--init-avg --init-clean --exam-weights none`。
  - 为什么 init-avg：卷里没有一阶题，初表一阶只能从二阶边际化得到；`derive_first_order_avg` 对每字段的 14 个伙伴对逆方差平均，比默认取首个覆盖对的 L1/N 好 5~6 倍（ε=0.1：0.30 → 0.060）。低 ε 平均后有负格（ε≤0.3 有 12~30 格），`--init-clean` 单纯形投影，必开，否则 rng.choice 直接崩。
  - 为什么 weights none：卷内 σ 全同，sigma 加权与 none 等价，写 none 省事。
  - GSD 也只从这份二阶边际出发，没有任何额外信息，两臂信息量完全相同。
- **主轴**：二阶（即卷内 105 对对真表的 L1/N）。副轴：三阶、等值、半空间、墙钟。
- **既有近似对照不作数**：10-08~10-09 的"GSD 同餐"我们这边吃的是 auto 卷（含 1.5% 一阶预算、不同噪声抽样），只能当趋势看。

## 3. 实验 1B：我们 vs PGM（AIM 选出的统计量）

- **同一录像**：`results/aimreplay/adult_eps{tag}_aimfull_seed{seed}_measurements.json`，由 `run_aim_full.py --dump-measurements` 录下官方 AIM 该跑 estimate 末次调用收到的完整测量列表（团、σ、加噪计数向量，含重复团）。隐私账逐字等于 AIM 这一跑。
- **PGM 臂**（对照，CPU 秒级）：`scripts/run_pgm_replay.py --dump … --seed s --iters 1000 --known-total rows` → `results/stage1/adult_eps{tag}_pgmrep_seed{seed}.csv`。即 AIM 收尾那两行 `MirrorDescent().estimate(measurements, iters=1000)` + `synthetic_data(rows=N)`，从零起步无 warm_start。
  - 为什么不用 AIM 终表当对照：10-11 核对发现 AIM 终表 ≠ 独立 PGM，ε=0.1 二阶 145.2k vs 136.5k（AIM 终表差 6.4%），ε=1 47.0k vs 48.2k（+2.5%），warm_start 路径影响超出 2% 带。AIM 终表只作参考列。
  - known_total 喂真 N 与我们、GSD 同口径；auto（AIM 原样自估）差 0.2%，不影响判定。iters 1000 = AIM 默认 max_iters；3000 轮二阶反差 1%（多拟合噪声），作敏感性记录。
  - **10-12 修订：对照臂改为收敛臂 `pgmrep10k`（`--iters 10000`，其余逐字同）**。收卷后发现 1000 轮从零起步在 ε≥3 远没收敛：ε=10 s1 二阶 1000 轮 34.8k、5000 轮 24.0k、20000 轮 24.0k（AIM 终表 23.2k），一阶误差 6.5k 对收敛后 ~1.5k。对手没跑完就判我们胜不算数，所以 1B 的对照 = 10000 轮（5000 已收敛，10000 留一倍余量，CPU 道每场 ≤3 min）；1000 轮臂保留为"AIM 默认预算"参考列，AIM 终表仍为参考列。本机脚本另加 `--tol/--patience`（mbi 自带相对损失早停）备用，未用于正式臂。
- **我们臂**：`data/adult_aimrep{tag}_s{seed}/`（`scripts/aim_replay_exam.py` 把录像转卷：同团重复测量逆方差合并，一阶团出 eq1way、二阶团出 eq2way，每题带 σ），命令见 `logs_eps/stage1/launch_stage1.sh` run_hybrid：与 1A 同 EXTRA，加 `--init-oneway --exam-weights sigma`（录像里有一阶团，一阶直接初始化；混 σ 卷必须逆方差加权，第五十一步消融不加权差 17.6%）。输出 `results/stage1/adult_eps{tag}_hybrid_seed{seed}.csv`。
  - 一阶初表来自录像里 AIM 测过的一阶团，PGM 同样拿到这些一阶测量，信息量相同。
- **主轴**：二阶（全 105 对工作负载，含没测的对——两臂都得填空，PGM 靠最大熵推断，我们靠一阶独立初表 + 演化）。副轴同上，另按"AIM 测过 / 没测"分组（`scripts/score_pair_groups.py`）。
- 录像现状：ε=0.1/1 各 8 份、ε=0.3/3 各 3 份已有；ε=10 的 AIM 跑（10-06）没开录像，须复跑 3 场（CPU，约 1.5 h/场）。
- 为什么 PGM 不进 1A：adult 全 105 对边际的联结树是完全图（树宽 14），精确推断不可行，PGM 只能比 AIM 选出的稀疏团。为什么不和 AIM 终表比：AIM = 选测器 + PGM，第一阶段只比生成器，AIM 只是帮 PGM 出题的工具。

## 6. 第二阶段首战 A：测量后处理（平分清洗）消融（10-12 起）

第一阶段 1B 低 ε 负的根因（工作笔记第五十七步第 14 条）：只被一阶测量覆盖的高基数字段（attr_14 国家 42 值，部分种子还有 attr_3 等），一阶噪声 σ≈555（ε=0.1）/≈200（ε=0.3）比多数真计数大，我们的终表一阶恰等于该噪声直方图的欧氏投影（负格归零、碰巧测高的格子保留），比 PGM 差 12–14%；经独立填空传到约 28 个没测的对，正是 1B 低 ε 的全部差额。其余环节（测过的对、没测对上的结构收益、自身目标损失、过拟合比）两臂相当。

- **药方**：对考卷目标的后处理（`src/resevo/denoise.py`，选测 → 加噪 → **清洗** → 生成），零隐私预算，总行数与 PGM 的 `--known-total` 同口径视为公开：
  - 一阶（`--oneway-pool z`）：|y| < z·σ 的格子视为"未测出"，其余保留 max(y,0)，总行数减保留量在未测出格子间**均分**；保留量超总数退回欧氏投影；
  - 二阶（`--pair-pool z`，须与一阶同开）：同一规则，但未测出格子**按清洗后一阶的乘积分**（没证据当独立）。
  - z=2（统计惯例）。离线选药：一阶 z=2 在仅一阶字段上 5/6 低 ε 种子优于投影、与 PGM 同量级（`logs_eps/scores/stage1_onewaypool_scan.md`）；二阶清洗在目标层面与逐对投影打平、无系统性增益（`logs_eps/scores/stage2_pairpool_scan.md`），故二阶臂定位为"有无副作用"验证。
- **臂**（命令 = 第一阶段 hybrid 逐字 + 开关，其余全同；对照臂用第一阶段已有终表不重跑）：
  - `hybridp1` = hybrid + `--oneway-pool 2`；`hybridp12` = hybrid + `--oneway-pool 2 --pair-pool 2`。
  - 一次只动一个开关：2A-1 p1 vs pgmrep10k（主问题）；2A-2 p1 vs hybrid（开关本身的作用）；2A-3 p12 vs p1（二阶开关的作用）；2A-4 p12 vs pgmrep10k。
- **档位**：ε=0.1/0.3（病灶）+ ε=1（不伤害检查）× 3 种子 = 18 场；通过后再补 ε=3/10 × 3 给胜出臂。
- **通过标准**：低 ε 主轴二阶 Δ vs PGM 进 ±2%（平）或更好；ε=1 p1 vs hybrid 主轴 |Δ| ≤ 1%（开关在高 ε 近似恒等，σ 小则几乎没有格子落入 z·σ 以内）。
- **产物**：`results/stage2/adult_eps{tag}_{hybridp1|hybridp12}_seed{s}.csv`（+ `_curve.csv`）；日志 `logs_eps/stage2/`（launch_s2a.sh、jobs_s2a.txt、各场 .log）；阅卷 `logs_eps/stage2/grade_stage2.py` → `logs_eps/scores/stage2a.md`（四场配对表 + 一阶覆盖表）；单元测试 `tests/test_denoise.py`；默认关闭时引擎逐位不变（ε=0.1 种子 1 前 3 轮曲线与第一阶段逐位一致）。
- **结果与定稿（10-12 21:50，工作笔记第五十七步 17–18）**：一阶清洗有效（病灶字段一阶 ε=0.1 反超 PGM 16%、ε=0.3 扯平；主轴 ε=0.1 负→胜、ε=0.3 +4.5%→+2.2%），二阶清洗三档全坏否决。全字段清洗给被对覆盖字段带 +2% 一阶偏差（它们的一阶由二阶测量决定），故**定稿规则 = `--oneway-pool 2 --oneway-pool-scope uncovered`：只清洗未被任何 ≥2 阶题覆盖的字段**（复核臂 hybridp1u：vs PGM ε=0.1 −2.5% 胜、ε=0.3 +2.2% 负；vs 全字段清洗 −0.8%/−0.0% 平；adult ε≥1 全字段被覆盖 → 题单原样、与第一阶段 hybrid 逐位同）。1B 记分变为 胜负平胜胜。遗留病灶：ε=0.3 没测对上的结构推断（填空测试：一阶传导已平，结构收益 −31.7k vs PGM −34.0k）。阅卷 `logs_eps/scores/stage2a.md`。

### 6.4 归属对照（10-13 补）

"③ vs PGM"两臂拿到同一份原始录像、各走各的流程，作为生成器对比成立；但清洗是零成本后处理，PGM 同样能用，须拆开"清洗规则的功劳"与"引擎的功劳"。补臂 `pgmrep10kp1u`：`run_pgmrep10k.sh` 命令逐字 + `--oneway-pool 2 --oneway-pool-scope uncovered`（`scripts/run_pgm_replay.py` 同名开关，numpy 自含实现；同字段重复一阶逆方差合并后清洗、以一条测量替换，高斯似然下等价；清洗向量与我们臂 `pool_oneway` 输出逐位核对一致，仅值序不同）。只跑 ε=0.1/0.3（ε≥1 adult 全字段被覆盖，开关恒等）。

| 对比 | ε=0.1 | ε=0.3 |
|---|---|---|
| 2A-8 pgmrep10kp1u vs pgmrep10k（PGM 只差清洗） | −4.5% 胜（−1.7/−8.2/−3.5） | −0.3% 平 |
| 2A-9 hybridp1u vs pgmrep10kp1u（同输入） | +2.0% 负（+3.3/+1.4/+1.4，刚过线） | +2.5% 负（+4.2/+1.4/+1.9） |

### 6.5 机制核查：对手的"分布"与"表"分开记（10-13 补）

PGM 的输出其实有两层：收敛的马尔可夫网（一个分布）和它采样出的 N 行表。`synthetic_data(method="round")` 逐父组随机取整 + 组内洗牌，每格注入约 ±√人数的抖动，与 ε 无关——测量越准这份抖动占比越大。只拿 PGM 的表比，会把"出表损耗"算成我们的功劳。规则：**凡对手能给出精确分布的（PGM/MRF 类），必须同时记"我们 vs 对手分布"与"对手表 vs 对手分布（出表损耗）"两行；"我们 vs 对手表"只作第三行校验。** 实现 `scripts/pgm_exact_marginals.py`（同配置重拟合，`model.project(attrs).datavector()` 精确一/二/三阶与等值题；半空间用 20×N 大表 /20 近似；每 50 次投影 `jax.clear_caches()` 以免撞 vm.max_map_count），阅卷 `logs_eps/stage2/grade_pgm_exact.py` → `logs_eps/scores/stage2b_pgm_exact.md`。重拟合表与第一阶段原表 0% 行相同（JAX 浮点次序）但各轴差 <1.5%，两份表二阶互距 ~21~23k×10⁻⁶，即出表随机性本身。

| ε | 我们 vs PGM 分布（主轴二阶） | PGM 出表损耗 | 我们 vs PGM 表（第一阶段原记分） |
|---|---|---|---|
| 0.1 | +5.3% 负（5.2/5.1/5.7） | +1.2% | +3.8% |
| 0.3 | +7.0% 负（7.8/5.8/7.2） | +3.4% | +4.5% |
| 1 | +7.9% 负（8.2/7.0/8.5） | +7.4% | +0.8% |
| 3 | +9.0% 负（8.3/10.0/8.7） | +21.0% | −10.1% |
| 10 | +9.5% 负（8.9/9.5/10.1） | +48.9% | −25.3% |

分组 我们 vs PGM 分布（测过的对 / 没测的对 / 一阶）：ε=0.1 +1.1/+5.8/+5.2；0.3 +0.3/+8.7/+4.4；1 +1.0/+10.5/+1.7；3 +2.0/+12.7/+2.4；10 −4.3/+17.9/−4.5。结论：a) 高 ε 的胜全是 PGM 出表丢的；b) 对手真实水平是 PGM 的分布，我们五档全负 5~9%，差全在没测的对（PGM 最大熵推断 vs 我们无先验的带噪独立）；c) 测过的对与一阶 ≈ PGM 分布，"落表无损"是我们真实且独有的优势。**口径：PGM 分布→表损失 7~49%、我们落表无此损失；论分布质量我们比 PGM 分布差 5~9%，差在没测的对。** 下一步候选（待 PI 令）：把 PGM 模型推出的没测对边际当软目标喂引擎（后处理、零隐私成本，精确边际已在 `results/stage2/*_pgmexact_*_exact.npz`）。

### 6.6 补没测的对：PGM 推断目标（10-13 补）

§6.5 定位差距全在 AIM 没测的对。拆解（ε=10，45 对）：真值离独立 82,025；PGM 分布误差 23,755；我们 28,006——引擎已靠表的耦合推到 PGM 的九成多，余下一截系统性略偏（逐对 PGM 赢 85~89%），非噪声（往独立收缩不变好）。没测的对无数据，最大熵推断是上限，目标为追平。规则：**允许把对手从同一份测量后处理得到的推断边际作为伪测量喂入引擎（零隐私成本），但须注明来源与 σ 口径，且测过的对仍用原始测量。** 实现 `scripts/add_infer_targets.py`（PGM 精确二阶边际逐格成 eq2way 题，σ = 该考卷二阶 σ 中位数，数据目录 `data/adult_aimrep{tag}_s{s}_infer/`，每卷 14301 题），臂 hybridinfer = hybrid 命令逐字只换数据目录；launcher `logs_eps/stage2/launch_infer_batch.sh`；阅卷 `logs_eps/stage2/grade_infer.py` → `logs_eps/scores/stage2b_infer.md`。

### 6.7 自洽地补没测的对：纤维洗牌平均目标（10-14 补，2B-3 / 2B-4）

规则（零预算后处理，不借任何对手产物）：
1. 取本方法自己的收敛表（第一阶段臂或 2A 定稿清洗臂的终表）。对每个字段，把行按"该字段在考卷里同时被测过的全部邻居字段"的取值分组，在组内随机互换该字段的值。考卷里每个测过的集合（一阶、二阶、含该字段的联合边际）逐位不变，须自检通过；没测过的关系被打散到"只剩经由测过字段传过来的部分"（局部马尔可夫性）。
2. 一条链连洗 100 趟，从第 2 趟起对每对没测字段的二阶边际取平均（`scripts/fiber_targets.py`，单表 ≈35 s）。单张洗牌表带抽样噪声只能收一半，必须取平均；平均到 100 趟后对 PGM 分布的剩余距离（adult ε=10 约 0.7 万）是系统性的（高邻居字段的行组太细），不是趟数问题。
