# 停止判据的理论依据草稿，噪声地板与两段平台停

回答三个问题。其一，机器凭什么知道该停，结论是带噪损失有一条由机制参数决定的信息论地板，损失贴近地板后的继续下降全是拟合噪声实现，见命题一。其二，为什么不能拿地板直接当停止线，结论是绝对值停止在俯冲段必崩且跨数据集不稳，必须写成到达噪声区与进展枯竭的合取，两个条件各自不充分，合取才稳，见命题二与实测教训。其三，晚停为什么有害，结论是追噪区里压带噪损失的方向与噪声实现对齐，真损失不降反升，早停是零成本的隐式正则，见命题三与四次独立实证。

## 一，记号与机制回顾

考卷由高斯机制生成，真答案向量 y 星加各格独立零均值方差 sigma 平方的噪声 xi 得到带噪答案 y 波浪，N 为格子总数，sigma 由隐私预算 epsilon delta 与查询集敏感度公开决定。机器全程只见 y 波浪，优化的带噪损失为 L 波浪(T) = sum_i (q_i(T) - y 波浪_i)^2，对真答案的真损失记 L 星(T) = sum_i (q_i(T) - y 星_i)^2，阅卷分数与真损失同向。

平台判据的实现在 src/resevo/batchkernel.py 的 evolve_batch，每 stop_lag = 100 轮结算一次窗口，取窗口内最优带噪损失 window_best，相邻两窗口的相对改进低于阈值即停。两段设计是，窗口最优损失首次降到噪声地板 F 以下后进入戒备态 armed，阈值从细阈 stop_threshold = 1e-4 切换为粗阈 stop_threshold_noisy = 3e-3，戒备态只切阈值不直接停，停止原因分别记 loss_plateau 与 noise_plateau 利于审计。地板取 F = c 乘 N 乘 sigma 平方，主线 c = 0.5，eps 1 下三数据集地板为 nltcs 942513，plants 355010111，adult 24265050。

## 二，命题一，噪声地板，带噪损失的期望下界

命题。对任意固定表 T，E[L 波浪(T)] = L 星(T) + N sigma 平方，特别地真表本身的期望带噪损失恰为 N sigma 平方，任何表都不能把期望带噪损失压到 N sigma 平方之下。

证明要点。逐格展开 (q_i - y 星_i - xi_i)^2，交叉项 E[xi_i] = 0 消失，噪声平方项期望 sigma 平方，求和即得。

推论一，带噪损失的实现值低于 N sigma 平方是可能的，但只能靠让残差 q - y 星与噪声实现 xi 正相关实现，即把这份噪声的具体抽样刻进表里，这就是追噪。地板 F 取半倍 N sigma 平方，窗口最优损失落到 F 以下说明实现值已显著低于任何表的期望下界，是已进入追噪区的证据，而非将要收敛的信号。

推论二，对大 N，L 波浪(T) 围绕期望的相对波动量级为根号(2/N)，N 为各数据集查询格子数，nltcs 480，plants 9248，adult 14123，最小的 nltcs 相对波动约百分之六，仍远窄于半倍余量，c = 0.5 的切换点不会被随机波动误触。

隐私口径说明，F 由格子数，机制 sigma，系数 c 三个公开量组成，不碰真数据与真答案，属后处理零隐私预算。

## 三，命题二，两段合取设计，绝对值停止不稳而合取稳

实测教训先行，回放第一轮试过纯地板停，损失一旦低于 F 立即收工，结果 c = 0.5 在开局俯冲段几十轮内就被砸穿，俯冲段一轮降数个量级，穿越地板完全不代表进展枯竭，c = 0.3 则在 nltcs 不同种子间行为不一，各数据集平台停点占理论地板比例 0.16 到 0.42 跨度太大，绝对值当停止线在本问题上不成立。

命题。把停止条件写成合取，条件甲为窗口最优损失不高于 F，条件乙为窗口相对改进低于阈值，则俯冲段与平台段的行为分别由以下两条保证。其一，俯冲段窗口相对改进远超粗阈值，量级为每窗口百分之几十对比粗阈千分之三，条件乙不成立，切换与否不影响俯冲段任何行为，不存在误停。其二，进入平台后相对改进单调趋零，停点由粗阈值与窗口长度唯一决定，与 c 在宽区间内无关，回放实测 c 从 0.25 到 0.5 停点完全不动，甜点区宽踩不崩。

证明要点。合取的两个条件针对两类错误各自免疫，条件甲挡住干净区里的正常平台，损失还高于噪声水平时即使改进变慢也只切粗阈而不是被粗阈误杀，因为未进戒备态时用的仍是细阈 1e-4，条件乙挡住俯冲段的地板穿越，二者缺一都会重现单条件方案的翻车。

## 四，命题三，晚停有害，追噪的泛化代价

命题。在追噪区继续压带噪损失，期望意义上真损失不降反升。分解 L 波浪 = L 星 + N sigma 平方 - 2 内积(q - y 星, xi) 加常数项波动，带噪损失已低于地板后，其进一步下降主要靠内积项增大，即残差方向与噪声实现对齐，此时 L 星的变化由方向对齐的代价主导，真损失回升。

实证四连。其一，plants 种子 3 最早平台停 1000 轮，综合分反而三种子最好，磨 3500 轮的种子 1 分最差。其二，adult 两段停 3999 轮比跑满 11500 轮提分 4%，晚停那七千轮不是白磨是有害。其三，粗阈 3e-3 相对 1e-3 再省三到四成轮数，plants 提 2.3%，adult 提 2.6%，九种子无一掉分。其四，5e-3 在 adult 抬损失 3.8 到 5.5%，说明粗阈存在上界，不是越早越好，3e-3 落在甜点区。晚停有害至此四次独立验证。

机理挂钩，早停与 stay 0.99，work-frac 0.10，damping 0.5 同属一条保守即正则线，噪声环境里少学少动少信，四个旋钮四度应验，构成方法叙述的主线。

## 五，常数校准账与敏感度

细阈 1e-4，官方三千轮切换版曲线离线回放，lag 50 100 200 乘阈值 1e-3 1e-4 1e-5 九档在干净区全不触发，尾部每百轮仍降 3.4%，1e-4 保守不误杀。

系数 c = 0.5，两段式下 c 0.25 到 0.5 停点完全不敏感，停点全由粗阈值决定，c 只需保证在俯冲段之后平台段之前完成切换，甜点区宽。

粗阈 3e-3，回放扫 1e-3 3e-3 5e-3，3e-3 省时提分，5e-3 在 adult 越界弃用，九种子转正确认无一掉分。

窗口 lag 100，与细阈联合回放校准，救援停的窗口 10 阈值 0.02 为另一套独立参数同法校准。

OFAT 佐证，第五件敏感度扫描证明主线各旋钮均处平台，无一处悬崖，停止层常数的回放校准与全局敏感度互为独立证据。

## 六，回放可预测性，停点的离线复现

两段停的停点可用旧全程曲线离线回放精确预测，回放器 scripts/replay_noise_stop.py，实跑停轮与回放预测在全部十八个对照点上口径一致，差 1 为取整口径，1e-3 时代 nltcs 699 599 699，plants 1299 1599 599，adult 3999 3299 3299，3e-3 时代 nltcs 500 500 500，plants 900 1000 500，adult 2300 2000 2200，停止原因全部 noise_plateau。可预测性的价值是停止层调参零算力，扫参在回放器上完成，实跑只做验收。

## 七，待定问题

其一，c 的机理下界未推导，回放显示 0.25 到 0.5 不敏感，理论上只需 c 严格小于 1 且切换点晚于俯冲段，c 能压多低未探。其二，粗阈 3e-3 是回放校准值，相对改进阈值与 sigma 的量纲关系未推导，缺一条从噪声波动幅度反推阈值的公式。其三，低 eps 档位地板占初始损失比例更大，俯冲段更短，两段停甜点区是否漂移待铺曲线战役实测。
