# AIM 选择层移植设计笔记

对标论文 AIM，McKenna Mullins Sheldon Miklau，PVLDB 2022，arXiv 2201.12677，
官方实现 private-pgm/mechanisms/aim.py，本仓外壳 scripts/run_aim_select.py。
目标是补齐 select-measure-generate 范式第三段，选择与测量照搬 AIM，生成段换本方法引擎。

## 一，照搬的部分

1. 候选集，全二阶 workload 的 downward closure 含一阶，权重为与 workload 各团交集大小加权和，compile_workload 语义与官方逐行对齐。
2. 预算日程，zCDP 总预算 rho 由 cdp_rho(epsilon, delta) 换算，测量份额 0.9 选择份额 0.1，轮数上界 T 默认 16 倍字段数，sigma 与 epsilon_t 由 T 反解，实际轮数由预算耗尽决定远小于 T。
3. 初始化，全部一阶边际先测一遍，按带噪一阶比例独立抽样出初始表，此步花测量预算。
4. 选择，指数机制，效用为候选边际上当前估计与真实答案的 L1 误差减噪声偏置 sqrt(2/pi) 乘 sigma 乘格子数，偏置项让效用近似真误差扣掉测了也白测的期望噪声。
5. 测量，选中边际全格高斯加噪入卷，同边际允许重复选中重复测量，各自成题等权，引擎拟合等效于取多次测量均值。
6. 预算退火，Algorithm 4 照搬，本轮测量前后估计在选中边际上的 L1 变化不超过 sqrt(2/pi) 乘 sigma 乘格子数即判白测，下轮 sigma 减半 epsilon_t 翻倍，剩余预算不足两轮时末轮吃光全部剩余。

## 二，与官方的三处差异

1. 树宽过滤拆除。官方 filter_candidates 按联结树参数表内存上限裁候选，是保图模型命的刚需，本方法无模型无此约束，候选永远全量入围。同款选择机制下官方被迫放弃的候选本方法照单全收，此为差异化卖点之一。
2. 预算原子换 bounded 口径。本仓考卷与 GSD 对照全线用 bounded 邻接，换一行两格各变一，高斯测量 L2 敏感度根号二，单次花费 1/sigma 方，官方 unbounded 为 0.5/sigma 方。指数机制效用 L1 敏感度相应取 2 wgt。sigma 公式相应为 sqrt(2T/(2 乘 0.9 rho))。不换口径会比本方法全测版多拿一倍有效预算，对比不公平。
3. 生成段换引擎。官方每轮 MirrorDescent 拟合图模型热启动，本方法每轮把累计测量写成考卷，引擎 --init-table 从上轮表续跑，当前估计即当前表，效用打分与退火判据全用表投影。末轮引擎长跑收尾。

## 三，实现细节

1. 引擎侧新开关 --init-table，从 CSV 载入初始表跳过抽样初始化，校验字段行数与域，与其他初始化开关互斥，默认空零改变。
2. 动态考卷含一阶单条件查询，求值层 evaluate_query 逐条件遍历天然支持，联合修改来源只收二到四字段集，一阶查询不进来源无碍。
3. 噪声地板逐题累加，0.5 乘 sigma_i 方乘格子数求和，退火后各轮 sigma 不同混装一卷，外壳逐轮算好传 --noise-floor。
4. 引擎种子每轮换，menu-seed 取机制种子乘十万加轮号，防逐轮同菜单。
5. 初始一阶花费超总预算一半直接报错，提示加大 T，防 T 过小烧穿。
6. 每轮考卷与表全部落盘工作目录，aim_log.json 记逐轮选中边际 sigma 预算退火与动量，全程可回放审计。

## 四，隐私账

外壳是机制，碰真数据的三处全部记账，初始一阶测量每条 1/sigma0 方，每轮选择 epsilon_t 方除 8，每轮测量 1/sigma_t 方，总和不超 rho。引擎只吃带噪考卷属后处理零花费。与官方 Theorem 1 同构，bounded 口径下逐项对应。

## 五，墙钟与轮数

T 是上界，退火触发后每轮花费乘四，实际轮数远小于 T。nltcs T 256 实际循环两百轮上下，本机 CPU 三种子并行每轮二十到一百秒。plants T 1104 与 adult T 240 的墙钟策略待 nltcs 验收后定，选项含 A6000 GPU，砍 T 记偏离，进程内化省每轮冷启动。
