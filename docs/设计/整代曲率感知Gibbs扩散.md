# 整代曲率感知 Gibbs 扩散

## 1. 研究问题

Issue #16 的标准闭环结果表明，最高三阶因子 Gibbs 相对独立单块核提高了一阶残差
方向收益，但整代平方 loss 的二次惩罚增加得更多，最终只有 13/20 个种子改善。
Issue #17 随后把二次增量精确拆成逐行自身项与跨行交叉项：两者分别占
61.32%/38.68%，没有任一项达到预注册的 2/3 主导门槛。到了 500 轮状态，联合核的
一阶优势只剩 `+0.213`，不足以支付总二次增量 `+0.535`。

因此本阶段不只固定每行 mask 基数，也不只缩小参与率。需要回答一个更一般的问题：

> 能否把平方 workload 的完整整代曲率直接写入有限温度扩散能量，在不使用收益
> 门槛、argmax、top-k 或 generation acceptance 的前提下，同时控制逐行组合和
> 跨行叠加造成的过冲？

另一个候选是总查询变化的硬预算或 trust region。但投影、删 bit、重抽或拒绝
超预算 mask 都对应不同的离散分布，并可能破坏反向支持或重新引入后置筛选。在
没有唯一生成语义前，本阶段不实现该路线；先研究具有明确目标分布与退化关系的
曲率核。

本阶段只做冻结算子验证，不接入默认生成器，不改变 `run_evolution`、
`scripts/run.py` 或任何默认参数。

## 2. 整代能量与平方 loss 恒等式

固定当前合成表、donor、参与行和旧查询答案。把所有参与行的复制 bit 合成整代
mask `M`。第 `i` 行的查询计数变化为 `δq_i(M_i)`，整代变化为

\[
D(M)=\Delta q(M)=\sum_i\delta q_i(M_i).
\]

令公开记录数为 `N`，计数残差为 `r=y-q`，比例残差为 `e=r/N`。定义

\[
V_\gamma(M)
=\langle e,D(M)\rangle
-\frac{\gamma}{2N}\lVert D(M)\rVert_2^2,
\qquad \gamma\ge 0.
\]

当 `γ=1` 时，若本阶段固定 `mu=0`，则

\[
V_1(M)=\frac{E(S)-E(S^M)}{N},
\]

其中 `E(S)=0.5 ||y-q(S)||²`。所以该能量不是二次项的近似，而是整代复制 proposal
的精确平方 workload 收益除以公开 `N`。除以 `N` 使曲率项与现有比例残差方向处于
同一尺度；不能把未归一化的计数二次项直接和现有温度混用。

以历史独立 Bernoulli 复制核为参考分布

\[
q_0(M)=\prod_b\eta^{M_b}(1-\eta)^{1-M_b},
\]

定义有限强度的整代目标分布

\[
\pi_\gamma(M)\propto q_0(M)\exp\{\beta V_\gamma(M)\}.
\]

`β` 沿用现有首个非零方向 RMS 固定定标，即 `β=tau/s0`。本阶段固定 `tau=2`，不同时扫描
温度。

### 2.1 退化关系

- `γ=0` 时，`V_0` 对记录分解为 `Σ_i <e,δq_i(M_i)>`，目标分布精确分解为现有
  逐行最高三阶联合 Gibbs 分布；
- 在相同独立初始 mask、逐行顺序、坐标随机量和 Bernoulli 均匀量下，`γ=0` 的
  有限步轨迹必须与现有 `evolve_step_factorized_gibbs` 逐 bit、proposal 和 RNG
  端点精确一致；
- `β=0` 时，所有条件更新退化为参考 Bernoulli 核，分布仍为 `q0`；
- `n_sweeps=0` 时不使用曲率项，精确返回现有独立定向初始 mask；为了
  保留该路径的最小依赖边界，不构造查询因子，未计算的查询变化与能量诊断明确
  记为 `None`，不误报为零。

这些是实现门禁，不是只比较均值的近似检查。

## 3. 单 bit 精确条件更新

固定其他 bit。令当前 bit 取 0 时整代查询变化为 `D0`，从 0 翻到 1 对查询变化的
增量为 `s`。则

\[
V_\gamma(M_b=1)-V_\gamma(M_b=0)
=\langle e,s\rangle
-\frac{\gamma}{N}\langle D_0,s\rangle
-\frac{\gamma}{2N}\lVert s\rVert_2^2.
\]

条件复制概率为

\[
P(M_b=1\mid M_{-b})
=\sigma\!\left(\operatorname{logit}(\eta)
+\beta\,[V_\gamma(1)-V_\gamma(0)]\right).
\]

实现默认沿用既有因子 Gibbs 的对称条件 logit 护栏 `[-30,30]`，避免有限输入在
float64 中舍入成确定性的 0/1。护栏一旦实际命中，有限步核就不再是上式未截断
目标的精确条件核；因此正式实验除记录有效 logit 最大绝对值外，还把“截断次数
必须为 0”设为语义门禁。显式关闭护栏只用于边界测试，不用于正式协议。

其中 `<e,s>` 继续由现有最高三阶稀疏方向因子精确计算；`s` 由每条查询在该行局部
mask 上的布尔变化因子精确计算。运行时只维护当前整代 `D`，不枚举整代全部 mask。

坐标调度保持现有因子 Gibbs 语义：参与行按固定行号顺序处理，每行执行
`n_sweeps * k_i` 个随机、带放回坐标微步。每个单坐标更新都是 `π_γ` 的精确 Gibbs
条件核；它保持目标分布不变并满足该微步的细致平衡。顺序复合核保持 `π_γ` 不变，
但不额外声称整个有限 sweep 复合核本身可逆。正式实验比较的是从同一独立初始
mask 出发的固定有限步转移，不把平稳分布性质冒充已经完全混合。

## 4. 扩散路线边界

本候选仍由已经提供的 workload 残差驱动，属于目标驱动的能量扩散。它与后置定向
筛选的区分必须由以下可检验性质支撑，而不能只靠命名：

- 有限 `β`、`0<eta<1` 且条件能量有限时，每个 bit 的两个状态都有正概率；
- 不按整代收益符号设置门槛，不执行方向 argmax、top-k 或候选排序；
- 冻结探针不执行 generation acceptance、重试、早停或 best checkpoint；
- 真实参考表、联合 TVD 和未测量查询不进入 mask 概率或参数选择；
- 高强度近确定性极限只作边界，不作为当前推荐路线；
- 若条件熵明显塌缩，即使训练收益改善，也只能记为更集中的目标驱动核，不能直接
  称为保留了有意义的扩散探索。

`γ=1` 使用的是已发布 workload target，而不是原始训练表。当前 target 仍是无噪声
精确计数，所以本研究不是 DP；它也不补齐查询选择、测量、accountant 或带噪
一致性。

## 5. 一次性冻结实验协议

正式运行前先用手算小例子和非正式小样本冒烟验证语义；正式结果只使用下面一次性
协议：

- 数据配置：`test_300x10`；
- 允许的运行时信息：公开 schema、公开记录数 300、预定义 50-query 精确 target、
  公开 1-way marginal；
- 种子：`0,1,2`；
- 每个种子两个预先固定状态：
  1. marginal 初始化状态；
  2. 同 seed 标准 0-sweep 残差驱动闭环 500 轮返回的 best 表；
- 每个 seed-state 200 个冻结 proposal，共 1200 对；
- donor：geometric；初始状态 `alpha=2`，500 轮状态 `alpha=10`；
- 更新：`rho=0.01`、`eta=0.5`、`mu=0`；
- 方向：`initial_rms, tau=2`；同 seed 两个状态复用标准闭环首个非零方向固定尺度，晚期不
  重新 RMS 加热；
- Gibbs：8 sweep、最高查询因子阶数 3、条件 logit 护栏 `[-30,30]`；
- baseline：`γ=0`；candidate：`γ=1`；唯一算法变量是曲率权重；
- 两侧共享状态、donor、参与行、独立初始 mask、逐微步坐标选择和条件抽样均匀量；
  初始 mask 必须从 update seed 独立重放全部行的随机 bit，而不能只从落地编辑反推；
- 设备：Conda `gsd`、单张 CUDA GPU（进程内逻辑设备 0）；
- 不执行 generation acceptance、重试、早停或 checkpoint 选择；
- 脚本不提供真实参考表路径，不报告联合 TVD；
- 所有地址由 `seed/state/proposal/stream` 确定性派生，失败 proposal 不得删除。

两个状态复用首个非零方向固定尺度的理由与 Issue #17 相同：如果在 500 轮状态重新按很小的
残差 RMS 归一化，就会把晚期方向重新加热，改变正在诊断的问题。

## 6. 记录指标与语义门禁

每个 proposal、每个核至少记录：

- 一阶收益、自身/交叉/总二次项、净收益和正/零/负收益；
- 参与行、活跃 bit、初始/最终复制 bit、mask Hamming 距离；
- Gibbs 微步条件概率的最小/最大值、平均 Bernoulli 条件熵、有效 logit 最大绝对值、
  护栏命中次数和双向支持门禁；
- 初始/最终整代查询变化哈希与 `V_γ`；
- 方向因子、查询变化因子、表项、微步数和构造/采样墙钟；
- 主 RNG 与 Gibbs RNG 的初始/最终摘要。

正式判断前必须全部满足：

1. 每个 seed 的直接初始态、闭环初始表哈希与正有限方向尺度元数据完整；
   两侧状态、donor、参与行、独立初始 mask、坐标/均匀随机流与 RNG 端点对齐；
   独立重放必须同时覆盖未参与行的初始随机 bit、落地有效 mask 和 mutation roll；
2. 新实现 `γ=0` 与现有因子 Gibbs 的最终表、mask 和 RNG 端点 1200/1200 精确
   一致，且每个微步条件概率逐值误差为 0；
3. 每次单 bit 条件能量差与直接重算 `V_γ(1)-V_γ(0)` 的测试误差不超过
   `1e-10`；
4. 每个 proposal 的 `N*V_1` 与直接平方 loss 收益误差不超过 `1e-10`；
5. 逐行查询变化之和、二次分解和 gain 恒等式误差均不超过 `1e-10`；
6. 所有正式微步条件概率严格位于 `(0,1)`，没有非有限能量或概率，且 logit 护栏
   实际命中次数为 0。

任一门禁失败时，正式结论只能是实现/诊断失败，不能解释算法效果。

## 7. 预注册主判断与风险标记

Issue #17 已显示全局结果会被初始大残差主导，所以本次主判断只使用三个 500 轮
seed-state；初始三个状态只作预先声明的阶段安全检查。200 个 proposal 共享同一
状态，不能当成 600 个独立实验单元宣称显著性。

主指标是每个 500 轮 seed-state 内 candidate 相对 baseline 的平均净 proposal
收益差。通过全部门禁后：

- 若三个晚期状态的平均差全部大于 0，晚期 600 对的聚合平均差也大于 0，且聚合
  正收益率不下降、至少 2/3 个晚期状态的正收益率不下降，则记为
  `supports_late_curvature_kernel`；
- 若晚期聚合均值改善但只有 2/3 个状态改善，或净收益改善但正收益率条件未通过，
  记为 `late_curvature_inconclusive`；
- 若晚期聚合平均差不大于 0，或至多 1/3 个状态改善，记为
  `late_curvature_not_supported`。

不以 proposal 级 p 值替代该规则，也不在观察结果后追加种子、换温度、换 sweep、
调 `rho` 或改 `γ`。

预先声明两个风险标记：

- 若初始三个状态聚合平均净收益相对 baseline 恶化超过 5%，即使晚期主判断支持，
  也只能称为晚期局部改进，不能直接进入完整动力学；
- 若晚期 candidate 的平均微步条件熵相对 baseline 下降超过 10%，则标记
  `conditional_entropy_concentration_risk`。数学支持仍在不等于探索强度没有实质
  塌缩。

复制单元格、mask Hamming 和条件概率分位数用于解释，不事后变成新的成功终点。
三种子结果只提供较强方向性机制证据，不支持跨 workload 通用最优声明。

## 9. 正式冻结实验结果

原输出 `959f93e` 的算法结果没有触发异常，但深审发现它从 0-sweep 落地编辑反推
初始有效 mask，不能独立覆盖未参与行上仍被消费的随机 bit；同时它没有显式记录
后来由父分支统一加入的 logit 数值护栏。提交 `743c8d5` 首次补齐这两项
证据。

同步 PR #22 最新父 HEAD 后的深审又收紧了正式状态元数据门禁：缺少任一直接
初始态、闭环初始表哈希或正有限方向尺度时立即失败；同时把 0-sweep 未计算的
查询/能量诊断从误导的零改为 `None`。两项均不改变正式 8-sweep 路径。以下
结果在干净提交 `991d039`、Conda `gsd` 和 RTX 4090 上重跑
（`CUDA_VISIBLE_DEVICES=1`，进程内逻辑设备 0）。固定的
3 seed × 初始/500 轮状态 × 200 proposal 共 1200 对全部完成；没有删除、替换或
追加状态，也没有真实参考表输入路径。

### 9.1 语义与恒等式门禁

- 直接 marginal 状态与标准闭环初始表哈希 3/3 一致；同 seed 的两个状态复用同一
  个标准闭环首个非零方向 RMS；
- donor、参与行、独立初始 mask、主 RNG 与 Gibbs RNG 1200/1200 对齐；初始 mask
  由 update seed 独立重放全部行的随机 bit、落地有效 mask 和 mutation roll；
- 新实现 `γ=0` 与既有因子 Gibbs 的最终表、最终 mask、共同诊断和 RNG 端点
  1200/1200 精确一致，156,720 个 `γ=0` 条件概率逐值最大误差为 0；
- 内部初始/最终查询变化与直接整表评价的最大误差均为 0；
- `N*V_1` 与直接平方 loss 收益的最大误差为 `5.68e-14`；
- `gain=linear-quadratic`、`quadratic=self+cross` 的最大误差均为 0；
- 稀疏线性因子与查询变化内积的最大误差为 `2.78e-17`；
- 两侧各 156,720 个微步全部保留计算上的双向条件支持；全程最大有效
  `|logit|=9.70686`，低于护栏 30，实际截断次数为 0。

独立审计严格解析全部 JSON 数值，复算 6 个状态、1200 对、查询变化哈希、每行
收益恒等式、全部状态/阶段/全局配对汇总和条件熵汇总；将新增门禁、mask 表示变化
和计时字段归一化后，与 `959f93e` 的所有非计时算法结果精确一致。
`743c8d5` 与最新输出去除环境、命令/路径和墙钟字段后，整份 JSON 也精确一致。

因此下面的差异来自唯一变量 `γ=0→1`，不是状态、初始 mask、随机流、有限步调度或
能量实现错位。

### 9.2 预注册晚期主判断

| 500 轮状态，600 对 | `γ=0` | `γ=1` | 平均配对差 |
|---|---:|---:|---:|
| 一阶残差收益 | 3.8233 | 3.3250 | -0.4983 |
| 逐行自身二次项 | 8.1967 | 7.2742 | -0.9225 |
| 跨行交叉二次项 | 0.7183 | 0.0283 | -0.6900 |
| 总二次项 | 8.9150 | 7.3025 | -1.6125 |
| 净 proposal 收益 | -5.0917 | -3.9775 | **+1.1142** |
| 正收益率 | 10.17% | 12.50% | **+2.33 pp** |
| 复制单元格数 | 7.4500 | 6.7683 | -0.6817 |

三个晚期 seed-state 的净收益差分别为 `+1.4125/+0.8675/+1.0625`，正收益率差
分别为 `+1.0/+3.5/+2.5 pp`，全部同向。逐 proposal 配对为 227 胜、332 平、
41 负。因此通过预注册规则，正式判断为
`supports_late_curvature_kernel`。

机制与预期一致：曲率核牺牲 `0.4983` 的一阶方向收益，但同时减少 `1.6125` 的完整
二次惩罚，净改善 `1.1142`。自身项与交叉项分别减少 `0.9225/0.6900`，说明同一个
整代能量确实同时作用于 Issue #17 识别出的两类来源，而不是只修复其中一个。

这个结果是相对改善，不是正漂移证明：两侧晚期平均净收益仍都为负。它支持把候选
带入后续无接受动力学或标准闭环验证，但不能直接推出最终 loss、接受率或生成质量
已经改善。

获得晚期改善，尽管个别条件更新会比 baseline 更强地偏向某一方向。

candidate 在晚期平均少复制 9.15% 单元格，baseline/candidate 最终 mask 平均相差
0.792 bit。当前实验检验的是完整分布定义，不能进一步把收益归因为“只减少复制量”
或“特定交叉结构”；若要作该机制归因，需要另行预注册匹配查询步幅或复制量的
