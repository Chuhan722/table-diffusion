# 残差信号几何：绝对与相对残差的适应度口径（Issue #57）

## 背景与问题

适应度信号链此前使用绝对比例残差：

    ε_j = (y_j − q_j(S)) / N

fitness `F(z) = Σ_j ε_j (a_j(z) − p_j)` 是 L2 计数损失
`E = ½Σ(y_j−q_j)²` 的一阶方向导数；残差定向扩散的方向场共享同一 ε。
该口径把每单位计数残差视为等价，优化力气天然集中于大计数查询。

评价主指标是每查询平均归一化 L1（`mean|y−q|/N`，对所有查询等权）。
多轮增强（预算加倍、maxent 初始化、si×factor Gibbs、乘性场简单版）
都停在 nltcs L1 ≈ 0.00086–0.0011 的平台。

## 诊断证据（dev，探索性，nltcs）

1. **抽样参考线**：真表自查 L1=0（完美解存在于表空间）；从真表 iid
   bootstrap 重抽 16181 行 20 次 L1 = 0.001598 ± 0.000174。既有最优
   0.000864 已低于单次 iid 抽样涨落线 46%——平台不是容量问题。
2. **平台残差谱**（si α16、2000 轮、seed 42，L1=0.001042）：
   - p<0.05 的查询占残差 L1 的 44.8%（bootstrap 对照 22.3%）；
   - p<0.01 桶平均相对误差 23.2%（bootstrap 9.7%）；
   - top-20 大残差查询的 p 中位数 0.023（bootstrap 0.374）；
   - p>0.25 桶平均残差 24/13 计数，已低于 bootstrap 涨落（41/45）。

   即绝对残差口径把大计数查询压到抽样涨落之下，而对稀有模式查询
   系统性无力：同为 16 计数的残差，对 target=5000 是 0.3% 误差、对
   target=50 是 32% 误差，在 fitness 中音量相同。几何失配，调参无解。

## 设计

`objective.compute_residual` 增加 `geometry` 参数：

    absolute（默认）: ε_j = sign(raw_j) · magnitude_j / N
    relative:         ε_j = sign(raw_j) · magnitude_j / max(y_j, floor) / N

- `magnitude` 是 σ/κ 噪声容忍之后的残差幅度：**容忍先于相对化**，
  DP 阶段的容忍语义不变；
- `floor > 0`（默认 8.0，计数单位）防止 y_j 极小或为 0 时分母爆炸；
- relative 近似 KL/最大熵拟合的梯度口径：稀有查询的推动力按相对误差
  放大。与外部边缘拟合方法（private-pgm 系）优化几何一致的假说来源；
- **信息流不变**：相对化只使用公开 target 计数做归一化，不引入新信息；
- **作用范围**：ε 同时流入 fitness（尺度不变选择核）与残差定向扩散的
  方向场，二者共享同一 residual 向量，信号几何统一切换；
- **不改动**：监控 loss（`compute_loss`，L2 口径）、接受门语义、终止
  检查（`residual==0` 零点在两种几何下相同）。

`run_evolution` 透传 `residual_geometry` / `residual_geometry_floor`
（vectorized 与 legacy 两条评价路径一致），诊断 `params` 记录配置。

## 边界与 DP 前瞻

- 本阶段仍是无噪声原型，本设计不构成任何 DP 声明；
- DP 阶段分母将使用带噪计数 ỹ：噪声进入分母的稳定化（如 floor 与噪声
  尺度 σ 挂钩、或改用平滑 y+c）需在 DP 设计中单独处理并计入预算论证；
- floor=8 来自 dev 拍定，正式实验含敏感性检查（见下）。

## 预注册正式实验（运行前冻结）

- **假设**：relative 几何在同配置同预算下显著优于 absolute（主指标
  每查询平均归一化 L1，nltcs 主判定）。
- **唯一变量**：residual_geometry（及次要臂的 floor 值）。
- **baseline**：no_gate_si 冻结配置（tol=inf、si α≡16、min_spread
  1e-3、ds=2.0、rho=0.01、marginal 初始化，与 #48 v3 正式配置一致），
  residual_geometry="absolute"。
- **candidate**：同配置 residual_geometry="relative"，floor=8。
- **次要臂（floor 敏感性）**：relative floor ∈ {1, 4, 16}（8 为主臂）。
- **种子**：配对 5 种子 200..204（与 dev 的 42/43/44 不重叠）。
- **轮数**：2000（与 dev 一致的固定预算口径；同轮数结论，不含墙钟
  等价声明）。
- **数据集**：nltcs（主判定）+ test_300x10（冒烟一致性）。
- **指标**：训练 workload L1（主）、未测量 2/3-way L1、train/test
  TVD、支持集指标、墙钟与候选评价次数（AGENTS 第 5 节全指标）。
- **判定**：主指标配对 5/5 改善且配对均值改善 ≥30% → supports；
  未达 supports 但 ≥3/5 种子改善且配对均值更低 → mixed；否则
  not_confirmed。train 侧未测量 3/4-way L1 或分箱 TVD 相对 baseline
  劣化 >5% 时报警，supports 降级为带质量风险后缀（与执行脚本
  QUALITY_RISK_REL=0.05 一致）。
- **失败结果全部保留。**
