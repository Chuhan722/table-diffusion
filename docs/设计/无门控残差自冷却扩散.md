# 无门控扩散演化：残差自冷却与吸收态动力学

关联 Issue #44（研究主题）、Issue #43（方法边界与消融协议）。

## 1. 动机

项目的方法主张是扩散演化：方向与收敛来自 fitness 加权 donor 抽样与扩散核的
分布动力学本身。但主循环从最初就带有整代接受门 `proposal_loss <= loss + tol`。
接受门是归因混杂因子：随机变异加贪心门本身就是有效爬山法，只要门在，就无法
证明扩散机制的必要性（Issue #43 的三臂探索数据：无门恒定扰动下分布倾斜完成
约 99.6% 的下降 28,900→118，但终点回漂到 ~234；历史门 85.7）。

回漂的机制原因：现有 fitness `F(z)=Σ_j ε_j(a_j(z)−p_j)` 在残差为零时自动变平
（达标查询不再产生选择压力），但参与率 `rho`、变异率 `mu` 是常数——即使
donor 抽样退化为近均匀，每代仍以恒定幅度重抽记录，零残差不是动力学的吸收态。
门的实际作用是"棘轮"：锁住终点。要去门，就必须把棘轮换成分布侧机制。

## 2. 机制定义

设第 `t` 轮当前查询答案为 `q_t`，初始为 `q_0`，定义残差比与冷却因子

    r_t = min(1, ||target − q_t||_1 / ||target − q_0||_1)
    c_t = r_t ** p                （p > 0，冷却指数）

每轮把扰动幅度整体缩放：`rho_t = rho · c_t`（重试缩步在其上叠乘）、
`mu_t = mu · c_t`。方向倾斜强度不缩放（参与的少数行仍按残差方向复制）。

性质：

- **零残差 = 吸收态**：`r_t = 0 ⇒ c_t = 0 ⇒` 无行参与、无变异，表停止变化；
  达标早停仍然在前（残差全零直接停止）。
- **纯分布侧**：`c_t` 只依赖当前合成表对（公开/已测）target 的残差，不含任何
  候选接受/拒绝判定；与 `tol=inf`（关闭接受门）组合即无门控配置。
- **内在停止**：`r_t ≤ self_cooling_stop_ratio` 时停机，为门控接受率之外的
  收敛信号。
- 初始残差为零时定义 `r = 0`（初始即达标）。

`p` 控制冷却陡度：`p=1` 线性，`p=2` 更陡（晚期噪声更小、下降更慢），`p=0.5`
更缓。

## 3. API 与边界

`run_evolution` 新增两个参数，默认全部关闭：

- `residual_self_cooling: Optional[float] = None`——冷却指数 `p`；None 关闭，
  此时主循环行为与历史逐轨迹一致（默认路径已做跨提交等价对拍）。
- `self_cooling_stop_ratio: Optional[float] = None`——内在停止阈值，取值
  (0, 1)，需同时启用冷却。

诊断新增 `self_cooling_history`（与 `loss_history` 逐轮对齐）与
`self_cooling_stopped`；两个参数写入 `params`。

边界：

- 研究机制，不修改默认生成器行为；
- 不与门控互斥——门开着时冷却同样生效（对照臂用途）；
- 冷却读取的是合成表对 target 的残差，与真实训练/测试表无关；
- 本阶段无 DP 声明。

## 4. 探索性证据（2026-08-11 冒烟，非正式结论）

test_300x10、seed 42/43/44 配对、残差定向扩散开启、`scripts/compare_gate_free_self_cooling.py`
同配置。抛弃式补丁（等价于本实现 `p=1`）结果：

| 臂（3 种子均值） | 轮数 | 最终 loss | 全程最优 | 末 100 轮均值 |
|---|---|---|---|---|
| 无门 + 恒定扰动 | 500 | 272.8 | 118.0 | 234.0 |
| 无门 + 自冷却 p=0.5 | 2000 | 152.7 | 85.8 | 155.3 |
| 无门 + 自冷却 p=1 | 2000 | 89.2 | 65.5 | 104.5 |
| 有门历史贪心（同轮对照） | 2000 | 82.3 | 82.3 | 82.9 |

方向性解读（单小表、三种子、无离线质量指标，不作最终结论）：

1. 纯分布侧冷却大幅压缩无门终点回漂（final/best 从 2.31 倍降到 1.36 倍）；
2. `p=1` 无门全程最优 65.5 低于同轮有门贪心 82.3——无门动力学不仅可追平，
   还探索到贪心门锁死后够不到的更低能量区；
3. 吸收态未完全达成：末段仍有波动带，候选改进为更陡冷却（`p=2`）或内在停止
   阈值截断。

正式实现的复现口径以本仓库提交的对照脚本输出为准。

## 4b. 机制边界（2026-08-12 审查补充）

- **rho 与 mu 同时冷却的复合效应**：变异只发生在参与更新的记录上，因此
  `rho·c` 与 `mu·c` 叠加后总变异量近似按 **c²** 缩小（c=0.1 时总变异约剩
  1%）。这是当前设计的有意选择——变异是无方向扰动，收敛后期二次压低它有利
  于终点锁定；但它也可能与小表上观察到的多样性下降有关。"只冷却 rho / 只
  冷却 mu / 同时冷却"的分解对照留待后续独立预注册。
- **非单调复燃只作用于扰动幅度**：残差回升时 `rho`、`mu` 回升，但 donor
  选择锐度 `alpha` 仍按轮数从 alpha_min 单调升到 alpha_max，不会回到早期
  探索值。准确表述是"更新幅度重新升温"，不是整个扩散状态回到早期阶段。
  固定 alpha 或残差驱动 alpha 的对照留待后续。
- **rho 显式固定**：正式协议自审查后显式固定 `rho=0.01`（项目标准配置）。
  此前首轮正式运行继承了 `run_evolution` 默认 `rho=0.1`，与文档"每轮约
  rho·N≈162 行"的计算不符；该轮结果保留为历史记录，正式结论以 rho=0.01
  重跑为准（见 §7）。

## 7. 正式结果（2026-08-12，预注册协议；rho 更正后为准）

### 7.1 rho=0.1 首轮（历史记录，已被更正取代）

首轮正式运行继承了 `run_evolution` 默认 `rho=0.1`（协议疏漏，审查发现）。
该轮 nltcs 曾得到 `supports`（无门+冷却 L1 0.003552 vs 有门 0.008450）。
现已确认这一优势是 rho 混淆的产物：`rho=0.1` 的大扰动让贪心门整代拒绝率
极高、等预算下浪费大量候选，有门 baseline 被系统性削弱。输出保留为
`*.rho01_legacy.json`，不再作为方法结论引用。

四臂允许把"候选方案未通过"与"失败来自哪个机制"分开（最终表 L1，5 种子

| 固定因素 | 比较 | 比值 | 解读 |
|---|---|---|---|
| 无门 | 冷却 0.006626 vs 恒定 0.003467 | 1.91 | 冷却有害 |
| 有门 | 冷却 0.006263 vs 恒定 0.002728 | 2.30 | 冷却有害 |

"完整候选方案能否替代历史方案"，不作为单因素因果判断。

### 7.4 机制解读与结论边界

1. **双重冷却是有意设计，结论限定其内**：冷却因子同时乘 `rho`（参与行
   比例）与 `mu`（行内变异率），变异通道的总机会按 **c_t² 近似二次冷却**
   （残差比 0.1、p=1 时变异机会只剩约 1%）。这是设计时的选择（§4b 第一轮
   审查已文档化），实验严格支持的结论因此限定为：**"同时冷却 rho 与 mu
   的这套双重自冷却方案，在 rho=0.01、p=1、2000 轮等预算与本组数据集上
   不能替代历史门"**。不推及"残差自冷却思路整体无效"——只冷却 rho、
   只冷却 mu、以及 `sqrt(c_t)` 分解（乘积按 c_t 线性缩小）均未测试，
   保留为开放变体。
2. **冷却×小 rho 交互**：`rho=0.01` 本已是小扰动（nltcs 每轮约 162 行），
   冷却再乘残差比在预算内把动力学饿死；min_cooling 冻结在 ~0.105，
   rho_eff ≈ 0.001（每轮 ~16 行）。
3. **回漂消除的正面性质保留**：无门+冷却回漂比 1.0002，吸收态语义本身
   成立；代价是等预算收敛不足。
4. **扩散必要性结论对 rho 稳健**（见 2×2 消融，PR #47 同步重跑）：
   rho=0.01 下无门条件扩散/随机 = 0.104（5/5），有门条件随机/扩散 =
   18.97——方向必要；该比较的含义限定见 PR #47（门能改善随机核但不能
   使其匹配引导核）。

下一步机制迭代的量化目标因此更正为：**在 rho=0.01、无门、等预算条件下打平
0.002728**——候选方向为 Issue #40 的漂移约束退火、只冷却 mu/方向强度的
分解调度，以及已另行推进的尺度不变选择（PR #48）。
