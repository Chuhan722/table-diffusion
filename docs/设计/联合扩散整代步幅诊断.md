# 联合扩散整代步幅诊断

## 1. 研究问题

Issue #16 的标准接受闭环实验中，8-sweep 因子 Gibbs 相对 0-sweep 独立核把
best workload loss 聚合均值降低 13.64%，但只取得 13/20 胜，没有通过预注册的
14/20 门槛。事后恒等分解显示，一阶残差方向收益平均增加 0.3048，而平方 loss
的整代二次惩罚增加 0.4614。当前小目标不是继续调 `rho`，而是回答：

> 联合 mask 增加的二次过冲，主要来自单条记录内部复制块数/组合的变化，还是来自
> 同一代多条记录在查询空间中的同向叠加？

只有先区分这两个来源，才能在固定基数 Gibbs、参与率/微批时间步归一化或保留失败
之间作有依据的选择。本阶段只做冻结诊断，不实现候选，不改变默认参数。

## 2. 精确分解

固定当前合成表、donor、旧残差和一代内的全部随机量。第 `i` 条记录更新对训练
查询计数的变化向量记为

\[
\delta q_i = a(x'_i)-a(x_i),
\qquad
\Delta q = \sum_i \delta q_i.
\]

平方 workload loss 下，提案收益精确为

\[
G
=\langle y-q,\Delta q\rangle-\frac12\|\Delta q\|_2^2
=L-Q.
\]

二次项进一步精确分解为

\[
Q
=\underbrace{\frac12\sum_i\|\delta q_i\|_2^2}_{Q_{self}}
+\underbrace{\sum_{i<k}\langle\delta q_i,\delta q_k\rangle}_{Q_{cross}}.
\]

- `Q_self` 只反映每行内部复制块的数量和组合；
- `Q_cross` 反映同一代不同记录的查询变化相互增强或抵消；
- `Q_self + Q_cross` 必须与直接计算的 `0.5 ||Δq||²` 在 float64 精度内一致；
- 该分解只使用公开查询、当前合成表和 proposal，不读取真实参考表。

## 3. 配对语义

每个冻结 proposal 的两侧共享：

- 当前状态、查询答案、残差、fitness、距离和 donor；
- 记录参与随机量；
- 逐属性独立定向初始 mask；
- 变异随机流（正式诊断固定 `mu=0`，另用测试覆盖非零变异）；
- 主 RNG 的抽取顺序和端点。

baseline 使用初始 mask，即 0 sweep。candidate 从完全相同的初始 mask 出发，使用
独立派生的 Gibbs RNG 执行 8 sweep。额外 Gibbs 随机量不得错位 donor、参与、
初始 mask 或后续变异。两侧不执行 generation acceptance、重试、早停或 best
选择；每个 proposal 都只离线测量，不成为下一状态。

初始 mask 不能只从 baseline 最终提案反推：未参与行即使抽中了复制 bit，也不会在
表上留下变化。脚本必须从配对 `update_seed` 独立重放 participation、每个属性的
Bernoulli 初始 mask 和 `mu=0` 变异随机量；重放后的主 RNG 端点要与两侧更新一致，
且重放 mask 在参与行上的落地编辑要与 baseline proposal 逐单元一致。输出同时记录
全 mask 和实际落地 mask 的摘要，避免用同一个反推哈希自证对齐。

## 4. 一次性冻结协议

- 数据配置：`test_300x10`；
- 运行时信息：公开 schema、公开记录数 300、预定义 50-query 精确 target、
  公开 1-way marginal；
- 种子：`0,1,2`；
- 每个种子两个预先固定的状态：
  1. marginal 初始化状态；
  2. 相同 seed 下标准 0-sweep 残差驱动闭环 500 轮返回的 best 表；
- 每个 seed-state 200 个冻结 proposal，共 1200 对；
- donor：geometric；初始状态用 `alpha=2`，500 轮状态用 `alpha=10`；
- 更新：`rho=0.01`、`eta=0.5`、`mu=0`；
- 方向：`initial_rms, tau=2`；
- 同一个 seed 的两个冻结状态复用其 500 轮标准闭环首轮固定的
  `direction_reference_scale`，不得在晚期状态重新 RMS 归一化并把残差方向重新
  加热；同时要求直接 marginal 状态与该标准运行的初始表哈希一致；
- 唯一算法变量：`factorized_gibbs_sweeps=0` 对 `8`；
- 因子最高阶数 3，条件 logit 数值护栏固定为 `[-30,30]`；
- 正式环境：Conda `gsd`、CUDA 0；
- 不读取真实参考表，不报告或选择联合 TVD；
- 全部状态和 proposal 地址使用 `seed/state/proposal/stream` 派生，失败项不得删除。

后期状态生成本身沿用标准接受闭环，但冻结诊断中的 proposal 不执行接受。返回的
best 表只是预先定义的公开生成状态，不使用真实表挑选。

## 5. 指标

每个 proposal、每个核记录：

- `linear_gain`、`quadratic_penalty`、`self_penalty`、
  `cross_penalty` 和 `net_gain`；
- 正/零/负收益；
- 参与行数、实际变化行数、复制单元格数；
- 每条参与记录的 active block 数、初始/最终复制块数和两侧 mask Hamming 距离；
- 因子数、表项、Gibbs 微步、因子构造/采样墙钟；
- 主 RNG 与附加 RNG 端点摘要。

聚合时同时报告 1200 个 proposal 的均值/分位数/配对差，以及六个 seed-state 的
独立均值；proposal 不是六个独立实验单元，不能把 1200 行当作独立样本宣称显著性。

## 6. 预先判断规则

先要求以下语义门禁全部成立：

1. 两侧 donor、参与行、初始 mask 和主 RNG 端点逐 proposal 对齐；
2. `update_seed` 重放的初始 mask 与两侧主 RNG 端点一致，且参与行上的落地编辑与
   baseline proposal 逐单元一致；
3. 每个 proposal 的逐行 `δq_i` 之和等于整表 `Δq`；
4. `Q_self + Q_cross` 与直接二次项的最大绝对误差不超过 `1e-10`；
5. 净收益与 `linear - self - cross` 的最大绝对误差不超过 `1e-10`。

通过门禁后，令 candidate 相对 baseline 的六个 seed-state 平均差为
`ΔQ_self` 和 `ΔQ_cross`：

- 若全局 `ΔQ>0`，且 `ΔQ_self` 为正、占 `ΔQ` 的至少 2/3，并在至少
  4/6 个 seed-state 大于 `ΔQ_cross`，则证据支持优先研究固定基数或每行步幅
  归一化；
- 若全局 `ΔQ>0`，且 `ΔQ_cross` 为正、占 `ΔQ` 的至少 2/3，并在至少
  4/6 个 seed-state 大于 `ΔQ_self`，则证据支持优先研究参与率、微批或查询变化
  时间步归一化；
- 其他情况记为混合或不确定，不强行选择候选。

“占比”只在全局 `ΔQ>0` 时计算；分量可能为负，必须保留符号和全部状态。mask
基数差只用于解释 `Q_self`，不能替代查询空间分解。

## 7. 测试与边界

实现前后依次验证：

1. 手工小例子的逐行查询变化、自身项、正/负交叉项和恒等式；
2. 零参与、单参与、多参与、无活跃块和零查询变化；
3. 0/8 sweep 的主随机流对齐、固定种子复现和非法输入；
4. 非零变异只作随机流/分解测试，不混入正式诊断；
5. 非有限输入及有限输入导致的 float64 聚合溢出必须明确拒绝；
6. NumPy 与 CUDA 冒烟、语法检查、针对性测试、完整测试和
   `git diff --check`。

本阶段仍使用精确 target，是无噪声原型，不是 DP。诊断只依赖允许的生成运行时
信息，但这不补齐查询选择、测量噪声、预算 accountant 或端到端隐私说明。

关联 Issue #17、#16、#14；因子构造性能继续由 Issue #15 独立跟踪。

## 8. 正式诊断结果

正式诊断在迁移深审修复后基于干净提交 `2441933`、Conda `gsd` 和 CUDA 0。3 个 seed ×
初始/500 轮两个状态 × 200 个 proposal 共 1200 对全部完成，没有删除或替换状态。
脚本没有真实数据路径，也没有读取或报告联合 TVD。

旧提交 `4c1e82d` 的输出把 baseline 提案中实际落地的复制反推成初始 mask；未参与行
不会在表上留下编辑，因此该哈希不足以独立证明全 mask 对齐。当前正式输出已改为从
配对 `update_seed` 重放 participation、全体独立初始 mask 和 `mu=0` 随机消耗，再
核对 RNG 端点及 baseline 参与行落地编辑。旧、新输出的全部非计时主指标、mask
汇总、六个状态分解和来源判断精确一致，但正式证据以后者为准。

### 8.1 语义与恒等式门禁

- 直接 marginal 状态与同 seed 标准闭环运行的初始表哈希 3/3 一致；
- 每个 seed 的初始/500 轮状态复用同一个标准闭环首轮 RMS；
- donor、参与行和主 RNG 端点 1200/1200 对齐；
- 配对 seed 重放的全体独立初始 mask 与主 RNG 端点 1200/1200 对齐，其参与行
  落地编辑也与 baseline proposal 逐单元一致；
- 逐行 `δq_i` 之和与整表 `Δq` 的最大误差为 0；
- `Q_self + Q_cross = 0.5 ||Δq||²` 的最大误差为 0；
- `gain = linear - self - cross` 的最大误差为 0。

因此下面的差异来自 0/8 sweep mask 本身，不是状态、donor、主随机流、尺度或数值
分解错位。

条件 logit 护栏固定为 `[-30,30]`。另一次完整协议审计覆盖 158,512 次实际 Gibbs
条件更新，最大原始 `|logit|=9.706858375965169`，没有非有限值或护栏触发；审计
输出去除墙钟与命令路径后与正式输出精确一致。

### 8.2 全局分解与预注册判断

| 1200 个配对 proposal | baseline | candidate | 平均配对差 |
|---|---:|---:|---:|
| 一阶残差方向收益 | 31.8783 | 45.5250 | +13.6467 |
| 逐行自身二次项 | 8.8963 | 9.7338 | +0.8375 |
| 跨行交叉二次项 | 0.7300 | 1.2583 | +0.5283 |
| 总二次项 | 9.6263 | 10.9921 | +1.3658 |
| 净 proposal 收益 | 22.2521 | 34.5329 | +12.2808 |
| 复制单元格数 | 8.4833 | 8.7625 | +0.2792 |

总二次增量中，自身项占 61.32%，交叉项占 38.68%。自身项在 5/6 个 seed-state
中比交叉项增量更大，但其全局占比没有达到预注册的 2/3；交叉项也没有达到 2/3，
只在 1/6 个状态占主导。因此正式来源判断为
`mixed_or_inconclusive_source`。不能因为自身项略大就直接选择固定基数 Gibbs，
也不能因为交叉项始终为正就只做参与率或微批归一化。

初始到最终 mask 每个 proposal 平均有 7.001 个复制 bit 不同。candidate 复制
单元格只增加 3.29%，而自身二次项增加 9.41%，说明问题不只是复制块数稍多；
联合选择了哪些块、这些块共同影响哪些查询同样重要。

### 8.4 阶段结论

本诊断否定了“二次过冲主要由单一来源造成”的预注册假设，因此本阶段不选择或实现
组件特定的归一化算子。更一般的下一问题应同时处理联合 mask 的逐行查询组合和
跨行叠加，例如研究有限温度、保留反向支持的整代曲率能量，或不依赖收益符号的
总查询步幅预算；两者都必须另立问题、先给出分布语义和退化性质，不能直接把本次
输出上的连续缩放当成可生成的离散算法。
