# 残差驱动的正向扩散算子

## 1. 研究问题与路线边界

现有流程已经用记录适应度和距离抽取 donor，但实际更新会随机复制 donor 的多个
属性块。完整 donor 的方向与实际 hybrid 编辑的方向并不总是一致；之后再用
donor/recipient 支配关系压低部分复制虽然能减少有害提案，却属于额外定向筛选，
不能证明扩散算子本身变得更好。

本设计研究一个更严格的问题：

> 能否让扩散转移概率本身在查询残差场中产生正向漂移，同时让反向与中性转移在
> 有限温度下继续具有非零概率？

第一阶段固定仓库原始无噪声配置，只改变块复制算子。schema、记录数、workload、
精确 target、1-way marginal 初始化、donor 抽样、种子和计算预算保持不变。真实
train/test 只用于生成完成后的离线评价；当前实验不是端到端 DP。

## 2. 从 donor 适应度改为实际局部转移方向

记比例残差为 `epsilon`，查询权重为 `w`，记录 `x` 的查询贡献向量为 `a(x)`。
固定本轮旧残差场，定义记录的方向势能：

\[
\phi_t(x)=\sum_j w_j\epsilon_{t,j}a_j(x).
\]

对 recipient `x` 的属性块 `g`，把它改成 donor `z` 的对应值，得到实际单块
hybrid 状态 `x^{g<-z_g}`。局部方向量为：

\[
d_{t,g}(x,z)
=\phi_t(x^{g\leftarrow z_g})-\phi_t(x)
=\sum_j w_j\epsilon_{t,j}
\left[a_j(x^{g\leftarrow z_g})-a_j(x)\right].
\]

它评价 recipient 条件下真正可能发生的单块编辑，而不是用 `F(z)-F(x)` 代理完整
donor 替换。只包含属性块 `g` 的查询可能改变，因此实现按属性收集相关查询，避免
计算无关贡献。

所有记录和属性块使用同一份 `S_t` 残差，生成阶段不读取真实表或离线指标。

## 3. 连续倾斜 Bernoulli 扩散核

历史算子以固定概率 `eta` 复制每个不同的 donor 块。新候选不增加
`direction > 0` 资格条件，而是在 baseline Bernoulli 的对数几率上连续倾斜。
原始尺度形式为：

\[
\operatorname{logit} p_{t,g}(x,z)
=\operatorname{logit}\eta_t+\beta_d d_{t,g}(x,z).
\]

其中 `beta_d` 是有效方向强度。直接使用原始方向量时：

- `beta_d=0`：逐项精确退化到历史固定 `eta`；
- `d=0`：复制概率精确等于 `eta`；
- `d>0`：复制概率连续升高；
- `d<0`：复制概率连续降低，但不会被硬置零；
- `eta=0/1`：保持历史端点语义。

不同 workload 的查询数、重叠程度和残差分布会改变 `d` 的绝对尺度。固定
`beta_d` 在小表上可能几乎等于 0.5 随机复制，在大 workload 上却可能接近硬门控。
推荐模式因此用首个非零方向矩阵中、所有实际不同块的 RMS 固定定标：

\[
s_0=\sqrt{\operatorname{mean}(d_{0,g}^2)},\qquad
\operatorname{logit}p=\operatorname{logit}\eta+\tau\frac{d_{t,g}}{s_0}.
\]

此时配置项 `diffusion_direction_strength` 表示无量纲初始温度 `tau`。`s_0` 一经
确定便不再逐轮更新：这样只消除 workload 的初始量纲差异，随着残差收缩，实际
logit 倾斜也自然冷却；不会把接近零的晚期方向每轮重新放大。若首轮所有方向均为
零，则等到首次出现非零方向时再固定尺度；在此之前保持历史 `eta`。

`normalization="none"` 保留为原始尺度消融。RMS 只由合成状态、donor 和已发布
统计量的残差计算，不读取真实 train/test；未来若 target 已经 DP 发布，它仍属于
后处理。

实现把数值 logit 截断到 `[-30, 30]`，避免有限输入在 float64 下变成精确 0 或 1。
复制仍使用历史每属性一个 `Uniform(0,1)` 随机数；方向计算不消耗 RNG。因此
`beta_d=0` 不仅分布相同，而且最终表、决策轨迹和后续随机流都应精确相同。

这是一种“改变随机转移分布”的算子，不是“先产生编辑再挑正收益编辑”的
逐候选优化。有限强度下反向传播仍真实发生，而不是只在文字上保留。

### 3.1 熵正则化解释

对某一个固定单块转移，令历史复制核为 `Bernoulli(eta)`。把定标后的方向
`d/s_0` 仍记作 `d`，新概率是以下问题的
唯一闭式最优解（`beta_d>0`；零强度取连续极限）：

\[
p^*=\arg\max_{0\le p\le1}
\left\{p d-\frac{1}{\beta_d}
\operatorname{KL}\bigl(\mathrm{Ber}(p)\,\|\,\mathrm{Ber}(\eta)\bigr)
\right\}.
\]

一阶条件给出
`logit(p*) = logit(eta) + beta_d d`。第一项偏好残差场中的正方向，KL 项约束新核
不要离历史扩散核过远。因此 `beta_d` 控制的是方向收益和随机扩散熵之间的权衡，
不是候选是否有资格发生的阈值。

### 3.2 零强度附近的局部正向漂移

忽略多块合取交互和二次步幅项时，一个单块的归一化期望一阶方向贡献为
`p(beta_d) d`。在历史核 `beta_d=0` 处：

\[
\left.\frac{\partial\,[p(\beta_d)d]}{\partial\beta_d}\right|_{0}
=\eta(1-\eta)d^2\ge0.
\]

因此，对固定状态和 donor，把强度从零轻微增大不会降低单块一阶期望漂移；只要
存在非零方向，严格增加。这个结论解释的是局部转移核，不等价于保证整代精确
loss 单调：多个块同时变化会产生合取交互，有限步长还有二次惩罚，变异也保持
无方向。是否改善完整原始 proposal 仍必须由接受检查前的实验验证。

## 4. 与 QDTE 式定向编辑的区分

本候选明确不做以下操作：

- 不按单编辑精确 loss 收益设置 `>0` 门槛；
- 不按收益执行 argmax、top-k 或非冲突候选选择；
- 不把反向编辑概率设置为零；
- 不用离线 train/test 指标选择转移或 checkpoint。

方向量只是倾斜每条记录的随机扩散概率。所有记录仍基于同一旧残差同步形成整代
proposal。现有整代 loss 检查暂时保留为共同安全护栏，但不能作为候选有效性的主要
证据。

## 5. 主验收指标必须位于整代接受之前

对原始 proposal 记：

\[
\Delta q=q(S_{proposal})-q(S_t),\qquad r=y-q(S_t).
\]

无噪平方损失的精确整代收益为：

\[
L(S_t)-L(S_{proposal})
=r^T\Delta q-\frac12\lVert\Delta q\rVert_2^2.
\]

每次尝试记录：

- 原始 proposal 精确收益；
- 一阶对齐量 `r^T delta_q`；
- 二次步幅项；
- 原始 proposal 正收益比例；
- 局部方向量正/负比例和均值；
- active Bernoulli 复制核的平均熵（自然对数，最大值为 `ln 2`）；
- 接受率、实际改动规模与运行成本。

第一项主假设是：在相同状态、种子和提案预算下，新算子的原始 proposal 平均收益
与正收益比例应优于 baseline。如果只有接受后的 best loss 改善，而原始 proposal
没有改善，则收益仍不能归因于扩散核。

## 6. 当前实现限制

当前方向量评价每个块相对旧 recipient 的单块变化。一次更新可能复制多个块，因此
包含多个属性的合取查询存在组合交互：各单块方向之和不一定等于最终 hybrid 的完整
方向。这是有意保留的第一版边界，优点是列顺序不影响方向分数、`beta_d=0` 可严格
对拍；缺点是不能直接建模“两个单块各自中性、合起来有益”的协同变化。

当前实现还会在抽参与掩码之前计算全部 `N×A` 个方向，虽然最终只有约 `rho*N`
条记录真正参与。这样做保持了历史 RNG 顺序，并让同轮重试可复用一份方向矩阵，
但在小表上方向计算会成为主要开销。后续可单独研究“先消费同一份参与随机数，再
只评价参与行”的惰性路径；必须同时覆盖多次重试、诊断口径和 `strength=0` 后续
随机流等价，不能在本方法 PR 中顺手混入未经对拍的性能重构。

若第一版原始 proposal 证据不足，后续候选应优先研究联合块转移或分步局部扩散，
而不是回到支配门控或用精确候选收益筛选。任何联合版本都需重新检查列顺序、随机
流、计算复杂度和与逐候选优化的边界。

## 7. 实验顺序

1. 单元测试：手算方向量、recipient 条件交互、中性端点、反向支持和异常输入；
2. 默认关闭与 `beta_d=0` 的表、轨迹和 RNG 精确对拍；
3. 小表多强度配对扫描，主看接受前原始 proposal；
4. 若主指标通过，再固定训练侧指标和候选强度做小表多种子正式实验；
5. 只有小表机制证据稳定后才运行 nltcs，并报告高阶、TVD、支持集和成本；
6. 最后增加关闭或弱化整代贪心检查的独立实验，验证演化动力是否主要来自算子。

关联 Issue #6。Draft PR #5 只作为方向失配诊断和定向筛选正对照，不与本实现混入
同一个 PR。

## 8. 已验证结果（2026-08-01）

### 8.1 固定实验口径

正式 baseline 是方向机制关闭时的仓库原始无噪声生成器：`marginal` 初始化、精确
`measured_1000query` target、geometric donor 抽样、`alpha=2→10`、`rho=0.01`、
`eta=0.5`、`mu=0.01`、无重试、1500 轮。candidate 只启用本算子，使用
`normalization="initial_rms"` 和无量纲温度 `tau=1`；其余输入、种子和轮数不变。

`tau=1` 先在不读取 train/test 的小表训练侧冒烟中固定。nltcs 测试 TVD 只在全部
生成结束后离线计算，不反馈给生成、强度选择、早停或 checkpoint。由于同一测试集
此前已经被多个方法分析查看，以下测试 TVD 只能作为反复观察过的离线指标，不能
包装成完全未触碰的最终测试。

### 8.2 失败消融：原始固定强度不能跨 workload

原始尺度 `normalization="none", strength=1` 在小表关闭整代接受的 1000 轮、10 个
配对种子中，只把最终当前 loss 从 `335.95` 降到 `321.90`：6 胜 4 负，配对
`p=0.720`，没有稳定效应。相同强度下小表的正/负复制概率约为 `50.4%/49.6%`，
几乎没有倾斜；nltcs 却约为 `55.3%/43.7%`。这不是“方向量无效”，而是其绝对
尺度依赖 workload。

首轮 active direction RMS 在小表约 `0.0456`，在 nltcs 约 `1.4563`，相差约 32 倍。
因此保留原始尺度作为消融，但正式候选采用首轮 RMS 固定定标。失败输出保留在：

- `outputs/residual_directed_diffusion_small/unfiltered_strength1_1000r_10seed_189a744.json`
- `outputs/residual_directed_diffusion_small/formal_strength1_500r_10seed_fe11966.json`

### 8.3 冻结同一状态的算子因果证据

冻结状态探针固定当前表、残差、donor 和参与/复制/变异随机数，不执行整代接受；
每个 proposal 只改变复制核。它避免把 candidate 到达更低 loss 后“提案自然更难”
误解为算子变差。

小表在 3 个种子的初始状态和第 100 轮 baseline 状态上各抽 200 个 proposal，合计
1200 对：

| 指标 | baseline | `initial_rms, tau=1` |
|------|---------:|---------------------:|
| 原始 proposal 平均收益 | 5.36 | **27.88** |
| 原始 proposal 正收益率 | 54.75% | **80.50%** |
| 相对 baseline 的逐提案收益 | — | **888 胜 / 238 平 / 74 负** |
| 负方向块实际复制概率 | 50% | **30.97%** |
| 平均复制核熵 | 0.6931 nat | **0.6084 nat（最大熵的 87.78%）** |

nltcs 使用 3 个历史 baseline 1500 轮成品状态，每个状态抽 100 个 proposal，合计
300 对：

| 指标 | baseline | `initial_rms, tau=1` |
|------|---------:|---------------------:|
| 原始 proposal 平均收益 | 20,743.86 | **136,670.29** |
| 原始 proposal 正收益率 | 75.67% | **100.00%** |
| 相对 baseline 的逐提案收益 | — | **300 胜 / 0 平 / 0 负** |
| 负方向块实际复制概率 | 50% | **33.28%** |
| 平均复制核熵 | 0.6931 nat | **0.6063 nat（最大熵的 87.47%）** |

负方向的复制概率约 31%–33%，并非只在浮点下形式上非零。结果说明新核在同一状态
和共同随机流下直接改善原始转移，同时仍保留实际反向传播；约 87.5% 的最大
Bernoulli 熵也说明它没有退化成近确定性门控。输出：

- `outputs/residual_directed_diffusion_small/frozen_initial_rms_tau1_200p_3seed_2200e37.json`
- `outputs/residual_directed_nltcs_frozen_initial_rms_seed{0,1,2}_100p_2200e37.json`

### 8.4 关闭整代接受后的动力学证据

小表 1000 轮、10 个配对种子中，每个原始 proposal 都无条件成为下一状态，不使用
loss 接受门控，也不回滚到 best 表。最终当前 loss 从 `335.95` 降到 `155.95`
（下降 53.58%，10/10 胜，配对 `p=1.59e-4`）；每轮平均原始收益从 `1.818`
升到 `1.998`，同样 10/10 胜。正收益事件比例从 49.96% 到 50.55%，变化不显著，
说明主要收益来自正向步幅增大、负向步幅减小，而不是简单增加“赢的次数”。

这个实验只关闭了整代接受筛选；donor 仍由原算法的适应度与距离抽取。因此它证明
下降动力不依赖 generation loss gate，但不声称脱离原 donor 机制后仍会下降。输出：
`outputs/residual_directed_diffusion_small/unfiltered_initial_rms_tau1_1000r_10seed_9496f89.json`。

率和缓存复用平均执行 `1226.3` 次，另固定执行 `1500` 次方向评价。因此 candidate

三种子 p 值仅作探索性方向证据，不能宣称跨数据集普遍最优。candidate 的唯一状态

### 8.6 等价性与结论边界

- 方向机制默认关闭；三枚 nltcs baseline 成品与历史成品 CSV SHA-256 逐种子完全
  相同，loss、接受、donor fitness、重试和质量轨迹相同。donor 距离诊断最大差
  `2.98e-8`，不参与决策。
- `strength=0` 在原始尺度和 RMS 尺度下都与关闭机制的最终表、决策轨迹和 RNG
  端点精确一致。
- 增加熵诊断前后，小表 baseline、`strength=0` 和 candidate 的 10 个正式成品
  哈希及 loss 逐种子完全相同；nltcs candidate seed 2 的完整成品和共享轨迹也
  完全相同。熵只做报告，不进入采样或接受决策。
- 当前完整 CPU/torch/CUDA 测试为 `343 passed`；qdte 环境的主循环定向测试为
  `25 passed, 1 skipped`。
- 当前结果支持“熵正则连续倾斜使扩散核产生正向漂移”，但尚未建模多块合取协同，
  也没有证明遍历性、全局最优或跨数据集通用性。
- 当前仍是精确 target 的无噪声原型，不是 DP。没有 ε/δ、噪声、accountant 或
  私有查询选择；未来对已发布带噪统计量使用该核只属于后处理的一部分。
- 该候选尚未按相同 target、初始化信息和计算预算与独立 QDTE 方法正式对拍，不能
  声称已经达到 QDTE。PR #5 的定向筛选对照目前数值更低，但路线不同，不能用它
  替代本算子的科学问题。

### 8.7 后续温度极限研究

本节的 `tau=1` 是第一阶段为验证机制而冻结的候选，不代表温度最优或理论上限。
后续温度—KL—漂移前沿、符号极限及高温平台结果见
[扩散核的温度—熵—漂移极限](扩散核温度熵漂移极限.md)。该研究保持本设计的路线
边界：不以高温符号门控替代有实际反向概率的扩散核，也不据小表扫描直接更改默认
参数。
