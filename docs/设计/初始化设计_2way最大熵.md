# 2-way 最大熵初始化设计

## 1. 为什么做这一步

原来的 `marginal` 初始化能精确贴合每一列的 1-way 边缘，但各列独立打乱，主动
丢掉了属性间相关性。后续扩散演化虽然会根据 2-way 和部分 3-way 查询修复这些
相关性，但在 nltcs 上需要从很远的起点开始，最终也容易停在较差的平台。

新的 `pairwise_maxent` 初始化不改变后续扩散演化。它只把已经测量的 2-way 等值
查询提前用于构造一个相关起点，再让原主循环根据全部工作负载继续精修。

## 2. 隐私边界

运行时只接收：

- 公开的 schema 与记录数 `N`；
- 查询定义；
- 已测量的查询计数 `target`。

它不读取原始表，也不使用真实 16-way 联合分布或 TVD 作为训练目标。拟合与抽样
都是测量结果的后处理，因此不会在既定测量之外新增原始数据访问。

需要特别说明：仓库当前的 `target` 仍是无噪声精确计数，差分隐私机制、隐私预算
和 accountant 尚未实现。将来给各查询加 DP 噪声后，不同属性对可能互相不一致，
应先增加统一的一致性投影；当前的逐属性对截断和归一化只是安全兜底，不能替代
这一步。`converged=false` 时也不能把结果称为精确最大熵解。

## 3. 算法

### 3.1 恢复二阶边缘

只采用恰含两个 `==` 条件的查询。对属性对 `(i,j)`，收集所有类别组合的计数并
归一化为目标边缘 `M_ij`。一个边缘允许缺少一个单元，此时用公开总人数恢复：

```text
missing_count = N - sum(other_cells)
```

缺少两个及以上单元时无法唯一恢复，该属性对被跳过并写入诊断。

### 3.2 枚举有限类别状态空间

若所有属性均为类别属性，联合状态数为：

```text
K = product(number_of_categories_i)
```

当前实现只处理 `K <= maxent_max_states`；默认上限为 1,000,000。超过上限或存在
数值属性时明确报错，提示回退到 `marginal`/`random`，不会静默做不可审计的近似。

### 3.3 IPF 最大熵拟合

从联合状态上的均匀分布开始，依次把当前二阶边缘校正到目标边缘：

```text
p_new(x) = p_old(x) * M_ij(x_i, x_j) / p_old_ij(x_i, x_j)
```

反复扫描全部可用属性对，直到所有二阶单元的最大概率误差不超过
`maxent_tol`，或达到 `maxent_max_sweeps`。在测量一致且算法收敛时，这得到满足
约束的最大熵联合分布；它只加入测量能够支持的相关性，不凭空猜测更高阶结构。

### 3.4 抽样并继续扩散演化

用同一个可复现 RNG 从拟合分布抽取 `N` 条记录，得到 `S_0`。抽样会重新引入约
`O(1/sqrt(N))` 的有限样本误差，因此诊断同时区分：

- `max_pair_error`：拟合分布本身相对二阶目标的最大误差；
- `sampled_max_pair_error`：实际抽样表相对二阶目标的最大误差。

随后原来的残差、适应度、donor 抽样、扩散更新和整代接受检查全部保持不变。

## 4. 使用方式

在 `scripts/run.py` 中设置：

```python
INIT_METHOD = "pairwise_maxent"
```

nltcs 的 16 个二值属性共有 `2^16 = 65,536` 个状态，低于默认上限。当前查询文件
提供 120 对属性边缘的 479/480 个单元，唯一缺失单元可由 `N` 恢复。

## 5. 正式三种子实验（2026-07-31）

以下指标中的 TVD 只用于离线评价，未进入训练：

| 方法 | 预算 | loss | 训练查询 L1 | 训练联合 TVD | 测试联合 TVD |
|---|---:|---:|---:|---:|---:|
| 原 `marginal` | 1500 轮，3 种子 | 7,209,582 ± 436,119 | 0.005349 ± 0.000199 | 0.3147 ± 0.0042 | 0.3957 ± 0.0022 |
| `pairwise_maxent` | 600 轮，3 种子 | 464,081 ± 74,341 | 0.001398 ± 0.000090 | 0.2352 ± 0.0053 | 0.3261 ± 0.0055 |

同种子配对比较中，新方法 3/3 胜出：

- loss 降低 93.56%，配对 t 检验 `p=0.00134`；
- 训练查询 L1 降低 73.86%，`p=0.00097`；
- 训练联合 TVD 降低 25.24%，`p=0.00292`；
- 独立测试联合 TVD 降低 17.58%，`p=0.00267`；
- 未参与训练的 3-way L1 降低 70.24%，全部 4-way L1 降低 62.18%；
- 漏掉的真实模式质量从 0.1085 降到 0.0982，生成的新模式质量从 0.1536 降到
  0.1009。

候选只用了 600 轮而基线用了 1500 轮，因此质量比较对候选更严格；总耗时降低主要
来自轮数减少，不能解释成单轮代码加速。新起点已经很接近目标，整代接受率也从旧
基线的 96.6% 降到 3.7%，说明后续若继续优化，应单独研究更小的更新尺度。

基于这组结果，`scripts/run.py` 的 nltcs 推荐配置改为
`INIT_METHOD='pairwise_maxent'`、`N_ROUNDS=600`；`run_evolution` 的通用 API 默认值
仍是 `random`，旧的 `marginal` 路径也完整保留。

## 6. 如何解释 TVD

nltcs 的训练集与独立测试集之间，经验 16-way TVD 本身约为 0.2834，因此有限
样本下不能期待合成表对训练集的经验联合 TVD 接近 0。旧成品约 0.315 并非完全
失效，但相对这个采样参照仍有明显结构误差。

`pairwise_maxent` 初始表的训练 TVD 低于训练—测试 TVD，不代表它“超过真实数据”
或保证泛化；最大熵平滑会让它更接近训练经验分布，而独立测试 TVD 仍是约 0.319。
评价时应同时报告训练查询误差、独立测试统计、联合 TVD 和支持集质量，不能只优化
某一个离线指标。

## 7. 当前限制与后续工作

- 只支持可枚举的全类别数据；混合数值表继续使用原初始化。
- 复杂度约与“状态数 × 可用属性对 × IPF 扫描数”成正比。
- DP 噪声下需要正式的一致性投影与隐私预算实验。
- 不能直接用真实联合 TVD 选择每轮更新，否则会越过既定测量边界。
- 新起点下原参数的接受率仅约 3.7%；更新尺度与接受机制应作为后续独立实验。
