# 纤维第二阶段：有限表合同与连通性

关联 #92。用户已确认**固定第一段完整测量字段集合边缘与全部一阶的可选硬后处理**，
保留原软正则作独立对照，不切换默认。实现基线为
`41317d7f75b4f584b19162ccaa49de87b1e92440`。
第1–9节保留设计阶段的小域热浴参考与边界，第10节是本次不同的对称交换实现；
不能把旧热浴轨迹直接当成新核的验收，也不作新的质量或DP结论。

## 1. 先拆开三个问题

当前链路是：

```text
第一段合成表 T1
  -> 保边际的受限列洗牌
  -> 未测二阶计数的链上平均
  -> 将平均值变成伪目标
  -> 从 T1 热启动另一轮平方损失优化
```

这条链路混合了不同任务：洗牌是否合法、链能否走遍目标集合、伪目标如何影响最终表。
不能由第一步保持边际，推出最后的优化结果也保持边际。

`fiber.py` 的列洗牌按所有测过邻居取值分组，因此保住测过字段集合的完整边缘。
`run_plants.py::lock_real_targets` 只是把原查询目标换成 `q(T1)`，
随后仍做软平方惩罚。有限惩罚权重不是约束；合卷损失下降时，原测量损失仍可能上升。
之前CPU/GPU小进程的 `0.25 -> 2.25` 反例仍适用，见
`outputs/stopping_fiber_audit_20261029/`；本轮没有把它当作新的真实数据效果实验。

因此须分别选择：

| 问题 | 必须明确的含义 |
|---|---|
| 保什么 | 实际已测格子，还是题面字段集合的全部边缘；是否额外固定所有一阶 |
| 在可行集合中做什么 | 采样、优化整数表熵、或拟合一组伪目标 |
| 最后交什么 | 预算终点的合法表，还是另行软拟合的表；平均计数未必能由一张有限表实现 |

本轮已确认先做**不放宽现有约束的硬后处理采样**，保留软正则作独立对照；
该功能显式开启，不代表默认算法或真实数据方法优劣已经切换。

## 2. 状态空间与硬锚点

公开域为 `Omega = D1 x ... x Dd`，公开行数为 `N`。
用非负整数直方图 `n_s` 表示合成表，`sum_s n_s=N`。
任意预先定义的计数查询可写作 `A_Q n`。

若选择严格保持第一段的已测答案：

```text
m_Q = A_Q n(T1)
F_Q(m_Q) = {n in Z_+^|Omega| : sum n=N, A_Q n=m_Q}
```

锚点是**第一段合成计数**，不是原始训练表，也不是直接把带噪目标 `y` 当作整数等式。
`T1` 本身保证该集合非空；`y` 可能含小数、负数或互相矛盾的边缘，不能自动具有这个性质。
硬固定 `A_Q n=m_Q` 后，对任意固定 `y,W`，原查询的平方损失与第一段精确相同；
它也不会修复第一段已经存在的测量误差或过拟合。

### 当前实现实际固定得更多

`measured_sets` 从等值题提取字段集合，不检查该集合的所有格子是否都已测量。
洗牌保住这些集合的**完整**边缘，并通过排列额外保住每一列的一阶计数。
令 `C` 为这些集合及全部单字段集合，当前比较合同是：

```text
m_C = M_C n(T1)
F_C(m_C) = {n in Z_+^|Omega| : sum n=N, M_C n=m_C}
F_C(m_C) is a subset of F_Q(m_Q)
```

该包含关系可能严格。例如三值两字段，只测 `(a=0,b=0)`：

```text
T1 = {00,11,22}
T2 = {00,12,21}
```

两表的一阶和已测格子都相同，但完整 `(a,b)` 边缘不同。
当前实现不能从T1到T2。换成 `F_Q` 会改变状态空间，不能冒充“只改善混合”的等价修改。
**本轮同合同的移动对照全部固定 `F_C`，没有靠放宽约束解冻。**

还须区分“没有二阶题”与“二阶统计未确定”：完整三阶边缘已经确定其三个二阶投影，
而当前 `unmeasured_pairs` 只判断二元集合是否显式出现。
小控制证实这些已被高阶边缘确定的对仍可能出现在列表中；后续设计应按约束闭包解释，
而不是把它们当成新信息。非等值查询当前由 `measured_sets` 明确拒绝。

## 3. 均匀表、均匀直方图和最大熵不是一回事

### 与当前排列操作相容的候选采样目标

先定义有行位置的可行表集合：

```text
T_C = {T in Omega^N : M_C n(T)=m_C}
P(T | m_C) = 1 / |T_C|
```

直方图 `n` 对应 `N! / product_s(n_s!)` 个有序表。因此其诱导分布是：

```text
pi(n | m_C) proportional to N! / product_s(n_s!), n in F_C
```

它不是“每张不同直方图等概率”。若引入非均匀的公开参考分布，还需相应参考质量因子，
不能继续无条件使用这个公式。本轮没有引入这种新先验。

在理想均匀排列模型下，当前组内列排列保住上述测度，但可能只在起点所在连通分量内活动。
平稳测度正确不等于不可约，更不等于预定100趟已经混合。
随机键排序和有限随机数实现另有表示边界，本稿的精确矩阵是理想计数／排列核的验证，
不是任意规模浮点随机数的精确性认证。

### 一个可完全核对的有限表例子

三字段二值链，测 `(a,b)`、`(b,c)`，每个二阶格子计数都是2，`N=8`。
整个纤维只有9个直方图，合计90720个有序表：

- 全部8个联合格子各放1行的直方图，按上述目标的概率是 **4/9**；
- 若误用均匀直方图，它的概率只是 **1/9**；
- 连续最大熵分布是8个联合状态各 `1/8`，不是这个9状态的有限表分布；
- 从该连续分布独立抽8行，恰好满足这些硬边缘的概率仅
  `90720 / 8^8 = 0.0054073333740234375`。

本轮以有理数计算了当前完整一趟列洗牌、四行条件更新的两张 `9 x 9` 转移矩阵：
行和、目标平稳性、细致平衡均精确成立；两链均连通且各状态有正自环。
均匀直方图则不是这些核的平稳分布。

连续最大熵另解：

```text
maximize H(p) = -sum_s p_s log p_s
subject to p>=0, sum p=1, M_C p=m_C/N
```

它与有限表采样、最大化 `H(n/N)`、最大化组合重数都是不同的任务。
不能把有限表采样说成每一步提高熵，也不能以伪目标平均替代可行整数表。
另一个控制中，三二值字段的完整二阶、`N=4`纤维有偶／奇校验两张直方图；
其联合平均计数各为 `1/2`，不是一张合法的4行表。
当前“完整二阶没有伪二阶题、跳过第二段”仍是既有正确行为，不据此自动新增高阶阶段。

## 4. 冻结需要多大的一步

这里“度数”指一次删除并替换的行数，即直方图变化的 `L1/2`，
不是修改的字段数，也不是非零单元格总数。

### 二值四环：完整小空间而非挑选种子

枚举16个联合状态构成的所有4行直方图，共 **3876** 张，按四条边的完整边缘分成
**2809** 个纤维，其中 **777** 个不是单点：

| 可用移动 | 不连通纤维数 |
|---|---:|
| 当前邻居条件单列排列的支撑 | 8 |
| 任意不超过2行的合法替换 | 8 |
| 任意不超过3行的合法替换 | 8 |
| 任意不超过4行的合法替换 | 0 |

最后一行只针对这个完整枚举的 `N=4` 小空间，不是任意类别、约束或行数的普遍证明。
数学背景见文末的二值图模型Markov基文献，也不能把二值环的结论直接推广到三值情形。

### 三值13行：原反例最小非平凡移动为4行

字段顺序 `(a,b,c,d)`，测量边为 `ab,bc,cd,ad`。
起点由 `((b+d) mod 3,b,(b+2d) mod 3,d)` 的9个模式组成，
`0000`重复5次、其余各一次。
每个字段在每个邻居上下文内只有一种取值，所以当前列洗牌对任何种子、任意趟数都不动。

从该起点穷举所有可删除子多重集及所有替换多重集：

| 替换行数 | 可删除子多重集 | 全域替换多重集 | 非平凡合法替换 |
|---|---:|---:|---:|
| 1 | 9 | 81 | 0 |
| 2 | 37 | 3321 | 0 |
| 3 | 93 | 91881 | 0 |
| 4 | 163 | 1929501 | 36 |

共核对 **2024784** 个全域替换候选；小于4行的链连第一步也走不出去。
一个四行见证为：

```text
删除：0000  0211  1110  2101
加入：0001  0210  1100  2111
```

其余9行不动，全部一阶及四条已测边的每个格子精确保持，未测对发生变化。
36个结果又由不同的列排列枚举算法交叉核对，并用生产查询求值器重数。
**这证明该起点不是单点纤维，且最小解冻块为4；没有枚举整个三值13行纤维，
不证明四行移动连接其中所有状态。**

## 5. 设计阶段的小域热浴参考：不是本次交换实现

对固定块大小 `r`：

1. 从N个有标签的行位置中均匀选择r个不同位置，选择不依赖当前值或评价分数。
2. 固定块外行，对块内枚举所有保住同一 `M_C` 计数的候选直方图 `b'`。
3. 以 `r! / product_s(b'_s!)` 为整数权重选择直方图，再均匀排列其r行落回这些位置。
4. 只返回当前表；不按真实质量筛选、回退或挑最好快照。

这是目标有序表分布在固定块外状态下的Gibbs条件更新，因而保持该目标并满足细致平衡。
选择块的位置分布若改成状态依赖，或在不同候选直方图之间直接等概率选择，
都不能沿用这个证明；需要重算转移比或重新定义目标。
所有预定观察时点都计入平均，包括自环，不能只记录发生移动的状态。

局部原型通过固定首列顺序枚举直方图代表，去重后恢复组合重数并随机排列；
固定首列只用于搜索，不是给某些有序结果特殊权重。
缓存键包括全部块约束，连同显式保留的一阶，不能只用块大小或局部ID复用。
对二值三字段的全部330个四行直方图，条件候选池与独立完整枚举逐项相同。

本轮程序只支持至多4字段、每字段至多3值、块至多4行。
其他列的排列枚举最坏随 `(r!)^(d-1)` 增长，**不是宽表生产实现**。
尚未覆盖额外联合合法性规则或结构零；它们会改变状态空间与连通性，不能沿用当前证明。
现有主核在只有已测目标且 `A_Q Delta n=0` 时没有正残差收益，
不能把这个后处理采样器伪装成原残差下降核的普通性能重构。

### 一个可扩展的设计方向，尚未实现

可研究固定分布的原子双交换：公开固定地选择字段组合及4个不同的行位置，
在前两行交换字段u、后两行交换字段v（允许u=v），把两个交换视为一个动作。
只有完整动作的约束增量为零才产生转移，否则留在原状态。

该动作是自身的逆；选择概率与状态无关时，合法性在正反方向一致，可构造对称有序表核。
这里拒绝的是离开预先定义可行集合的动作，不是用真实数据或损失选优。
若为提速改成从“当前合法配对列表”均匀抽取，列表大小可能随状态变化，
必须重新证明可逆性；不能删掉自环后仍声称目标不变。
它是否具有足够支撑、实际接受率及宽表成本，都需要新的协议和验证。

现有 `NullSwapPhase` 不能直接充当该目标的实现：它保全部一／二阶，
并按辛普森集中度单向选择，和本稿的条件均匀采样不是同一个目标。
仅仅“都是四行”不构成等价或连通性证明。

## 8. 路线确认与后续边界

| 路线 | 获得的性质 | 代价与尚未解决的问题 |
|---|---|---|
| 硬后处理采样 | 第一段指定统计逐格不变；目标分布可明确定义 | 可能保住第一段误差／人工结构；大纤维连通性、混合和可扩展候选仍需验证 |
| 现有软正则 | 允许在已测与伪目标之间折中，复用现有演化核 | 不保证原统计／原损失不变；须单列漂移诊断与允许范围，伪sigma只是权重 |
| 改成只锁实际已测格子 | 解除当前额外固定的部分统计 | 同时改变状态空间，必须与只换移动核分开实验，不能偷称等价 |

本轮用户已经确认第一条路线，并保持**现有完整边缘加一阶约束**，
避免同时改变状态空间与转移核；软正则保留为另一路对照，默认路径继续不动。
本次实现只交付固定预算终点，另行核验实际交换核及不可移动状态的报告，
不沿用旧热浴的实际轨迹或成本。不自动开展真实数据或大规模质量比较。

最后，保持统计和采样正确都不保证未测真实关系变好。
若L1／L2监控也只看这些已锁定查询，第二段没有新的查询计数变化，
不能用“未报警”证明未测关系良好；软路线也不能自动继承第一阶段监控的独立性或停法合同。
仅当输入合成表及上游发布已满足完整DP机制时，这类只用公开参数和合成统计的后处理
才可沿用相应隐私保证；当前仓库仍不是端到端DP。

## 10. 本次实现：惰性单次／四行原子交换

实现位于 `src/resevo/hard_fiber.py`，公开入口为
`hard_fiber_sample(X, doms, sets, steps, rng)`。
X是第一段合成表的整数域编码，不是原始训练／测试表；输入不被修改，返回独立终点副本。
指定集合去重并补齐所有一阶，空集合由N守恒处理。
域大小、索引和更新数须为合法整数；非法输入在消耗随机流之前拒绝。
整数元组的稀疏多重集比较不分配 `product(doms)` 大小的数组。

### 概率与支撑

对 `N>=4`，一步核为：

```text
P = (1/2) I + (1/4) P_single + (1/4) P_paired
```

`P_single`均匀选择两个不同的行位置和一个字段，交换这两个值。
`P_paired`均匀选择四个不同的行位置及两个独立均匀字段，分别交换前两行、后两行；
字段可以相同，两个交换作为原子动作。先比较受影响完整边缘的局部整数多重集，
不合法则保持原表，不会先应用一个违反约束的半动作。
一阶由同列排列构造性保持；返回前仍独立重数全部保持集合。

行位置／字段选择与当前值无关，每个提议是自身的逆，合法性在正反方向一致，
所以有序表转移对称，目标仍是第3节的逆阶乘直方图测度。
这里拒绝的是离开可行集合的动作，不是用损失或离线评价挑选成品。
不从随状态变化的“合法动作列表”直接均匀抽签，也不按接受率停止。

必须保留单次交换：在两字段各有4个不同值、仅固定一阶的控制中，
单纯不交双交换从恒等排列只到达Klein四元群的4个相对排列；
不能把“都是偶排列”误说成12个偶排列都可达。单次／双交换联合则到达24个。
单次合法换位也生成原邻居条件列排列的支撑，因此本次不丢掉原来的可达分量。

显式1/2保持避免小样本合法动作始终翻转时的周期性。
N=2/3时为1/2保持、1/2单次交换；N=1明确返回`no_row_pairs`、实际更新0次且不消耗rng。
0步仍校验输入、不消耗rng。其余输入始终执行给定步数，不能把零变化次数叫作全局收敛。
正自环只解决周期性，不证明全纤维不可约，更不证明有限预算已充分混合。

### 入口与输出

`python -m resevo`新增`--hard-fiber-steps`，默认0；独立种子默认`400000+seed`，
可用`--hard-fiber-seed`显式覆盖。种子覆盖须配正预算。
后处理只在第一段正常完成后执行，GPU第一段也接CPU后处理。
四条第一段随机流、其轨迹和停止规则不因此改变。
`run_plants.py`及原软纤维函数保持原样；没有新增伪目标、熵打分或第二次残差拟合。

只接受等值查询；按全部输入题面提取字段集合，不因`P2_`等题号前缀跳过约束。
常量与含字段的等值题混合时没有空边缘；只含常量的卷在现有CPU第一阶段会发生
空增量拼接异常，已在干净master复现并单列 #93。
本选项在生成前明确拒绝该入口场景，不通过跳过演化或成功回退掩盖原问题。
库级API仍支持不指定测量集合、只固定全部一阶；未启用新选项时的原行为不改。

原JSON中的`rounds`、`stop_reason`、`backend`及采样精度仍描述第一段。
开启时另外增加`hard_fiber`对象，记录CPU后端、独立种子、保持集合和
`lazy-symmetric-exchanges-v1`核身份，明确`mixing_certified=false`。
成功输出为硬后处理预算终点；不变量复核失败会报错，不发布第一段表伪装成成功。
第一段既有数值错误仍走其原诊断出口；本次不新增完整可续跑检查点协议。

计数合同为：

```text
executed_steps = lazy_steps + single_proposals + paired_proposals
single_proposals + paired_proposals
  = rejected_constraints + identity_proposals + relabel_proposals + histogram_moves
```

`identity_proposals`没有值变化，`relabel_proposals`只改变行位置但直方图相同，
`histogram_moves`才改变表的多重集。`moved_cells`只统计实际应用的值变化，
`constraint_checks`统计提议校验的投影比较次数。N=1的实际更新数0与请求预算分别报告。
最后的`invariants_verified`只表示完整边缘核对，不代表混合、效用或隐私认证。
