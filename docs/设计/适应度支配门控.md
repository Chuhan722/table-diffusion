# 适应度支配软门控：偏置 donor 复制并保留探索

## 1. 问题、baseline 与阶段边界

当前扩散演化先按适应度和距离抽取 donor，再让每条 recipient 以相同的 `rho`
参与随机块复制。donor 被按“是否值得繁殖”打分，recipient 却均匀参与，因此较差
donor 也可能改写较好 recipient。nltcs 的十提案机制探针显示，实际 hybrid 编辑中
约 40.6%（marginal 起点）到 45.3%（1500 轮成品）会单独升高 loss；晚期负收益
平均抵消约 78.9% 的正收益。

本文的正式 baseline 固定为仓库原始无噪声配置：

- 公开 schema、公开记录数与固定 `measured_1000query.json`；
- 精确 target 与 1-way `marginal` 初始化；
- geometric donor 抽样，`alpha: 2→10`、`lambda=0.5`；
- `rho=0.01`、`eta=0.5`、`mu=0.01`、`exclude_self=True`；
- 不启用缩步重试，nltcs 固定 1500 轮、种子 0/1/2。

唯一方法变量是 donor 复制的参与率缩放。真实训练集和测试集只在全部生成结束后
用于离线评价，不进入初始化、门控、接受检查、早停或参数选择。当前 target 是精确
计数；本文不是 DP 实验，也不改变 select-measure-generate 的后续边界。

## 2. 适应度差与完整替换的一阶关系

记计数残差为 `r=y-q(S)`，记录 `x` 对全部查询的 0/1 贡献向量为 `a(x)`。若完整地
用 donor `z` 替换 recipient `x`，令 `d=a(z)-a(x)`，无噪声平方损失的精确下降量为

\[
L(S)-L(S-x+z)=r^\top d-\frac12\lVert d\rVert_2^2.
\]

当前记录适应度使用比例残差：

\[
F(v)=\frac1N r^\top(a(v)-p),
\]

其中 `p=q(S)/N`。中心项相消后有

\[
N\,[F(z)-F(x)]=r^\top[a(z)-a(x)].
\]

因此 `F(z)>F(x)` 表示完整替换的一阶项为正，但它不是实际更新必然降低 loss 的
充分条件：实现只随机复制部分属性，还存在二次步幅项和同代其他记录的共同作用。
门控只能作为方向代理，不能删除整代 loss 检查。

## 3. 为什么不保留旧的硬门控

PR 初稿使用

```text
dominance[i] = fitness[donor_idx[i]] > fitness[i]
participate[i] = Bernoulli(rho)[i] and dominance[i]
```

同一个 `participate` 同时控制 donor 复制和随机变异。这会产生两个问题：

1. 非支配或中性 pair 的复制概率严格为零，缩小了反向/中性演化的提案支持；
2. 变异也被一并关闭，在适应度相等但 residual 非零的状态中可能形成吸收状态。

一个确定性反例是：20 行全为 `a`，查询目标要求 20 行全为 `b`，运行 5 轮并设
`rho=eta=mu=1`。旧硬门控下所有 donor 与 recipient 的 fitness 相等，最终 `b`
数量仍为 0、loss 仍为 200；关闭旧门控时变异产生 13 个 `b`，loss 降至 24.5。
这不是“多跑几个种子”可以修复的方差问题，而是转移支持被实现规则删除。

即使把变异单独放开，纯硬复制门控仍排除了可能有用的反向 donor 组件。某个单行
反向编辑可以由同代更强的正向编辑补偿，使整代提案净下降；提前把它删掉可能降低
组合提案跳出局部结构的能力。因此硬复制门控只保留为 `gamma=0` 消融，不作为
唯一候选。

## 4. 软门控规则与端点语义

对第 `i` 行定义

\[
D_i=\mathbf 1[F(z_i)>F(x_i)],\qquad
s_i=D_i+(1-D_i)\gamma,
\]

其中 `gamma` 是 `fitness_dominance_exploration_rate`，与 DP 隐私预算 ε 无关。
每次提案只抽一个基础参与随机数 `u_i~Uniform(0,1)`：

\[
M_i=\mathbf 1[u_i<\rho],\qquad
C_i=\mathbf 1[u_i<\rho s_i].
\]

- donor 块复制使用 `C_i`，并继续叠加原有 `eta` 与 donor 是否不同的条件；
- 随机变异使用完整的 `M_i`，再叠加原有 `mu`，不受适应度门控限制；
- 因为 `s_i<=1`，复制参与行始终是基础参与行的子集；
- 使用同一个 `u_i`，不同 `gamma` 不增加随机数消耗，便于同随机流端点对拍。

三个端点的含义是：

- `gamma=0`：非支配 pair 不复制 donor，但变异仍可发生；
- `0<gamma<1`：非支配 pair 以 `rho*gamma` 的概率参与复制；
- `gamma=1`：复制与变异逐项退化到未启用门控的 baseline。

`fitness_dominance_gate=False` 仍是默认值，历史算法不变。启用门控时默认
`gamma=0.02`，它是保留非零复制支持的保守起点，不是已证明的通用最优参数。
同一轮缩步重试复用 donor 和 `s`，但遵循既有重试语义，每次尝试重新抽参与、复制
和变异随机数。

软门控只恢复逐行反向/中性组件进入“净下降整代提案”的可能性。最终接受规则仍是
`loss(proposal) <= loss(current) + tol`，所以算法不能接受净上坡的一整代，也没有
建立全状态空间遍历性或跨越任意 loss 势垒的保证。

## 5. 自动测试、随机流与兼容性

核心实现对应提交 `3043aca`。合入前验证包括：

- `copy_participation_scale` 的形状、数值类型、有限性和 `[0,1]` 边界；
- `gamma=0` 禁止非支配复制但不禁止变异；
- 分数缩放使用同一个基础参与随机数，改变缩放不改变随机数消耗量；
- `gamma=1` 的最终表与全部决策诊断精确等于 gate-off；
- 缩步重试复用同一缩放向量；
- 零轮、初始即收敛和空诊断历史；
- 旧吸收状态可通过独立变异通道逃出。

针对性测试为 `65 passed, 1 skipped`，完整 CPU/torch/CUDA 测试为
`308 passed`。另在最新 `origin/master=df99bfa` 的独立 worktree 做 6 组默认关闭
跨版本回归，覆盖 geometric 两种子、缩步重试、linear、legacy 和允许自身；最终
CSV 与全部共享决策轨迹逐项相同。

`gamma=1` 还在 nltcs seed 0、1500 轮做了正式 CUDA 端点回归。它与历史 baseline
CSV 的 SHA-256 均为
`36643dcdae52e79a7f3c60e783237b4b2012a2a9f1329ad5631dfd0e8a3f4999`；loss、接受、
重试、donor fitness、自身率和 alpha 轨迹精确相同。GPU donor 距离诊断最大差
`2.98e-8`，来自既有性能修复的归约顺序，不参与算法决策。

## 6. 小表配对筛选与复制量控制

`test_300x10` 使用 1000 轮、20 个配对种子，除 `gamma` 外配置完全相同：

| 配置 | best loss（均值±std） | 相对 baseline | 胜/平/负 | 配对 p |
|------|-----------------------:|--------------:|---------:|-------:|
| baseline | 33.725 ± 9.603 | — | — | — |
| `gamma=0` | 22.650 ± 6.190 | -32.84% | 16/0/4 | 0.000808 |
| `gamma=0.02` | **22.175 ± 7.664** | **-34.25%** | 18/0/2 | 0.000014 |
| `gamma=0.1` | 23.600 ± 5.979 | -30.02% | 17/1/2 | 0.000127 |
| `gamma=1` | 33.725 ± 9.603 | 0.00% | 0/20/0 | 完全相同 |
| 匹配复制量控制 | 44.700 ± 12.117 | +32.54% | 6/0/14 | 0.00559 |

`gamma=0.02` 的平均复制参与率缩放为 0.721237。匹配控制关闭门控、保持 `rho` 和
变异不变，只把 `eta` 从 0.5 调为 0.360618，近似匹配期望 donor 块复制量。候选
相对该控制 loss 低 50.39%，19/0/1，配对 `p=2.55e-6`。这是“收益不只是少复制”
的机制证据；由于复制缩放与 donor 差异位置相关，该控制是近似量匹配，不是逐编辑
完全相同。

以下各列使用相同种子 0/1/2。baseline 的旧墙钟来自性能修复前，因此质量可比，

| 测试联合 TVD | 0.395718 ± 0.002226 | 0.329424 ± 0.001678 | **0.327302 ± 0.001433** | 0.331113 ± 0.003609 |

`gamma=0.02` 相对 baseline 的 loss、训练 L1、未测量 3-way/4-way、训练 TVD 和
测试 TVD 分别改善 86.61%、65.52%、64.48%、59.51%、24.05% 和 17.29%，三个种子
全部同向。但三种门控率之间没有稳定显著差异：

- `gamma=0.02` 相对 `gamma=0` 的训练 loss 高 5.04%（`p=0.532`），训练 TVD
  低 0.15%（`p=0.870`）；
- `gamma=0.02` 相对 `gamma=0.1` 的训练 loss 低 10.02%（`p=0.259`）。

这些 p 值只有三个样本且经历多项比较，只能描述本实验方向，不能作为普适定参
证据。尤其不能用反复查看的离线测试 TVD 选择 `gamma`。1500 轮最后四分之一的
loss 仍下降约 76%–80%，说明这里主要比较固定预算收敛速度，并未观察到渐近平台。

## 8. 3000 轮长时域敏感性

为检查参数排序是否随预算改变，另从同一初始配置重新运行 seed 0、3000 轮。这里
`alpha` 仍从 2 线性调到 10，因此调度被拉长；它不是 1500 轮 checkpoint 的续跑，
也不能把第 1500 轮状态与前表直接当成同一轨迹比较。

| 指标 | `gamma=0` | `gamma=0.02` | `gamma=0.1` |
|------|------------:|-----------------:|--------------:|
| best loss | 679,910.5 | **637,288.5** | 721,407.0 |
| 训练 workload L1 | 0.001540 | **0.001527** | 0.001597 |
| 未测量 3-way L1 | 0.001843 | **0.001812** | 0.001904 |
| 全部 4-way L1 | 0.001692 | **0.001643** | 0.001702 |
| 训练联合 TVD | 0.236018 | **0.231321** | 0.232928 |
| 测试联合 TVD | **0.323697** | 0.324377 | 0.325057 |
| 漏掉训练模式质量 | **0.097398** | 0.098634 | 0.099623 |
| 训练集外合成质量 | 0.114950 | **0.112107** | 0.113281 |
| 接受率 | 57.70% | 59.70% | 62.00% |
| 最后四分之一接受率 | 4.40% | 3.87% | 9.33% |
| 墙钟（RTX 4090） | 369.6s | 379.4s | 380.9s |

这个单种子结果中，`gamma=0.02` 的训练与未测量边缘指标最好，硬复制门控的测试
TVD 和漏失质量略好；`gamma=0.1` 在最后四分之一仍下降 26.9%，另外两组也仍下降
约 12.7%–13.3%。它支持“探索率与时域存在交互”，不支持某个 `gamma` 在长时域
必然最优。若要正式调参，需要预先冻结训练侧选择指标、增加数据集和种子，并保留
独立的最终测试评价。

## 9. 运行成本与剩余限制

软门控只增加长度为 `N` 的缩放向量，不改变主流程 `N×N` 距离/概率矩阵的渐近
内存。nltcs 实跑的 GPU 峰值仍约 9.9 GiB，主要瓶颈没有变化。

同版本 seed 0、1500 轮的 `gamma=1` baseline 为 260.9s，执行 1442 次状态/距离
评价；`gamma=0.02` 为 247.0s，执行 1337 次。差异主要来自接受率和缓存命中，
不是门控内核加速。3000 轮并行运行的三组墙钟相近，也不支持独立的性能收益声明。

剩余方法限制包括：

- fitness 差只代理完整 donor 替换的一阶项，不是实际 hybrid edit 的精确收益；
- 整代贪心接受仍禁止净上坡代，软门控没有解决一般局部最优；
- 变异每次最多修改一个块，虽保留探索支持，但概率较低；
- 证据只覆盖一个小表和 nltcs，正式 nltcs 只有三个种子；
- 尚未建立与独立方法 QDTE 的同 target、同初始化信息、同种子和同计算预算协议，
  不能声称已经达到或超过 QDTE；
- 当前没有噪声机制、ε/δ、accountant、私有查询选择或带噪一致性处理，
  不能称为端到端 DP。
