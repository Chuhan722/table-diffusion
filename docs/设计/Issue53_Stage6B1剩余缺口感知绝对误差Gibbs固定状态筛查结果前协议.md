## 3. 无门控边界

三组方法都必须满足：

1. 每个冻结随机地址只形成一个最终复制开关表；
2. 仅复制表和完整表都无条件保留，不按误差、B、C、G 或任何离线质量删样、补样或重抽；
3. 吉布斯内部可以比较某一个开关为 0 或 1 时的临时误差，但只能用连续软概率重抽这个开关；
4. 所有有限条件下，开关取 0 和取 1 都必须有严格正概率；
5. 完成固定微步后直接应用最终开关表一次，随后按同一随机量执行突变；
6. 生成完整候选下一表之后，不接受、拒绝、回滚、重试、排序、选最优或切回另一个核；
7. 冻结状态之间互不接续，结果不反馈到第 6A 阶段来源轨迹；
8. 本阶段的实验级“通过/不通过”只决定是否值得另做长轨迹研究，不是生成过程中的候选门控。

## 5. 新核的精确目标

冻结当前表的已测查询计数为 `q`，目标计数为 `y`，查询数为 `J`。临时复制开关表记为 `M`；它精确决定
复制部分的总查询改变量 `D(M)`。当前无噪声首版的有效绝对误差固定为：

```text
E(M) = (1 / J) * sum_j |y_j - (q_j + D_j(M))| / max(y_j, 8)
```

其中：

- 容差半径固定为 0；
- `max(y_j, 8)` 与当前相对残差的分母下限保持一致；
- 不读取原始参考表、留出查询或离线安全查询；
- `D(M)` 必须由全部参与行在当前完整临时组合下的精确查询指示变化求和；
- 同一行多个属性对合取查询的共同作用不能用孤立单属性改变量线性相加近似；
- 多行的改变量必须先求总和再计算绝对误差，不能逐行分别计算后取平均。

对当前待更新开关 `g`，固定其他全部开关：

```text
E0      = g 取 0 时的 E
E1      = g 取 1 时的 E
score_g = E0 - E1
```

- `score_g > 0` 表示复制更接近目标；
- `score_g < 0` 表示复制更远；
- `score_g = 0` 表示当前上下文中两者的总误差相同。

新核不再把旧 B 与另一个固定平方 C 相加减。是否已经到达或越过目标，由 `E0/E1` 的精确比较自然体现。

## 6. 新核的软条件概率

令固定参考尺度为 `R>0`，抽样强度为 `tau=2`，基础概率为 `eta=0.5`。条件对数几率固定为：

```text
raw_logit_g = log(eta / (1 - eta)) + tau * score_g / R
logit_g     = clip(raw_logit_g, -30, 30)
p_g         = 1 / (1 + exp(-logit_g))
```

因为 `eta=0.5`，第一项等于 0。解释固定为：

| `score_g / R` | 复制概率约值 |
|---:|---:|
| `+1` | 88.08% |
| `+0.5` | 73.11% |
| `0` | 50.00% |
| `-0.5` | 26.89% |
| `-1` | 11.92% |

数值护栏只防止浮点数把有限软概率舍入成精确 0 或 1，不代表命中护栏是正常科学工作区。所有条件必须
记录护栏命中、原始对数几率、实际概率、二元熵以及概率落在 `(0,0.001)`、`[0.001,0.01)`、
`[0.01,0.99]`、`(0.99,0.999]`、`(0.999,1)` 的数量。

## 7. 固定参考尺度

### 7.1 每个数据集、每个来源随机种子只定一次

第 6B-1 阶段对每个 `dataset（数据集） × source seed（来源随机种子）` 定一个 `R`，同一随机种子的
五个状态和全部候选地址都复用它。不得按状态、轮次、候选地址、参与行或已经看到的结果重新定尺。

定尺地址固定为该随机种子 `initial（初始）` 状态中最小的候选编号。只使用该地址已经冻结的供体场，
不使用参与随机量、初始复制开关、新核条件概率或生成结果。

### 7.2 孤立分数

对定尺地址中所有“当前值与供体值不同”的行—属性 `(i,a)`：

1. 令其他所有复制开关都为 0；
2. 比较 `(i,a)` 单独为 0 和单独为 1 时的精确 `E`；
3. 得到孤立分数 `s_ia = E0 - E1`；
4. 精确为 0 的分数不进入定尺集合；
5. 正负分数都保留，定尺只使用平方后的大小。

若非零集合为 `S`，则：

```text
R = sqrt((1 / |S|) * sum_(s in S) s^2)
```

必须用先除最大绝对值再求均方根的数值稳定算法，保存：非零数量、零数量、最小绝对值、中位数、四分位、
均方根、最大绝对值和最大值与均方根之比。中位数和分位数只作诊断，不能看结果后替换均方根。

### 7.3 首个定尺地址没有非零分数

- 如果当前全部已测查询误差已经为 0，则生产流程应在抽供体前停止，不需要参考尺度；固定状态地址记为
  `already_exact（已经精确命中）`，三组都不生成候选，也不进入方法胜负分母。
- 如果误差非零，但最小候选编号没有非零孤立分数，则按候选编号递增寻找第一个非零集合，仍只用
  `initial` 状态；必须记录实际定尺编号。
- 如果该初始状态的全部冻结候选编号都没有非零孤立分数，则该数据集/随机种子记为
  `calibration_unsupported（无法定尺）`，筛查执行资格失败。不得临时设极小常数、借用旧 B 尺度或按
  后续结果选择另一把尺子。

未来完整长轨迹的对应生产语义应是：若当前误差非零但本轮没有非零孤立分数，本轮保留现有 B 初始开关，
不启动新吉布斯重扫描；后续每轮继续尝试，首次得到非零 `R` 后永久冻结。该退化规则只在未来长轨迹协议中
再次正式绑定，本固定状态筛查不模拟未定尺的过渡轮次。

## 8. 临时复制开关与 8 次扫描当量

### 8.1 初始开关

三组逐随机位共享现行主随机流产生的：

1. 参与行开关；
2. 每个属性的 B 倾斜复制随机数；
3. `current != donor` 掩码；
4. 得到的初始复制开关表；
5. 后置突变的命中、属性和值随机量。

新核不得先按自己的误差重新生成一份初始开关。新误差只进入后续吉布斯条件重抽。

### 8.2 新核的扫描域

新核活跃集合是所有“行已参与且当前值与供体值不同”的行—属性开关，总数记为 `K`。固定执行：

```text
8 * K 个随机坐标微步
```

每个微步使用独立派生的新核吉布斯随机流，在 `K` 个活跃开关中等概率、有放回地选择一个；计算该开关
当前上下文的 `E0/E1`，按第 6 节概率重抽，并立即更新该行的临时值、行查询指示、总 `D` 和总误差。

`K=0` 时原样返回初始开关且不消耗新核吉布斯随机流。非参与行和当前值等于供体值的属性永远不进入扫描。

### 8.3 8 次不是新能量的混合资格

第 4 阶段证明的是旧 B 因子能量、逐行活跃属性上的 8 次随机扫描资格。新误差把多行临时计划通过总查询
计数耦合起来，目标分布和扫描域都已改变，因此旧资格不能直接继承。

本协议仍按用户决定固定 8 次，只把它定义为首版实际转移核和受控比较参数，不重新扫描 4/8/16/32，
也不宣称已经逼近新核平稳分布。若首版失败，不得在同一结果上顺手调扫描次数；若以后确需混合资格，
必须另立协议和新随机地址。

## 9. 完整生成顺序保持不变

未来接入完整生成器时，顺序固定为：

```text
当前表
→ 计算已测查询、残差和供体适应度
→ 为全部行抽供体
→ 计算现有局部 B、现有 B 参考尺度和初始属性复制概率
→ 若新误差参考尺度尚未建立，按第 7 节只读定尺
→ 用统一 rho=0.01 抽参与行
→ 按现有 B 概率抽临时复制开关初值
→ 计算临时组合的精确总查询改变量 D
→ 做 8 次新误差吉布斯扫描当量
→ 应用最终复制开关一次
→ 按现有 mu=0.01 做突变
→ 得到唯一下一张表并无条件接续
```

定尺是供体确定后的只读计算，不抽参与行随机数，也不调整“先供体、后参与”的顺序。参与行仍无逐行偏好。


`initial` 完整报告并进入早期安全门槛，但不与后初始状态混成一个平均数。随机种子是统计独立单位；不得
把 5500 个地址、参与行、属性开关或吉布斯微步伪装成独立随机种子。

## 11. 随机性与配对身份

每个第 6A 阶段冻结地址必须复用并重放：

- 当前表、目标和有序已测查询；
- 当前查询计数、残差、供体适应度与供体概率；
- 供体编号；
- 现有 B 方向分数与来源轨迹固定 B 参考尺度；
- 参与随机数；
- 初始属性复制随机数与初始开关；
- 突变命中、突变属性和突变值随机数。

额外派生两个互不重叠的流：

1. `factor_b_gibbs_rng（原始 B 因子吉布斯随机流）`；
2. `gap_l1_gibbs_rng（新误差吉布斯随机流）`。

两种吉布斯扫描域和坐标消费语义不同，不伪称逐微步使用了同一随机位。公平配对来自共同冻结状态、共同
供体、共同参与、共同初始开关和共同后置突变；额外内部随机量各自域隔离，不能错位主随机流。

供体概率和供体编号必须用第 6A 阶段状态中记录的 `runtime_device（运行设备）` 重放并对拍既有供体哈希；
供体确定后，将当前表、供体表、初始开关和查询计数移交给 CPU 上的新核双精度路径。不得为了省去 CUDA
重放而用另一后端重新抽一套“近似相同”的供体。

采集器必须先完成全部三组原始结果再交给评价器。不得查看部分组结果后决定是否继续剩余地址或增加内部
重复次数。

## 12. 仅复制与后置突变

每组都产生两条顺序测量：

```text
q0      = 当前查询计数
qcopy   = 应用最终复制开关后的查询计数
qfull   = 在同一 qcopy 上再执行公共突变随机量后的查询计数
```

仅复制是主机制段，因为新核只设计复制开关；完整段是生产相关安全检查。不同组之间不得选择较好的
`qcopy/qfull`。同一个突变“设值”操作必须应用到三组各自复制表，即使该位置在不同组复制前的值不同。

继续独立复算第 6A 阶段的二次 `B2/C2/G2` 和复制—突变顺序恒等式，但它们是旧平方损失诊断，不替代
第 5 节的新绝对误差主指标。

## 13. 每个地址必须记录的指标

### 13.1 新绝对误差主指标

对仅复制和完整段分别记录：

```text
E_current
E_after
gain_E          = E_current - E_after
positive_gain_E = max(gain_E, 0)
negative_harm_E = max(-gain_E, 0)
```

使用目标计数和整数查询计数独立复算；正式评价的加减、绝对值、分母和比较以精确有理数为权威，浮点只
用于实际软概率和阅读输出。

### 13.2 查询级方向与越界

对每个查询令旧缺口 `r_j=y_j-q_j`、复制改变量 `d_j=qcopy_j-q_j`，完整报告：

- `no_move（未移动）`：`d_j=0`；
- `toward_not_crossed（朝目标且未越界）`：`r_j*d_j>0` 且 `|d_j|<=|r_j|`；
- `crossed_target（穿过目标）`：`r_j*d_j>0` 且 `|d_j|>|r_j|`；
- `away_from_target（背离目标）`：`r_j*d_j<0`；
- `left_exact_target（离开精确目标）`：`r_j=0` 且 `d_j!=0`。

同时记录按 `max(y_j,8)` 加权的穿越量、离开目标量、查询 L1/L2 位移和精确命中查询数变化。它们用于
解释，不单独替代总误差结论。

### 13.3 运动、概率与成本

至少记录：

- 参与行、活跃开关、最终开启开关、实际变化行和单元格；
- 临时总查询位移、最终仅复制位移和完整位移；
- 参考尺度、实际定尺地址和全部定尺分布诊断；
- 条件分数、标准化分数、原始/护栏后对数几率、概率与二元熵分布；
- 护栏命中、非有限条件、精确 0/1 条件概率、两方向最小概率；
- 吉布斯微步、条件误差评价次数、查询指示增量更新次数；
- 预计算、定尺、扫描、物化、查询复算和完整地址墙钟。

墙钟只作诊断，不进入本开发筛查的科学通过门槛。

## 14. 结果前冻结的判定规则

所有正式筛查判断都在两个数据集分别进行；不做跨数据加权总分。每个随机种子先在地址内求平均，再对
五个随机种子等权，避免小表的 200 个地址压过大表的 20 个地址。`4/5` 稳定门槛沿用第 6A 阶段的
随机种子一致性口径；`1.05` 非劣界沿用第 5 阶段的安全边界，不根据本阶段结果重新选择。

### 14.1 执行资格

以下条件必须全部满足：

1. 5500/5500 个地址全部有清单记录；所有非精确命中地址的三组和两条测量段完整，精确命中地址有三组
   一致的确定性无操作记录；
2. 第 6A 阶段输入身份、供体、参与、初始开关和突变重放全部通过；
3. 每个非精确命中随机种子得到唯一、正、有限且全程固定的新参考尺度；
4. `gap_l1_global_s8` 的微步数逐地址精确等于 `8*K`；
5. 每次增量更新后的查询总改变量与从临时/最终表完整复算完全一致；
6. 全部条件分数、对数几率和概率有限，所有 0/1 结果都有严格正概率；
7. 条件对数几率护栏命中为 0；
8. 没有生成后接受、拒绝、回滚、重试、挑赢家、漏地址或结果驱动补样；
9. 结果盲结构审计和独立算术审计都通过。

结构、身份或精确重建失败记为 `execution_invalid（执行无效）`；无法定尺记为
`calibration_unsupported（无法定尺）`；出现非有限值、精确单向概率或护栏命中记为
`outside_frozen_soft_scale（超出冻结软概率工作区）`。这些情况下不解释方法效果，也不事后调护栏、
参考尺度或抽样强度。

### 14.2 后初始状态的稳定误差改善

对每个数据集和两个基准组分别比较 `gap_l1_global_s8`。在四个后初始状态合并后，必须同时满足：

```text
新核的五随机种子等权 mean(E_copy) 严格更低
且至少 4/5 个随机种子的 mean(E_copy) 严格更低
```

必须同时胜过 `independent_b_s0` 与 `factor_b_s8`，才记为
`stable_gap_error_gain（稳定的剩余误差改善）`。精确相等不算胜；不追加地址或随机种子。

### 14.3 坏步损失必须下降

对每个基准组分别比较 `negative_harm_E`：

```text
新核的五随机种子等权 mean(negative_harm_E) 严格更低
且至少 4/5 个随机种子的 mean(negative_harm_E) 严格更低
```

该门槛比较的是坏步造成的误差总量，而不是只数坏步个数。坏步率、平方曲率过冲率和查询穿越率全部报告，
但不要求用更多微小坏步换取更好看的“坏步个数”。若某基准在一个数据集的五个随机种子上
`negative_harm_E` 全为 0，则没有可供检验的坏步损失，该项记为
`insufficient_harm_support（坏步支持不足）`，不能伪造“下降”结论，也不把新核同为 0 写成严格胜利。

### 14.4 有益前进量不得被统一压慢

对每个基准组 `c`，只看该基准仅复制 `gain_E_c>0` 的配对地址。每个随机种子定义：

```text
retention_c =
    sum(max(gain_E_new, 0) on addresses where gain_E_c > 0)
    / sum(gain_E_c on those addresses)
```

若某随机种子没有基准正收益地址，记为分母不足，不把 0 当成通过。每个数据集、每个基准必须满足：

```text
五随机种子等权 mean(retention_c) >= 0.95
且至少 4/5 个随机种子的 retention_c >= 0.90
```

平均保留量 `0.95` 和单随机种子 `0.90` 下限在结果前固定，用来排除历史固定完整 C 所表现出的约
16.7% 全局运动缩减，而允许少量吉布斯内部随机差异。查询二次位移、变化行和变化单元格
继续报告，但不要求无差别维持同样位移；如果新核用更小但更准确的步子保住了实际误差改善，不视为失败。
任一基准有随机种子缺少正收益分母时，该基准记为
`insufficient_good_step_support（有益步支持不足）`，不静默跳过该随机种子。

### 14.5 初始状态安全

`initial` 状态不参与 14.2--14.4 的后初始稳定主判定，但必须对两个基准分别满足：

```text
新核五随机种子等权 mean(E_copy_initial)
    <= 1.05 * 基准五随机种子等权 mean(E_copy_initial)

且至少 4/5 个随机种子满足同一 1.05 非劣界
```

若基准值为 0，新核也必须为 0。该门槛专门防止新方法只在晚期好看、却重演早期统一刹车。

### 14.6 后置突变完整段安全

对四个后初始状态的 `E_full`，新核相对两个基准都必须满足：

```text
新核五随机种子等权 mean(E_full)
    <= 1.05 * 基准五随机种子等权 mean(E_full)

且至少 4/5 个随机种子满足同一 1.05 非劣界
```

完整段只作安全门，不允许突变偶然救回掩盖仅复制主机制失败。

### 14.7 每数据集与跨数据分类

每数据集按顺序分类：

1. 执行资格失败：对应 14.1 的无效标签；
2. 后初始稳定误差改善失败：`no_stable_gap_error_gain（没有稳定的新核误差改善）`；
3. 坏步或有益步分母不足：`insufficient_transition_support（转移支持不足）`；
4. 稳定误差改善通过但坏步损失未下降：
   `gap_gain_without_harm_suppression（有净改善但没有稳定压低坏步损失）`；
5. 稳定误差与坏步损失门槛通过，但有益前进量保留失败：
   `gap_gain_with_good_step_suppression（改善伴随有益步被压慢）`；
6. 主机制通过但初始状态或完整突变段失败：
   `gap_mechanism_with_transition_risk（局部机制有效但进入完整流程有风险）`；
7. 全部通过：`gap_kernel_development_supported（新核开发筛查获得支持）`。

跨数据只允许：

- 两数据均通过：`shared_development_support（两数据开发筛查共同支持）`；
- 仅一套通过：`dataset_dependent_development_support（开发支持依赖数据集）`；
- 两套均未通过：`no_shared_development_support（没有跨数据开发支持）`；
- 任一执行无资格：`inconclusive_or_invalid_screen（筛查无结论或无效）`。

无论是哪一类，都不自动修改默认核。

## 15. 概率接近确定性的处理

无门控硬边界是所有有限条件下两种结果都有正概率；14.1 已将精确 0/1、非有限值和护栏命中列为失败。

概率低于 1% 或高于 99% 的条件占比另行形成
`near_deterministic_warning（接近确定性的警告）`，但本阶段不凭空设一个额外效果否决阈值。原因是强烈
有益或有害的真实条件本来可能合理地产生很偏的概率。该警告必须与最大标准化分数、定尺最大值/均方根比、
查询频率和状态阶段一起完整报告，供长轨迹协议决定是否需要独立尺度研究；不能在看过效果后改 R 或
`tau=2` 重跑本矩阵。

## 16. 采集、评价与独立审计

实施必须分成互相隔离的五步：

1. 只读输入与定尺清单构建；
2. 三组固定状态结果盲采集；
3. 结果盲结构与随机重放审计；
4. 冻结评价器；
5. 不调用采集器/评价器共享算术助手的独立算术审计。

采集器只发布逐地址原始指标、稀疏编辑、随机端点、概率诊断和完整清单，不计算第 14 节最终分类。必须
完整采完两数据、三组和两段，结构审计通过后，评价器才能看到结果。

独立审计至少从当前表、供体、开关日志、突变日志和查询定义重新计算：

- 定尺孤立分数与固定均方根；
- 每个吉布斯微步的坐标、`E0/E1`、概率和随机结果；
- 最终仅复制/完整表与查询计数；
- 精确 `E`、gain、positive/negative 分解；
- 查询方向/越界、旧 B/C/G 和复制—突变恒等式；
- 随机种子等权汇总、所有门槛与最终标签。

输出目标必须排他原子创建；输入漂移、已有输出覆盖、部分清单、重复地址或审计失败都立即停止，不写一份
看似完整的部分结论。

## 18. 实施与授权顺序

本文冻结后，后续顺序固定为：

1. 把确认后的协议作为独立文档提交，并用协议模块绑定文档和科学清单 SHA-256；
2. 只实现独立的新误差计算、固定定尺和固定状态采集路径，不接入公共默认生成器；
3. 用手工微型表测试单属性、同一行多属性、多行交叉、到达目标、穿过目标、离开零误差、零分数定尺、
   8K 微步、随机重放、数值护栏和无门控身份；
4. 实现结果盲采集器、结构审计、冻结评价器和独立算术审计；
5. 只做小规模冒烟验证，验证接线与精确重放，不输出机制证据；
6. 向用户报告小规模耗时和完整 5500 地址预计成本，等待单独正式筛查授权；
7. 完整筛查和双审计通过后，只按第 14 节报告冻结分类；
8. 只有得到 `shared_development_support（两数据开发筛查共同支持）`，才优先起草全新随机种子的完整
   无门控长轨迹协议；其他结果先讨论，不自动调尺度、强度或扫描次数。

任何一步都不自动推送、创建拉取请求、评论议题、请求审查或修改公共默认。用户没有明确说“推”就不推。

## 19. 本协议冻结后的解释边界

- 固定状态通过，表示新条件打分在旧轨迹状态上按预定目标工作，不表示完整闭环一定更好；
- 固定状态失败，否定的是当前 `绝对误差 + 初始非零均方根 + tau=2 + 8 次扫描当量` 这一整套首版身份，
  不能只挑一个有利子组宣称方法成立；
- 8 次首版通过也不等于新全局能量已经完成混合资格；
- 第 6A 阶段旧平方 B/C/G 和本阶段相对绝对误差 E 是两种不同评价几何，必须并列解释，不能偷换；
- 50 个冻结状态全部来自现行独立核轨迹，对另两组属于旧策略状态分布上的离线比较；即使通过，也不能
  推断新核自己产生的中后期状态会有相同表现；
- 当前无噪声 `h=0` 的结论不能外推到加噪目标；带噪容差必须另立结果前协议；
- 本协议没有授权参与行偏好或顺序调整，整体流程最终定稿后再回到该待决项。
