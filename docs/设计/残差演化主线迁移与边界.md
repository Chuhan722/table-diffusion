## 基础数学合同

固定公开 schema、公开 N、查询目标 y 与正对角权重 W：

```text
e = y - q(S)
L = ½ eᵀ W e
G_B(u) = eᵀ W d_B(u) - ½ d_B(u)ᵀ W d_B(u)
P_B(u) ∝ R_B(u) exp(β G_B(u))
D = Σ E_P[G_B] ≥ α Σ max G_B
C = ½ (∥Σ v_B∥²_W - Σ ∥v_B∥²_W)
E[L_next | 旧状态与本轮支持] = L - hD + h²C
```

块内联合抽样、块间条件独立；方向分布 P 不直接等于最终核 K。
不得在抽样后按损失接受/回退，再把产物称为这一个核的样本。
条件期望下降不要求每次实际损失下降，也不证明全局最优或真实泛化质量必然改善。
随机有限菜单未找到正方向，不是完整支持上的局部最优证书。

## 本次参数修复

所有构核/多轮公开入口统一验证：

- `damping` 有限且位于 `(0,1]`；
- `max_expected_rows` 是 `None` 或正有限数。

检查在冻结返回、候选提供器调用和抽样之前完成；零轮仍按原规则拒绝。
没有重排 `h = damping * min(h_star, B_max/H)` 的算术，也没有新增随机调用。
没有预算时保留 `h = damping * h_star`。

三个二值行的反例表明，“概率合法”不蕴含“期望下降”：
旧损失 0.5，错误放行 `damping=3` 可得到合法 K，却使下一损失期望升至 1.0625。
因此不能把过大的阻尼仅交给概率检查处理。详见锚点文档第 15 节和跨后端回归测试。

## 新入口与历史适配器

`python -m resevo` / `resevo-generate` 只接受显式公开 schema、N、已提供查询目标及
算法参数，不接受真实训练/测试表或原表路径。它提供基础批量核入口；
默认单位权重，默认不启用结构先验、配对救援、nullswap、纤维、地板或输出选择。
缺 GPU 依赖时失败，不静默换后端；输入错误和已有输出路径明确拒绝。

保留的 `run_plants.py`、测量外壳与离线评价脚本是历史基准适配器，不被上述新入口调用。
其中原表推断 schema/N、精确结构基准以及带噪目录附带原表副本的问题仍需独立处理。
本次不能据新入口的隔离性宣称所有历史适配器已经符合端到端隐私边界。

## 后续问题，不随迁移视为解决

| 事项 | 当前边界 |
|---|---|
| 数值假冻结 | 用整个旧损失缩放方向阈值，可能吞掉可靠小正增益；后续应按局部运算误差处理 |
| 噪声地板 | 固定表的噪声期望公式不能直接作为噪声自适应估计表的通用下界或晚停必坏证明 |
| 噪声分裂探针 | 固定未裁剪高斯观测下的独立性，不自动覆盖自适应选测、合并和清洗后的输入 |
| 纤维第二阶段 | 保持已测边际不等于遍历整个纤维或达到最大熵；伪目标改变了优化问题 |
| nullswap 与精修 | 单独的可选优化步骤，不能不加条件地继承基础核或任意 workload 的保证 |
| 完整自动停系统 | 机器专属启动/监控和失败交表路径没有在本 PR 中迁入或认证 |
| DP | 本次不增加 accountant、预算组合证明或完整私有发布协议 |

迁移和参数校验是工程门禁，不是一次新的算法效果比较。合法输入等价性应核对
同种子的初始/终表、每轮非计时量、候选数和停止原因；耗时与内存作为诊断单独记录。
新算法或附加统计策略的优势仍需各自预定实验，不能沿用源码迁移的测试结论。

## 独立复现对拍

验证器 `scripts/verify_resevo_migration.py` 既可从原分支 API 生成参考产物，
也可通过新的公开输入 CLI 生成候选并核对，避免依赖本机未提交的实验脚本。
它会检查导入来源、工作树清洁性、公开输入哈希和基线表与元数据的一致性；
不会覆盖已有结果。

以下以 nltcs 全组单种子为例。在同一依赖环境中执行；新工作区及输出路径应不存在：

```bash

  python scripts/verify_resevo_migration.py \
  --code-root outputs/resevo-source --reference-api \
  --public-inputs outputs/resevo-source/data \
  --dataset nltcs --variant full --seed 6101 \
  --out outputs/resevo-equivalence/reference/nltcs_full_s6101

OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 \
  python scripts/verify_resevo_migration.py --code-root . \
```

## 后续主题：分裂探针记账与显著回升停（2026-10-25，研究分支第七十三步移植）

来源：`residual-evolution=959b473`，相对 `08ac64b` 只改 `batchkernel.py`、`gpukernel.py`、
`run_plants.py` 三个文件并新增 `tests/test_fission_probe.py`；三方套入 master 后，三个文件
相对源版本的差异恰为本仓库此前的参数校验改动，无其他分歧。本次移植另加两处：GPU 记账
`fission_errors_of` 只取 `_state_terms` 返回元组的首项（残差），不按成员个数拆包，该元组
日后增减成员不影响记账；新增 GPU 路径测试（通用与直算两通路的逐题误差与 CPU 按表答案
重算一致、题数不符报错、元组多出成员结果不变，有卡才跑）。

`evolve_batch` 新增只读记账 `fission_targets / fission_every / fission_hook`：每 N 轮及分档
全过线轮，用起点表对模拟卷算逐题误差 e 与 L1_B；全过线轮的 e 存为参照 e_G，其后每次记账算
配对差 d = e − e_G 的均值与标准误 std(d, ddof=1)/√n 交给钩子。`fission_stop_z > 0` 时启用
显著回升停：连续 `fission_stop_runs` 次记账均满足 diff_mean ≥ z·diff_se 即停，停止原因
`fission_rise`，交触发轮起点表。默认全部关闭，关闭时算术与随机流不变；开启记账不停时
轨迹与不开逐位相同（测试覆盖 CPU/GPU 后端）。`run_plants.py` 增加
`--fission-exam / --fission-every / --fission-out / --fission-stop-z / --fission-stop-runs`
（需 `--batched` 与 `--snapshot-group-floor`），记账 CSV 列
`round, elapsed_s, old_loss, l1_b, at_group_floor, diff_mean, diff_se`，收工追加终表一行。

边界：
- 停止规则 z ≥ 2 连续 3 次是事先约定的经验校准规则。单次记账的配对 z 检验在模拟卷噪声
  逐题独立且与学习卷独立的条件下成立；但记账每 5 轮一次、每格数百至数千次，反复观察下
  的总体误报率没有正式保证，依据是研究分支 adult 30 格 + acsmob 15 格的实测余量：45 格
  判停全对；24 个收敛格过线后 1～28 轮内 z 最高 +2.04（过线瞬间的抖动），z ≥ 2 从未连出
  3 次；门槛降到 1.5 仍无误报，降到 1/0.5 分别误判 1/3 格；纯看回升拐点不看幅度的规则在
  全部收敛格误报。离线回放还显示过线 100 轮后收敛格 z 最高只到 +0.72，"过线 100 轮后再
  启用低门槛"在 45 格全对并可再省 20～40% 判停时间，但这是对同一批记录拟合出的结论，待
  第三数据集验证后才考虑采用。门槛随观察次数增长的任意时刻有效规则在同批记录上只保留
  ε=0.3/1 的提前停，ε=0.1/3 退回收敛；若改用它，收敛后的兜底须改为终点比较。规则的优劣
  属预定实验结论，不随本次移植视为已证明。
- 地板/收敛的分界随数据集移动：adult 1A 在 ε≤3 为地板停，acsmob 1A 在 ε≤1；acsmob ε=3/10
  的收敛终表分别比全过线快照好 2%/13%。探针判停在两个数据集上均与神视角一致，但对第三
  个数据集没有保证。
- 用时：研究分支记录的单格墙钟（acsmob 1A 229/373/1,212/3,373/3,264 秒，ε=0.1→10）出自
  研究分支代码；本仓库套入后的引擎在算术上等价，但未在同格单独计时。地板格的交付快照在
  66～154 秒内即已落地，其余时间在等探针确认显著回升，斜率平缓的数据集（acsmob ε=1）
  等待较长。
- 自动停驱动（并行探针/正式跑、GPU 与核绑定、交表与阅卷脚本）与结果仍只在研究分支，
  本次不迁入；本仓库只提供引擎与基准适配器层的能力。
