## 基础数学合同

固定公开 schema、公开 N、查询目标 y 与正对角权重 W：

```text
e = y - q(S)
L = ½ eᵀ W e
G_B(u) = eᵀ W d_B(u) - ½ d_B(u)ᵀ W d_B(u)
P_B(u) ∝ R_B(u) exp(β G_B(u))
D = Σ E_P[G_B] ≥ α Σ max G_B
C = ½ (∥Σ v_B∥²_W - Σ ∥v_B∥²_W)
E[L_next | 旧状态与本轮支持] = L - hD + h²C
```

块内联合抽样、块间条件独立；方向分布 P 不直接等于最终核 K。
不得在抽样后按损失接受/回退，再把产物称为这一个核的样本。
条件期望下降不要求每次实际损失下降，也不证明全局最优或真实泛化质量必然改善。
随机有限菜单未找到正方向，不是完整支持上的局部最优证书。

## 本次参数修复

所有构核/多轮公开入口统一验证：

- `damping` 有限且位于 `(0,1]`；
- `max_expected_rows` 是 `None` 或正有限数。

检查在冻结返回、候选提供器调用和抽样之前完成；零轮仍按原规则拒绝。
没有重排 `h = damping * min(h_star, B_max/H)` 的算术，也没有新增随机调用。
没有预算时保留 `h = damping * h_star`。

三个二值行的反例表明，“概率合法”不蕴含“期望下降”：
旧损失 0.5，错误放行 `damping=3` 可得到合法 K，却使下一损失期望升至 1.0625。
因此不能把过大的阻尼仅交给概率检查处理。详见锚点文档第 15 节和跨后端回归测试。

## 后续局部数值修复（#79）

方向存在性按已复核的 `M = Σ max G` 判断，只有 `M=0` 才报告本轮支持无正方向。
`old_loss` 仍作为兼容参数和有限性检查输入，但不再用
`numerical_tol * max(1, old_loss)` 截断收益。零贡献或恒值查询可以增加旧损失，
却不改变任何合法转移的收益，因此不能改变该判据。

这不是简单关闭容差。正常计数路径保留原计算顺序，另外用局部绝对线性项与
半二次项之和估计运算量级；组核的 `phi` 差分使用保守上界，避免漏掉 `phi`
内部消减。以项数 `t`、`k=8(t+1)`、float64 单位舍入误差 `u` 构造
`gamma=ku/(1-ku)`；`max(numerical_tol, gamma/(1-gamma))` 和次正规数余量
只用于触发复核，不用于把小收益改成零。范围安全的整数/半整数乘加可跳过复核。

可疑项用实际 float64 输入的精确有理表示计算局部收益。复核必须从已提供的
目标和当前**合成表**查询答案重建残差，而不能只把已经舍入的残差升精度。
例如三个相同计数查询的目标为 `(1e16, 2.500001, -1e16)`、旧计数均为 1，
`target - count` 的浮点结果会丢掉大坐标上的减 1；只复核该残差会错误激活方向。
CPU 按需恢复旧答案；GPU 保留原有计数答案，仅回传被选中的稀疏路径和半空间增量，
不回传整个候选矩阵。所有缓存只属于本轮，不跨轮复用残差。

收益无法表示为非零有限 float64、`alpha*M` 下溢、非有限校准量或相对 `M`
的校准误差超过 `numerical_tol` 时，明确抛出带 `numerical_indeterminate` 的
`FloatingPointError`，而不是返回“冻结”。`numerical_tol=0` 仍保留机器舍入保护。
其默认值不变；没有改变查询、支持、随机流、参考质量、步长公式或抽后接受语义。

范围限定：这是计数查询的局部方向判断修复，不是整条浮点计算链的区间认证。
公开入口的 0/1 贡献及可精确表示的旧计数是主要验证范围；对任意非整数或巨大
贡献矩阵，不承诺覆盖在形成查询答案/增量时已经丢失的信息。损失、交互项 `C`
和漂移仍使用原 float64 路径，不能由两个巨大总损失之差验证一个极小收益。
未同时解决平台早停的尺度依赖、概率下溢诊断或稀疏菜单的全支持覆盖；
无正方向仍只针对本轮支持，不表示全局最优。没有新增 DP 认证。

## 新入口与历史适配器

`python -m resevo` / `resevo-generate` 只接受显式公开 schema、N、已提供查询目标及
算法参数，不接受真实训练/测试表或原表路径。它提供基础批量核入口；
默认单位权重，默认不启用结构先验、配对救援、nullswap、纤维、地板或输出选择。
缺 GPU 依赖时失败，不静默换后端；输入错误和已有输出路径明确拒绝。

保留的 `run_plants.py`、测量外壳与离线评价脚本是历史基准适配器，不被上述新入口调用。
其中原表推断 schema/N、精确结构基准以及带噪目录附带原表副本的问题仍需独立处理。
本次不能据新入口的隔离性宣称所有历史适配器已经符合端到端隐私边界。
