# Issue #53 B+C 问题一：A/R 相对初始进度 logit 截断短诊断协议

## 1. 触发事实与诊断目的

开发种子 9908 的 v2 两轨迹采集使用执行协议
`56f852fb925f2ec2785a3a7f56593a51f73d4b39a1649db82725cb1076647685`。
`test_300x10` 已完整封存；NLTCS 完成生成后，在结果盲转移审计遍历到第
232 轮时命中“微步数不等于 `8*K`、非有限条件数非零或 logit 截断数非零”
的联合护栏，因此没有发布 NLTCS case、shard report 或 collection。

正常扫描诊断直接把 `gibbs_microsteps` 构造为 `n_sweeps*K`，并只在全部条件
数值有限后返回 `nonfinite_condition_count=0`。所以已有失败位置唯一指向：
第 232 轮至少一个条件 raw logit 超出 `[-30,30]`。

本诊断只回答三个机制问题：

1. 前 231 轮是否确实零截断；
2. 第 232 轮发生多少次截断，占多少条件微步；
3. 截断来自哪些行—属性微步、raw logit/标准化分数多大，以及该微步改变了
   哪些已测合取查询的行指示。

它不回答候选质量是否改善，不为放宽护栏或选择新温度提供自动授权。

## 2. 冻结重放范围

- 数据集：只运行 `nltcs`；
- 方法：`gap_dual_abs_relative_progress_max_s8`；
- 随机种子：9908；
- 生成输入、边际初始化、供体选择、B 初始开关、C 核公式、A/R 初始参照、
  扫描顺序、每轮 `8*K` 微步、突变和所有随机流均继承 v2；
- 只把 `n_rounds` 与 `candidate_budget` 从 6000 同时截到 232；
- 由于原轨迹至少完成 232 轮，资源上限只在第 232 轮完成后生效，不改变前
  232 个状态转移；
- 使用同一冻结 Python/NumPy/pandas/PyTorch 环境和物理 GPU 1。

诊断不得恢复 v2 空临时 case，不得把输出混入 v2 staging，也不得覆盖已有
诊断输出。

## 3. 行为中性的只读插桩

不修改生产生成器。诊断入口只在自身调用域内临时包装三个内部函数，退出时
无条件恢复：

1. CUDA 缺口扫描入口：只记录轮号、调用输入、扫描随机流调用前状态；
2. A/R 通道主导计数函数：只在第 232 轮把已经从 GPU 复制到主机的四个通道
   值追加到诊断缓冲；原计数函数仍原样调用一次；
3. 扫描诊断构造函数：只复制其本来就会汇总的 score、normalized score、
   raw logit 和 probability 向量；原诊断函数仍原样调用一次。

插桩不得更改 GPU 张量、随机数生成器、复制 mask、查询计数、条件概率或返回
值。第 232 轮坐标带和均匀随机带由调用前 RNG 状态在独立 RNG 中只读重放；
必须与原扫描概率重新得到完全相同的开关结果。

对截断微步，诊断用重建的当时 mask 构造该行 `z_g=0/1` 两个临时行，只评价
属性 `g` 涉及的已测查询，记录行指示确实发生改变的查询。它不读取原始参考表。

## 4. 必须通过的身份与数值检查

- 当前生产核、主循环、v2 科学协议和 v2 执行协议文件 SHA-256 均与冻结值
  相同；
- v2 失败 staging manifest 与已封存 test case 四个文件保持冻结哈希；
- NLTCS schema、queries、marginals 身份与 v2 相同，禁止读取 reference；
- 初始表 SHA-256 为
  `173c0ad24e9e1b3ec4e30bc27c5325c34a664968f366254a84e9c14665cbd40b`；
- primary RNG 初始化后状态 SHA-256 为
  `cdf19822cb312a91493ba3540ace38a938c8ea3fd2bc64bbc225707e056124da`；
- A/R 初始参照逐位等于 v2 冻结值；
- 实际推进恰好 232 轮、每轮唯一候选且无条件应用；
- 每轮实际微步数等于 `8*K`，非有限条件数和精确 0/1 概率数均为 0；
- 第 1--231 轮 `clip_hit_count=0`；
- 第 232 轮 `clip_hit_count>0`，且逐向量重算的截断位置数与之完全相等；
- `eta=0.5`、`strength=2`，每个截断位置都满足
  `abs(score/reference_scale)>15`；
- 独立重放的坐标、随机数与概率必须重建相同的最终开关选择；
- 诊断输出不得包含终表、检查点答案、参考质量、L1、未测查询、方法比较或
  参数推荐。

若第 232 轮没有复现截断、身份不一致或任一检查失败，诊断整体失败并拒绝发布。
