## 1. 唯一问题与边界

本阶段只回答：在相同完整生成流程、相同初态和相同外层预算下，新的
`gap_l1_global_s8（B+C 剩余缺口绝对误差核，8 次扫描当量）`，能否让最后当前合成表的查询答案
稳定地比以下两个基线更接近目标：

1. `factor_b_s8（原始 B 因子 Gibbs（吉布斯）核，8 次扫描）`；
2. `independent_b_s0（现行独立 B 核，0 次内部扫描）`。

本阶段保持严格无门控：每轮只有一张下一表并无条件成为新当前表；禁止接受/拒绝、回滚、缩步重试、
重抽、候选选优或历史最好表输出。供体先于参与行的现行顺序不改，参与行不增加偏好。

当前两份 measured（测量）查询文件保存源数据的精确计数。本阶段因此只验证“贴近源数据精确查询”。
带噪目标必须另行冻结噪声机制、强度与噪声随机种子，不得混入本矩阵，也不得把本结果解释成带噪资格。

每个数据输入同时绑定两套用途不同的身份，二者必须分别复算通过：

- result-blind identity（结果盲身份）：对每条查询内条件排序后生成查询指纹，再按查询向量顺序绑定整个查询集合；
  目标以原始整数计数向量的规范 JSON（结构化文本）编码绑定。这一套延续第 4--6A 阶段既有冻结身份。
- stationarity trace identity（状态轨迹身份）：使用状态轨迹模块的有序查询指纹列表编码；目标统一转为有限浮点向量后绑定。
  这一套核对生成器实际记录的检查点向量列顺序。

两套编码保护的是同一查询与目标，但规范化表示不同，所以哈希值本来就不应相等。执行器必须同时核对四个固定哈希，禁止拿
一套的值去与另一套比较，也禁止删掉任一套护栏。

## 3. 共同生成参数与唯一方法差量

三组方法共同固定：

```text
初始化                    marginal（边缘初始化）
rho / eta / mu            0.01 / 0.5 / 0.01
供体距离与选择             geometric（几何距离），尺度不变
alpha                     fixed 16（固定 16）
B 方向强度与定尺           2.0 / initial RMS（初始均方根）
残差几何                  relative floor 8（相对残差，分母下限 8）
tol / retries             +infinity / 0（正无穷 / 零重试）
完整轨迹输出               terminal current（最后当前表）
P=6 内层停止器             关闭
精确零残差停止             保留
```

三组唯一差量是复制开关核：因子核 8 次扫描、独立核 0 次扫描、新缺口核 8 次扫描。新核每个已定尺轮次
严格执行 `8*K（8 乘以活跃开关数）` 个微步；参考尺度取首个正非零孤立分数轮次的均方根并在整条轨迹
固定。不得改强度、分母下限、扫描次数、参与率、供体顺序或公共默认方法。

固定2500轮是比较预算，不宣称收敛。若当前测量残差精确为零，保留现有抽供体前确定性停止；未到达的
检查点标记为未观察，不插值、不复制终点、不伪造轨迹。

## 4. 输出身份与 L1（平均绝对查询误差）

每条轨迹唯一候选输出为最后实际 current table（当前表）。历史最好平方误差状态只允许作为诊断，
不得保存为方法输出、不得参与主指标、不得用于选择检查点。

设测量查询数为 `m`、表行数为 `N`、目标计数为 `y_j`、合成表查询计数为 `q_j`：

```text
absolute count error sum（绝对计数误差总和） = Σ_j |y_j - q_j|
normalized L1（归一化平均绝对查询误差）       = Σ_j |y_j-q_j| / (m*N)
gap E（缺口几何诊断）                         = mean_j |y_j-q_j| / max(y_j, 8)
```

同一数据内，整数绝对计数误差总和与 normalized L1（归一化平均绝对查询误差）的排序完全一致。
主胜负使用整数总和，避免浮点平局歧义；L1 必须完整输出，不能只输出分类。

最终评价至少产生：

- 每条轨迹的 terminal（终点）绝对计数误差总和、L1、平方误差和缺口 E；
- 每个数据/方法 5 个随机种子的 L1 原值、均值、中位数、最小值和最大值；
- 新核相对两个基线各自的逐随机种子 L1 差、均值差、胜/平/负数量；
- S0、500、1000、1500、2000、2500 的当前 L1 曲线；
- 一个独立 `l1_results.csv（L1 结果表）`，同时包含终点与检查点明细。

检查点只解释过程；主判断固定使用最后实际 current table（当前表），禁止从检查点中挑最好者。

## 5. measured（测量）主改善规则

两个数据分别判断，新核相对两个基线分别判断。对任一 `dataset/baseline（数据/基线）` 配对：

```text
新核五随机种子 absolute count error sum（绝对计数误差总和）
    < 基线五随机种子对应总和

且五个配对随机种子中至少 4/5 的新核误差严格更低
```

严格相等记平局，不算任一方获胜。95% paired t interval（配对 t 区间）只作描述，不增加、替代或
放宽上述门槛。

一个数据上的 `stable_gap_gain（新核稳定改善）` 必须同时胜过两个基线。只胜一个基线记 mixed（混合），
不得写成新核整体更好。

## 6. 离线安全评价

正式生成阶段只读取 schema（结构）、测量查询及目标、边缘初始化和冻结协议；不得读取原始参考表、
未测量查询答案、支持集、多样性或任何离线分类。

30/30 条全部完成且结构审计通过后，评价器才读取原始参考表并复用既有冻结组：

`test_300x10（小型测试数据）`：

- 25 条一属性安全查询；
- 521 条未测量二属性查询；
- 512 条冻结三属性留出查询；
- 512 条冻结四属性留出查询。

`NLTCS（真实数据）`：

- 32 条一属性安全查询；
- 3958 条未测量三属性查询；
- 29120 条全部四属性查询；
- 既有分箱联合分布 TVD（总变差距离）。

每个组分别报告，不跨组加权。每项比较先分别计算新核和对应基线的五随机种子算术均值，再以均值比应用
既有 5% 风险带：

```text
越低越好：new <= 1.05 × baseline
越高越好：new >= 0.95 × baseline
```

越低越好包括各离线查询组 L1 和 NLTCS 分箱 TVD；越高越好包括参考支持、覆盖率、唯一行比例、
有效唯一行比例和属性有效支持比例。全部合成表必须 100% 合法。

安全线只防止“测量查询变好但表整体明显受损”，不与主 L1 合成总分，也不允许一个查询组的改善抵消
另一个查询组的恶化。

## 7. 固定分类

每个数据按顺序分类：

1. 任务、身份、数值、最后当前表或无门控审计失败：`execution_invalid（执行无效）`；
2. 新核没有同时稳定胜过两个基线：`no_stable_gap_gain（无稳定新核改善）`，并标明胜哪个、负哪个；
3. 测量主改善通过但任一离线安全、多样性或合法性失败：
   `gap_measured_gain_with_quality_risk（测量改善但有质量风险）`；
4. 主改善和全部安全线通过：`gap_quality_supported（新核质量获得支持）`。

跨数据只允许：

- 两数据均第 4 类：`shared_gap_kernel_support（两数据共同支持新核）`；
- 只有一套数据获支持：`dataset_dependent_gap_response（新核响应依赖数据）`；
- 两数据主改善通过但存在安全风险：`shared_measured_gain_with_quality_risk（共同测量改善但有风险）`；
- 两数据都没有稳定主改善：`no_shared_gap_support（无跨数据共同支持）`；
- 任一执行无效：`inconclusive_or_invalid（无结论或无效）`。

墙钟、显存、内部微步和条件概率计算量完整报告，但不进入质量硬门槛。本阶段优先回答效果是否更好，
不把质量与成本压成一个分数。
