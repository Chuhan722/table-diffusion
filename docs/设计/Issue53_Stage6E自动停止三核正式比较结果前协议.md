# Issue #53 Stage 6E 自动停止三核正式比较结果前协议

## 1. 目的

本阶段只回答：在完整生成流程不变、恢复既有自动停止规则后，替换复制开关核是否改善终止时当前表的质量。不在本阶段重新设计初始化、供体抽取、参与行抽取、突变、扫描、停止器或输出规则。

## 2. 冻结矩阵

- 数据：`test_300x10` 与 `NLTCS`。
- 方法：原 B 因子 Gibbs 核扫描 8 次、独立 B 核、新 B+C 缺口核扫描 8 次。
- 随机种子：353–357，每个“数据×种子”的三种方法必须完整配对。
- 共30条轨迹；不允许根据中间结果增删数据、方法或种子。

353–357在旧的固定2500轮诊断中用过，因此本阶段不声称它们是未见种子。重用它们的目的是对同一配对矩阵只修正停止配置，不通过更换种子改变问题。

## 3. 唯一方法差异

三组共用全部生成参数、主随机流、初始表、方向场、无门控应用与停止器。只有以下核开关不同：

| 方法 | `factorized_gibbs_sweeps` | `gap_l1_sweeps` |
|---|---:|---:|
| 原 B 因子 Gibbs | 8 | 0 |
| 独立 B | 0 | 0 |
| B+C 缺口核 | 0 | 8 |

新核仍必须每轮精确执行 `8*K`个微步，且所有条件值有限、不命中裁剪护栏。

## 4. 自动停止与输出

- `inner_early_stopping_patience_ticks=6`。
- 自然工作量为累计参与复制的行数除以数据行数；其整数部分每增加1完成一个自然工作刻度。
- A：当前平方误差为0时 `fit_target_reached`。
- B：连续6个已完成的自然工作刻度没有严格刷新历史最好平方误差时 `early_stopped`。
- C：轮数或候选评价达到6000时 `resource_cap_reached`。
- 优先级固定为 A > B > C。
- 提案先无条件写入当前表，再检查停止；不接受/拒绝、不回滚、不重试、不选历史最优。
- A/B/C 三种停止都输出停止时的 `terminal current`。

## 5. 轨迹与评价

生成阶段不读取原始参考表，不输出方法排名。它保存初始、100、250、500、1000、2000、4000、6000轮中实际到达的固定检查点，以及每条轨迹的真实终点。检查点只用于诊断，不允许被选为输出。

完整30条采集并固定采集报告哈希后，才允许离线评价读取参考数据。评价输出每条终点L1、五种子汇总、相对两条基线的配对差、离线查询与质量/安全指标。独立复核必须重新读取终表和检查点，重算结论，不重跑生成器。
