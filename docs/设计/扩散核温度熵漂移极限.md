# 扩散核的温度—熵—漂移极限

## 1. 问题与边界

残差驱动扩散已经把局部方向写进随机转移核，而不是在生成后用正收益门槛、
argmax 或 top-k 筛选编辑。本阶段继续回答一个更窄的问题：

> 在当前“独立单块 Bernoulli 复制 + 单块一阶方向”的理论族内，温度还能带来
> 多少正向漂移；取得这些漂移需要牺牲多少扩散熵；质量开始饱和后，剩余误差究竟
> 来自温度不足，还是已经来自该理论族之外？

实验固定仓库原始无噪声配置，只改变无量纲温度。生成运行只使用公开 schema、记录
数、预定义 workload、精确 target、1-way marginal、算法参数和种子。真实训练表与
测试表只允许在候选完全冻结后的离线评价中使用。当前结论不属于端到端 DP 结论，
也不直接改变默认参数。

## 2. 固定状态下的核内精确最优性

固定当前合成状态、残差和 donor，把所有 donor 与 recipient 不同的属性块编号为
`i=1,...,B`。记经过固定初始 RMS 定标后的单块方向为

\[
u_i=d_i/s_0,
\]

历史复制核为相互独立的 `Bernoulli(eta)`。温度为 `tau` 时，当前核为

\[
p_i(\tau)=\sigma\!\left(\operatorname{logit}(\eta)+\tau u_i\right).
\]

以下核内最优与符号极限结论假设 `0<eta<1`；当前实验为 `eta=0.5`。实现仍保留
`eta=0/1` 的历史端点语义，但端点参考分布没有完整支持集，指数倾斜不能开启原本
概率为零的转移。

在“方向贡献可加、复制决策独立”的核族内，它不是一个经验公式，而是以下问题的
唯一闭式解：

\[
q_\tau=\arg\max_q
\left\{
\mathbb E_q\!\left[\sum_i m_i u_i\right]
-\frac{1}{\tau}\operatorname{KL}(q\Vert q_0)
\right\},
\]

其中 `q_0` 是历史乘积 Bernoulli 核，`m_i` 表示是否复制第 `i` 个块。换言之，
固定 KL 正则强度后，当前 logistic 核已经达到这个理论族的一阶漂移最优；继续在
同一族内增加启发式筛选并不能得到更强的核内最优性。

定义对数配分函数

\[
\Psi(\tau)=\sum_i\log\left[(1-\eta)+\eta e^{\tau u_i}\right].
\]

加性一阶期望漂移为

\[
D(\tau)=\Psi'(\tau)=\sum_i p_i(\tau)u_i,
\]

并且

\[
D'(\tau)=\sum_i p_i(\tau)(1-p_i(\tau))u_i^2\ge 0.
\]

因此，固定状态和 donor 时，提高温度对加性一阶漂移的改善对所有有限温度都单调
成立，而不只是在零温附近成立。严格改善的条件是至少存在一个非零方向且其复制
概率尚未饱和。

核相对历史扩散核的代价满足

\[
\operatorname{KL}(q_\tau\Vert q_0)
=\tau D(\tau)-\Psi(\tau).
\]

当 `eta=0.5` 时，每个 active 块还有简单关系

\[
\operatorname{KL}(\mathrm{Ber}(p_i)\Vert\mathrm{Ber}(0.5))
=\log 2-H(p_i).
\]

所以平均 KL 和相对最大熵是同一代价的两个口径；一般 `eta` 下不能直接用
`log(2)-H` 代替 KL。

上述闭式关系针对未截断的数学 logistic 核。数值实现把 logit 截到 `[-30,30]`；
截断生效前两者完全一致，生效后漂移仍随温度非减，但饱和项不再严格增加，且不能
再用同一个全局 `tau` 的配分函数恒等式替代直接 KL 计算。实验因此直接从实际复制
概率计算 KL、熵和利用率。

## 3. 符号极限与利用率

当 `tau` 趋于正无穷时，正方向复制概率趋于 1，负方向趋于 0，中性方向保持
`eta`。加性一阶漂移的符号极限是

\[
D_\infty=\sum_i\max(u_i,0),
\]

历史核漂移为 `D_0=eta * sum_i u_i`。定义当前温度对可用核内改善的利用率

\[
U(\tau)=\frac{D(\tau)-D_0}{D_\infty-D_0}.
\]

只要存在非零方向，分母为正，且 logistic 路径上 `U(tau)` 从 0 单调趋近 1。
这个极限是诊断参照，不是推荐算法：它正是实际上的符号门控极限，反向传播和熵会
随温度继续升高而消失。实现中的有限 logit 截断只保证浮点概率不精确等于 0/1，
不能把 `1e-13` 量级的反向概率解释成有意义的扩散。

实现记录的加性漂移诊断使用原始比例方向 `d_i`；比例缩放会同时作用于分子和分母，
不改变利用率。若换算到计数残差的一阶量，在忽略交互和变异时还需乘以记录数与
参与率，即近似为 `N * rho * sum_i p_i d_i`。

## 4. 这个“极限”不是完整生成器的上界

上面的结论只在当前核族内精确。完整生成器至少还有四层不同的限制，不能混成一个
“温度没调够”的结论：

1. **温度—KL 限制**：同一批单块方向已经给定，有限温度尚未用完多少符号极限
   漂移；由 `U(tau)`、KL、熵和正反向复制概率衡量。
2. **独立单块近似限制**：同一记录可能同时复制多个属性。合取查询中的协同或抵消
   使单块方向之和不等于最终 hybrid 的完整方向；精确 proposal 还有二次步幅惩罚
   和无方向变异。
3. **donor 支持限制**：复制核只能使用本轮 donor 已提供的值。需要的局部状态若不
   在合成支持集中，任何温度都无法创造该 donor 块；这与温度无关。
4. **workload 信息限制**：未测量高阶关系没有进入残差场。即使训练 workload
   完全拟合，也不能据此保证未测量高阶查询或离线 TVD 同步改善。

因此，温度扫描达到质量平台后，下一步应先用诊断判断是哪一层成为主瓶颈，再分别
研究联合块扩散、donor/支持集机制或 workload；不能继续靠提高温度把符号门控当作
扩散创新。

## 5. 实验阶梯

### 5.1 冻结状态的核因果前沿

固定状态、残差、donor、参与随机数、复制随机数和变异随机数；不同温度只改变
Bernoulli 概率。不执行整代接受。报告：

- 精确原始 proposal 收益及一阶/二次分解；
- 相对 baseline 的逐提案胜负；
- 平均 KL、熵、正反向复制概率；
- 加性漂移改善和符号极限利用率；
- 改动单元格与记录数。

### 5.2 关闭整代接受的动力学前沿

每个 proposal 都进入下一状态，最终当前表是主终点，不用 best checkpoint 回滚。
这一步检验正向动力能否由扩散核自身累积，但 donor 仍按原适应度和距离机制抽取，
所以不能解释成脱离 donor 选择的纯扩散。

### 5.3 标准接受闭环

沿用历史 500 轮正式配置和配对种子，只改变温度。主指标仍包括接受前原始 proposal，
最终 best loss 只是完整闭环终点。三种子只用于寻找转折区间；正式方向性结论使用
十种子，并保留失败种子。

### 5.4 跨 workload 验证

只有训练侧指标冻结候选温度或约束后，才运行 nltcs。至少同时报告训练 workload、
未测量高阶查询、训练/测试 TVD、支持集指标、墙钟和关键阶段次数。离线指标不进入
生成、早停或 checkpoint 选择。

配对置信区间为 `[-45.83, -22.97]`；接受前平均 proposal 收益也 10/10 改善，
平均差为 +1.376。正收益事件比例反而从 33.18% 降到 29.08%，再次说明收益来自
方向幅度分布变化，不是更频繁地制造可接受事件。

高温前沿显示两个不同的极限口径：

- `tau=16` 相对 `tau=8` 的最终 loss 平均差为 +0.15，5 胜、1 平、4 负；接受前
  平均 proposal 收益差为 +0.092，均没有稳定改善，但熵和反向概率已经明显下降。
- `tau=32/64` 相对 `tau=8` 的最终 loss 分别再低 3.35/4.25；不过二者彼此平均只差
  -0.90，95% 配对区间为 `[-5.01, 3.21]`。两者接受前平均 proposal 收益都没有
  超过 `tau=8`，而负向概率已经降到 5.72%/0.78%。

因此，在这个 workload 和 500 轮预算下，接近符号门控的“纯训练 loss 极限”约为
14，而保留实际反向扩散的 Pareto 拐点在 `tau=8` 附近。`tau=8` 已取得从 baseline
到 `tau=64` 训练 loss 总改善的约 95.6%，同时保留 27.05% 的负向复制概率；把剩余
约 4.4% 的 loss 空间继续压掉，需要让核接近确定性门控。十种子仍只是较强方向性
证据，且这里查看了多个温度，不能把未经跨 workload 验证的 p 值包装成通用最优。

## 7. 当前判断与后续候选

现有证据已经否定“`tau=1` 接近当前理论极限”：在冻结 proposal、关闭接受的动力学
和标准闭环三种口径下，`tau=4/8` 都有尚未用尽的核内空间。它也同时否定“温度越高
越好”：冻结状态在 `tau=8` 后精确 proposal 收益平台化，标准闭环在 `tau=32/64`
进入训练 loss 平台，但扩散熵和反向概率仍持续损失。

下一步可以研究一个仍属于扩散核本身的受约束候选：保留固定温度的自然冷却，但在
每轮用 KL 上限限制早期过硬的倾斜，即求解

\[
\max_q\;\mathbb E_q[\text{加性方向}]
\quad\text{s.t.}\quad
\frac{1}{B}\operatorname{KL}(q\Vert q_0)\le \kappa.
\]

其解仍是同一个 logistic 族，只需用单调一维求根确定有效温度；它不是正负门控或
候选筛选。是否实现必须另立小目标，并先明确 KL 上限、晚期冷却语义和训练侧选择
规则。若高温平台主要来自多块交互而不是 KL 约束，则应优先转向联合块扩散，不应
继续调温。
