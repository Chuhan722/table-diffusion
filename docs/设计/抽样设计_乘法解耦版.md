# 抽样设计：乘法解耦版（Multiplicative Decoupling）

## 设计背景

### 原设计的问题

现有抽样分数（linear 模式）：
```
ℓ_ik = β·F(z_k) − d(x_i, z_k) / h
```

两项相加,存在两个问题:

1. **量级匹配难题**：F 的量级由查询数 m、残差幅度、残差相关性决定,跨数据集不稳定;d∈[0,1] 有界。要让两项"平衡",需要让 β·F 和 d/h 在同一量级,但:
   - F 的量级只能实测,换数据/查询就变(nltcs 上 |F|≈1.7)。
   - β 和 h 需要协同调整才能匹配,调参空间耦合、不直觉。

2. **硬门槛的坍缩风险**：若改用硬门槛(距离 > r 直接排除),虽然绕开量级问题,但会丢失"逃逸通道"——圈外候选概率彻底为 0,导致"相似→只互抽→更相似"的正反馈,容易坍缩到少数重复记录。

### 设计目标

找一个新的抽样结构,同时满足:
- **不需要匹配 F 和 d 的量级**：两者各自独立,调参解耦。
- **不会坍缩**：远候选始终保留一丝概率(逃逸通道),避免硬门槛的正反馈。
- **调参好做**：参数有界、可直觉估、跨数据集含义稳定。

---

## 设计方案：适应度 softmax × 有界距离权重

### 核心思路

**让适应度和距离各自算各自的,最后把两个概率相乘。**

不再是"把两个数加成一个分数",而是"一个因子管好坏、一个因子管远近,相乘得最终概率"。

### 完整公式

对当前记录 x_i,从 K 个候选 {z_1, ..., z_K} 中抽取参考对象:

**第 1 步：适应度概率**（只看候选好坏,候选之间比）
```
p_F(k) = exp(β · F(z_k)) / Σ_j exp(β · F(z_j))
```
- 标准 softmax,在 K 个候选间做归一化。
- β 控制锐度：β 大→高适应度候选陡升,低的陡降;β=0→完全均匀。

**第 2 步：距离权重**（只看记录 i 到候选 k 的远近）
```
w_ik = (1 − d_ik)^p
```
- d_ik ∈ [0,1] 归一化汉明距离 → w_ik ∈ [0,1] 有界权重。
- p 控制陡度：p 越大→权重随距离衰减越快,越偏近邻;p=0→w 恒为 1,忽略距离。

**第 3 步：相乘得未归一化概率**
```
π_ik = p_F(k) × w_ik
```

**第 4 步：按行归一化**（每条记录的候选概率和为 1）
```
p(k | i) = π_ik / Σ_j π_ij
```

**第 5 步：按概率抽样**

每条记录 i 按分布 p(·|i) 抽一个候选索引,得到参考记录。

---

## 为什么这个设计能同时解决两个问题

### 1. 不需要匹配量级

**原因**：两个因子从不相加,F 和 d 的绝对大小永远不需要比较。

- **p_F(k)** 是 softmax,天然对 F 的绝对量级不敏感：
  - F 整体加一个常数 → softmax 结果不变。
  - F 的绝对大小被 β 和 exp 自动吸收,只有候选之间的**相对差异 × β** 起作用。
  - 换句话说,F 爱多大多大,softmax 自动归一化到 [0,1],不用手动匹配。

- **w_ik** 天然有界 ∈ [0,1],和 F 多大毫无关系。

- 两者相乘后再归一化,**F 和 d 从头到尾没有"加"的动作,不存在量级匹配问题**。

**调参解耦**：
- β 只管"多看重适应度好坏"(softmax 的锐度)。
- p 只管"多看重远近"(权重衰减的陡度)。
- 两个钮各调各的,不用协同匹配——这才是对"调参好做"的实质改善。

### 2. 不会坍缩

**原因**：w_ik = (1−d_ik)^p 永远 > 0(除非 d=1,但实际数据不会所有属性都不同)。

- 远候选权重小但**非零**,相乘后仍有一丝概率被选中 → **逃逸通道存在**。
- 对比硬门槛(圈外 w=0):w=0 焊死"相似→只互抽→更相似"的正反馈,导致坍缩。
- 软权重 w>0 时不时从远处拉个不一样的候选进来,打破正反馈,坍缩风险和现在的 linear 相当(低)。

---

## 两个调节钮的直觉含义

### β（选择强度,控制适应度的锐度）

- **β=0**：p_F 退化成均匀分布,完全随机,忽略适应度。
- **β 小**（~0.5）：各候选概率拉平,探索性强。
- **β=1**（默认）：正常。
- **β 大**（~5）：高适应度候选陡升、低的陡降,锐利收敛。

### p（距离陡度,控制权重衰减速度）

- **p=0**：w 恒为 1,完全忽略距离,退化成纯适应度抽样。
- **p=1**（默认,线性衰减）：d=0.5 时 w=0.5,远近影响温和。
- **p=2**（二次衰减）：偏近邻,d=0.5 时 w=0.25。
- **p 大**（~5）：强烈偏近邻,远的几乎零权重(但不彻底为 0)。

**关键特性**：两个钮独立,β 管"多看重好坏",p 管"多看重远近"。不用让"β 的项"和"p 的项"一样大——这就是"躲掉量级匹配"的实际体感。

## 与现有模式的对比

| 模式 | 公式 | 量级问题 | 坍缩风险 | 逃逸通道 |
|------|------|---------|---------|---------|
| **linear**（当前默认） | ℓ = β·F − d/h | 有(需匹配) | 低 | 有(软) |
| squared | ℓ = β·F − d²/(2h²) | 有(需匹配) | 低 | 有(软) |
| none | ℓ = β·F | 无 | 低 | 无(但无距离约束,收敛差) |
| **multiplicative**（本设计） | p ∝ softmax(β·F) × (1−d)^p | **弱**(解耦成形状钮) | **低** | **有(软)** |

**multiplicative 是唯一同时占两头的**：
- 量级问题退化成"两个有界形状钮"(β 的锐度、p 的陡度),好调、可直觉估、跨数据集稳定。
- 软权重 w>0 保留逃逸通道,坍缩风险低。

---

## 剩余的弱交互（诚实交代）

**距离的实际影响力,取决于 p_F 有多"尖"。**

- 若某候选的 p_F(k)≈1(适应度远超其它),乘上 w 几乎不改这个候选的概率 → 距离被忽略。
- 若 p_F 很平(各候选适应度接近),w 说了算 → 距离主导。

**这个交互没消失**,但它和原来的"量级匹配"有本质区别:
- 原来：需要让"βF 和 d/h 在同一量级"这种跨单位、跨数据集乱飘的匹配,没法直觉估。
- 现在：交互退化成"两个各自有界/归一的形状钮"(β 的锐度、p 的陡度),直觉清楚、跨数据集稳定。

这是"解耦"的真实含义:**把一个没法直觉估量的量级匹配,换成了两个能直觉估量的形状参数。**

## 实现要点

### 数学关键

**为什么不能用 exp(−d/h) 作权重？**

因为 `softmax(βF) · exp(−d/h) ∝ exp(βF − d/h)` ——指数一乘就退化成相加,量级问题原样回来。

**必须用非指数的有界核**,如 `(1−d)^p`,乘起来不会塌回干净的加法指数形式。

### 代码落点

**sampling.py**:
- `distance_mode` 新增 `'multiplicative'`(与 squared/linear/none 并列,第四种)。
- `compute_sampling_probs` 加参数 `p: float = 1.0`(距离陡度)。
- 在 multiplicative 分支:
  1. F 先过 softmax → p_F (向量,和为 1)。
  2. 距离权重 w = (1−d)^p (矩阵)。
  3. 相乘 π = p_F × w (broadcast)。
  4. 按行归一化 → 直接返回概率矩阵(跳过原来的 softmax 步骤)。
- numpy 和 torch 两条路径都实现。

**evolution.py**:
- `run_evolution` 加参数 `p: float = 1.0`,透传给 `compute_sampling_probs`。
- diagnostics.params 记录 `p`。

### 边界情况

**所有候选适应度相同**：p_F 退化成均匀,只剩 w 说话,纯近邻抽样。自然,不需特判。

**所有候选距离相同**（罕见）：w 全相等,只剩 p_F 说话,纯适应度抽样。自然,不需特判。

**候选可能抽到自己**（玩具阶段）：d=0 → w=1 满权重,若自己适应度也不错,概率会高。合法,不需排除。

**数值稳定**：F-softmax 里减行最大值(标准做法);相乘后归一化分母是行和,不会为 0(至少自己 w=1)。

## 实验验证（2026-07-26/27）

### 实验设置

- 除 distance_mode 和 p 外，两组参数完全一致（控制变量）：β=1.0, ρ=0.01, η=0.5, μ=0.01, init=marginal。
- multiplicative: p=1.0；linear: h=0.8（各自的中性起点，距离影响强度同档，对比公平）。

### 第 1 步：小数据查错（test_300x10, 100 轮, 单种子）✅ 通过

- 无 NaN/inf，loss 下降 29.6%（2021→1422），接受率 40%，参数记录正确。
- 目的：扫雷，确认能跑、不崩、行为正常（非性能对比）。

### 第 2 步：nltcs 单种子对比（1500 轮, seed=0）✅ multiplicative 明显更好

| 模式 | 最优 Loss | 归一化 L1 | 接受率 |
|------|-----------|-----------|--------|
| multiplicative | 7.17e7 | 0.0188 | 46.0% |
| linear | 1.04e8 | 0.0232 | 43.2% |

- loss 相对差 **-31.1%**。
- multiplicative **全程领先**（非后期反超）：第 100 轮 3.20e8 vs 3.43e8，第 500 轮 1.09e8 vs 1.47e8，一路保持。
- linear 后期几乎停滞（1000→1500 轮仅降 ~10%），multiplicative 到 1500 轮仍在降。
- 接受率相近，说明不是靠"更易接受提案"取巧，而是每步质量更高。

### 第 3 步：nltcs 多种子严格对比（1500 轮, seed=0/1/2）✅ 高度显著更好

| 模式 | 最优 Loss (均值±std) | 归一化 L1 (均值±std) | 接受率 |
|------|---------------------|---------------------|--------|
| **multiplicative** | **7.09e7 ± 8.3e5** | **0.0186 ± 0.0002** | ~45% |
| linear | 1.03e8 ± 5.2e5 | 0.0230 ± 0.0001 | ~42% |

- **loss 相对差 -31.4%**，t 检验 **t=-47.0, p=1.2e-6（高度显著）**。
- 三种子明细：mult = 7.17/7.14/6.98e7，linear = 1.04/1.03/1.03e8。
- **两组完全不重叠**：最差的 mult（7.17e7）仍远低于最好的 linear（1.03e8）。
- 方差极小（~均值的 1%），结果稳定；与第 2 步单种子（-31.1%）一致，排除偶然。
- 归一化 L1 同步改善约 19%（0.0230→0.0186），与 loss 结论互相印证。

### 结论

- 乘法解耦在 nltcs 上**显著优于 linear（约 31%，高度显著）**。
- **设计推理得到验证**：解耦 F 和 d 的量级 + 软权重保留逃逸通道，确实带来实质收敛改善。
- **未观察到坍缩**（loss 全程持续下降、接受率正常），印证"软权重 (1−d)^p > 0 保留逃逸通道"的设计判断。
- 耗时与 linear 几乎相同（~1350s/1500轮），乘法的额外计算可忽略。

### 默认值决策（用户定，2026-07-27）

**暂不改默认**（默认仍是 linear），理由：nltcs 单数据集虽 3 种子很稳，但需换数据集才能确认"普遍更好"。multiplicative 作为可选模式已就绪，改默认待更多数据集验证后再定。
