# 曲率收益的共同状态阶段交互

## 1. 问题

Issue #18 在完全相同的冻结状态、donor 和随机流下比较 `gamma=0/1`，发现
`gamma=1` 在三个 500 轮状态上的单步 proposal 相对收益都更高。Issue #24 的
20 配对种子无接受动力学却没有形成长期优势；Issue #27 又表明曲率核会降低查询
空间移动速度，并在按各自轨迹汇总的残差区间中呈现混合漂移。

这两类证据回答的问题不同。冻结探针估计固定状态上的算子差异，长期轨迹则同时
包含算子差异和由历史转移造成的状态分布差异。尤其是 Issue #27 的 baseline 与
candidate 已经处于不同合成表，不能把残差分箱的组间差直接解释为曲率权重关于
残差阶段的因果交互，也不能据此事后选择调度方向或阈值。

本阶段因此只回答：

> 在共同合成状态和共同随机条件下，`gamma=1` 相对 `gamma=0` 的 proposal 收益，
> 是否会从 marginal 初始态到标准闭环 500 轮态稳定增强或减弱？

本阶段是诊断，不实现状态调度，不接入默认生成器。

## 2. 估计量与配对单位

固定 seed `i` 和阶段 `s`，从同一个合成状态生成 200 对 proposal。每对共享
donor、参与掩码、独立初始复制 mask、Gibbs 坐标流和均匀随机流，唯一变量为曲率
权重。记第 `p` 对 proposal 的精确平方 workload 收益为 `G`，定义 seed-state
层面的曲率相对收益

\[
\Delta_{i,s}=\frac{1}{200}\sum_p
\left(G_{i,s,p}^{\gamma=1}-G_{i,s,p}^{\gamma=0}\right).
\]

主估计量是同一 seed 内的阶段交互

\[
I_i=\Delta_{i,500}-\Delta_{i,0}.
\]

`I_i>0` 表示曲率相对优势在 500 轮态更强，`I_i<0` 表示更弱。seed 是独立统计
单位；每个状态的 200 个 proposal 只降低条件蒙特卡洛误差，不能当作 4000 个
独立样本，也不进行 proposal 级显著性检验。

这个差分中的差分仍只覆盖两个预先固定的状态来源，不等于连续残差函数的导数，
也不证明任意中间状态上的单调调度。

## 3. 固定实验协议

- 数据配置：`test_300x10`，公开记录数 300、预定义 50-query 精确 target、公开
  schema 和 1-way marginal；
- 独立种子：固定 `30..39`，不复用既有正式曲率实验的 seed；
- 每个 seed 固定两个共同状态：
  1. 由该 seed 直接生成的 marginal 初始化态；
  2. 标准 0-sweep 残差驱动接受闭环运行 500 轮得到的 best 表；
- 500 轮状态只用于构造共同的冻结输入；两个曲率变体都不参与该状态的选择；
- 同一 seed 的两个状态共享标准闭环在初始阶段确定的首个非零方向 RMS，避免按
  后期状态重新标定温度；直接初始化表必须与闭环记录的初始表哈希一致；
- 每个状态 200 对 proposal，共 `10 × 2 × 200 = 4000` 对；探针不执行整代接受、
  重试、早停或 checkpoint 选择；
- baseline 为 `gamma=0`，candidate 为 `gamma=1`；
- 固定 `rho=0.01`、`eta=0.5`、proposal 内 `mu=0`、`tau=2`、8 sweep、最高
  三阶因子和条件 logit 护栏 30；
- donor 使用既有 geometric 抽样；初始态 `alpha=2`，500 轮态 `alpha=10`；
- Conda `gsd`、CUDA 0 串行运行；墙钟只作诊断，不是方法终点；
- 不读取真实训练表或测试表，不报告联合 TVD；当前是精确统计量下的无噪声原型，
  不是端到端 DP。

正式运行不得追加 seed、扫描 `gamma/rho/tau/sweep` 或根据结果改变阶段定义。

## 4. 主统计与预注册分类

对 10 个 `I_i` 报告均值、样本标准差、中位数、范围、正/零/负种子数，以及以
seed 为单位、自由度 9 的双侧 95% t 区间。预注册分类为：

1. 区间下界大于 0，且至少 8/10 个 seed 的 `I_i>0`：
   `curvature_advantage_strengthens_late`；
2. 区间上界小于 0，且至少 8/10 个 seed 的 `I_i<0`：
   `curvature_advantage_weakens_late`；
3. 其余：`state_interaction_inconclusive`。

同时分别报告初始态与 500 轮态的 10 个 `Delta`、95% t 区间和方向计数。阶段交互
的显著方向不能覆盖绝对效应：例如两个阶段都不利但晚期较少不利，只能说明交互，
不能据此推荐开启曲率。任何调度候选还必须结合两个阶段的绝对方向，并在后续独立
Issue 中预注册长期动力学终点。

## 5. 次要诊断

为解释交互而不改变主分类，按阶段和 seed 报告：

- `gamma=0/1` 的一阶收益、总二次项、净收益与正收益率；
- 查询步平方范数、改变行数、复制单元格数和 mask Hamming；
- 条件微步数、平均熵、最小/最大条件概率与最大绝对 logit；
- 冻结状态的 workload loss 和 RMS 计数残差；
- 状态构造、因子构造、Gibbs 抽样和完整探针墙钟。

这些量用于判断交互来自一阶项、曲率代价还是移动量变化，不在看到结果后升级为
新的成功门槛。

## 6. 语义与复现门禁

正式分类前必须全部满足：

1. 每个 seed 恰有一个直接初始态和一个 500 轮闭环状态，二者初始表哈希一致，
   方向参考尺度正有限；
2. 每对 proposal 的 donor、参与、完整初始 mask、主 RNG 与 Gibbs RNG 对齐；
3. `gamma=0` 与既有因子 Gibbs 的最终表、mask、共同诊断、RNG 端点和条件概率
   精确一致；
4. 内部查询变化与直接整表评价一致；行增量求和、
   `gain=linear-quadratic`、`quadratic=self+cross` 及 `N*V_1=gain` 的最大误差
   不超过 `1e-10`；
5. 条件 logit 护栏零命中，全部条件概率严格双向；所有正式数值有限；
6. 正式运行要求 tracked 工作树干净，输出拒绝覆盖并记录 commit、完整命令、环境、
   GPU、公开输入哈希和全部逐 proposal 原始结果；
7. 独立读取正式 JSON，重新计算 20 个 seed-state、10 个阶段交互、区间、分类、
   门禁与输入哈希；
8. `py_compile`、针对性测试、完整 CPU/torch/CUDA 测试和 `git diff --check`
   通过。

任一门禁失败时只报告诊断失败，不给出阶段交互分类。

## 7. 决策边界

本实验固定 `rho=0.01`，与 Issue #29 的参与率衰减调度正交。它不修改默认参数，
不实现残差阈值或内禀时钟控制，不接入 select-measure 流程，也不使用真实联合 TVD
驱动生成、阶段判断或输出选择。

若结果支持晚期增强或减弱，下一步仍需根据绝对阶段效应另立 Issue，冻结一个只依赖
公开查询残差或内禀时钟的有限温调度，并用无接受动力学检验。若结果不确定，则不
事后扫描阈值或参数，优先承认证据精度或两阶段概括不足。

关联 Issue #30、#29、#27、#24、#18。
