# 统一参数配置改造方案

## 背景

当前参数配置混乱：
- `scripts/run.py` 在顶部用常量硬编码参数
- `experiments/*.py` 用字典硬编码参数
- `configs/` 目录只存数据文件，不存算法参数
- `experiment_config.py` 有数据类定义，但没人用

**问题**：
1. PR #36 问题 2.2：配置不完整，`ExperimentConfig` → `run_evolution` 没有完整映射
2. 每个脚本重复定义参数，容易不一致
3. 要改参数必须改脚本源码

## 目标

- `ExperimentConfig` 作为唯一参数源头
- 所有脚本都用这套配置体系
- 实现完整的配置 → 参数映射（关掉 PR #36 问题 2.2）
- 同时实现 W/H 改名（问题 2.1）和 logger 原子性（问题 1）

## 设计

### 1. 补全 `ExperimentConfig`

把 `scripts/run.py` 里的所有常量都搬进去，加完整注释：

```python
@dataclass
class ExperimentConfig:
    # ========== 数据配置 ==========
    schema_path: str
    """数据模式文件路径（YAML），定义属性类型和合法值域"""
    
    query_path: str
    """查询workload文件路径（JSON），包含查询定义和真实计数"""
    
    n_records: int
    """合成表记录条数"""
    
    # ========== 运行控制 ==========
    n_rounds: int = 1000
    """最大演化轮数。可能因探测平台或candidate_budget提前停止"""
    
    seed: int = 0
    """随机种子，确保可复现"""
    
    device: str = 'cuda'
    """计算设备：'cuda'(GPU) | 'cpu'(PyTorch CPU) | 'numpy'(纯NumPy)"""
    
    log_every: int = 50
    """进度打印频率。0=每轮打印，>0=每N轮打印"""
    
    candidate_budget: Optional[int] = None
    """全局候选评估次数预算（可选）。None=不限制，整数=达到后停止"""
    
    # ========== 算法核心 ==========
    beta: float = 1.0
    """选择强度（固定值）"""
    
    h: float = 0.8
    """邻域尺度（固定值）"""
    
    rho: float = 0.01
    """记录参与率，范围(0,1]。小值精修，大值快速收敛但易过冲"""
    
    eta: float = 0.5
    """块复制率，范围[0,1]"""
    
    mu: float = 0.01
    """变异率，范围[0,1]"""
    
    # ========== 距离和抽样 ==========
    distance_mode: str = 'geometric'
    """抽样模式：'geometric'(推荐) | 'multiplicative' | 'linear' | 'squared' | 'none'"""
    
    lambda_param: float = 0.5
    """适应度-距离权衡（geometric模式）。0=纯距离，1=纯适应度，0.5=均衡"""
    
    alpha_min: float = 2.0
    alpha_max: float = 10.0
    """锐度调度范围（geometric模式）。前期小广探索，后期大精挑。推荐2→10"""
    
    delta: float = 0.05
    """下界防止log(0)（geometric模式）"""
    
    winsorize_quantiles: Tuple[float, float] = (0.01, 0.99)
    """稳健归一化分位点（geometric模式），裁剪极端适应度"""
    
    exclude_self: bool = True
    """禁止记录抽到自己作为donor（候选池=全表时）"""
    
    # ========== 初始化 ==========
    init_method: str = 'pairwise_maxent'
    """初始化方式：'pairwise_maxent'(推荐) | 'marginal' | 'random'"""
    
    marginals_path: Optional[str] = None
    """边缘测量文件路径（仅init_method='marginal'时需要）"""
    
    maxent_max_states: int = 1_000_000
    """二阶最大熵最大状态数（仅pairwise_maxent）"""
    
    maxent_max_sweeps: int = 200
    """IPF最大扫描轮数（仅pairwise_maxent）"""
    
    maxent_tol: float = 1e-8
    """二阶单元概率误差阈值（仅pairwise_maxent）"""
    
    # ========== 查询评估 ==========
    eval_method: str = 'vectorized'
    """查询评估方式：'vectorized'(快，默认) | 'legacy'(慢，对拍用)"""
    
    batch_size: int = 256
    """向量化评估分块大小（仅vectorized模式）。越大越快但越吃内存"""
    
    # ========== 残差驱动扩散核（研究候选，默认关闭）==========
    residual_directed_diffusion: bool = False
    """是否启用残差驱动的局部扩散核"""
    
    diffusion_direction_strength: float = 1.0
    """扩散方向倾斜强度（仅residual_directed_diffusion=True）"""
    
    diffusion_direction_normalization: str = 'initial_rms'
    """方向归一化方式：'initial_rms' | 'raw'"""
    
    # ========== 缩步重试（默认关闭）==========
    max_retries: int = 0
    """整代拒绝后重试次数。0=不重试，保持历史行为"""
    
    retry_rho_decay: float = 0.5
    """重试时rho衰减因子。每次重试rho乘以此值"""
    
    # ========== 接受规则 ==========
    acceptance: AcceptanceConfig = field(default_factory=lambda: AcceptanceConfig(rule='A0'))
    """接受规则配置。默认A0（严格Q改善）"""
    
    # ========== Alpha探测调度（可选）==========
    alpha_schedule: Optional[AlphaScheduleConfig] = None
    """探测式调度配置。None=固定线性调度，非None=启用停滞探测"""
    
    def to_run_evolution_kwargs(self) -> dict:
        """配置 → run_evolution 参数的完整映射"""
        kwargs = {
            'n_records': self.n_records,
            'n_rounds': self.n_rounds,
            'seed': self.seed,
            'device': self.device,
            'log_every': self.log_every,
            'beta': self.beta,
            'h': self.h,
            'rho': self.rho,
            'eta': self.eta,
            'mu': self.mu,
            'distance_mode': self.distance_mode,
            'lambda_param': self.lambda_param,
            'alpha_min': self.alpha_min,
            'alpha_max': self.alpha_max,
            'delta': self.delta,
            'winsorize_quantiles': self.winsorize_quantiles,
            'exclude_self': self.exclude_self,
            'init_method': self.init_method,
            'marginals': None,  # 需要外部加载
            'eval_method': self.eval_method,
            'batch_size': self.batch_size,
            'residual_directed_diffusion': self.residual_directed_diffusion,
            'diffusion_direction_strength': self.diffusion_direction_strength,
            'diffusion_direction_normalization': self.diffusion_direction_normalization,
            'max_retries': self.max_retries,
            'retry_rho_decay': self.retry_rho_decay,
            'maxent_max_states': self.maxent_max_states,
            'maxent_max_sweeps': self.maxent_max_sweeps,
            'maxent_tol': self.maxent_tol,
        }
        
        # 处理 candidate_budget
        if self.candidate_budget is not None:
            kwargs['candidate_budget'] = self.candidate_budget
        
        # 处理 alpha_schedule（如果有）
        if self.alpha_schedule:
            kwargs.update(self.alpha_schedule.to_kwargs())
        
        # 处理 acceptance
        kwargs.update(self.acceptance.to_kwargs())
        
        return kwargs
```

### 2. 修改 `AlphaScheduleConfig` - W/H 改名

```python
@dataclass
class AlphaScheduleConfig:
    """探测式alpha调度配置"""
    
    probe_block_candidate_budget: Optional[int] = None
    """块大小W：检测停滞的候选评估次数窗口（改名自probe_block_size）"""
    
    probe_H_candidate_budget: Optional[int] = None
    """探测预算H：每个分支的候选评估次数上限（改名自probe_H）"""
    
    probe_P: Optional[int] = None
    """连续失败阈值P：连续P次探测全失败判定为经验平台"""
    
    probe_eps_L1: Optional[float] = None
    """L1改善阈值：块内平均L1下降 < eps_L1 判定为停滞"""
    
    probe_alpha_step: Optional[float] = None
    """探测步长：UP/DOWN分支的alpha调整幅度"""
    
    def to_kwargs(self) -> dict:
        """转换为 run_evolution 参数"""
        return {
            k: v for k, v in {
                'probe_block_candidate_budget': self.probe_block_candidate_budget,
                'probe_H_candidate_budget': self.probe_H_candidate_budget,
                'probe_P': self.probe_P,
                'probe_eps_L1': self.probe_eps_L1,
                'probe_alpha_step': self.probe_alpha_step,
            }.items() if v is not None
        }
```

### 3. 改造 `scripts/run.py`

```python
"""
扩散演化运行入口

一键跑一组多种子演化并自动落盘。
调参方式：修改下面的配置对象，改完再跑。
"""
from table_diffevo.experiment_config import ExperimentConfig, AcceptanceConfig
from table_diffevo.schema import load_schema
from table_diffevo.queries import load_queries
from table_diffevo.evolution import run_evolution
from table_diffevo.io import save_run, create_parent_dir, save_summary
from table_diffevo.marginals import load_marginals

# ========== 参数配置（调参改这里） ==========
CONFIG = ExperimentConfig(
    # 数据
    schema_path="configs/nltcs/schema.yaml",
    query_path="configs/nltcs/measured_1000query.json",
    n_records=16181,
    
    # 运行
    n_rounds=600,
    device='cuda',
    log_every=50,
    
    # 初始化
    init_method='pairwise_maxent',
    
    # 其他参数用默认值（在 ExperimentConfig 定义）
)

SEEDS = [0, 1, 2]  # 多种子
# ===========================================

def main():
    schema = load_schema(CONFIG.schema_path)
    queries = load_queries(CONFIG.query_path)
    target = np.array([q["result"] for q in queries])
    
    # 加载边缘测量（如果需要）
    marginals = None
    if CONFIG.init_method == 'marginal':
        marginals = load_marginals(CONFIG.marginals_path)
    
    parent_dir = create_parent_dir()
    per_seed = []
    
    for i, seed in enumerate(SEEDS):
        print(f"\n===== 种子 {seed}（{i + 1}/{len(SEEDS)}）=====")
        
        # 更新种子
        CONFIG.seed = seed
        kwargs = CONFIG.to_run_evolution_kwargs()
        kwargs['marginals'] = marginals  # 外部加载的数据
        
        best_S, diagnostics = run_evolution(target, queries, schema, **kwargs)
        
        # 保存和打印...
        sub_name = f"{i}-{seed}"
        run_dir = save_run(best_S, diagnostics, run_dir=os.path.join(parent_dir, sub_name))
        # ...
```

## 实施步骤

按顺序，每步一个小 commit：

1. **补全 `ExperimentConfig`**（`src/table_diffevo/experiment_config.py`）
   - 把 `scripts/run.py` 的所有常量搬进去
   - 加完整注释
   - 实现 `to_run_evolution_kwargs()` 方法

2. **修改 `AlphaScheduleConfig`**
   - `probe_block_size` → `probe_block_candidate_budget`
   - `probe_H` → `probe_H_candidate_budget`
   - 更新注释说明单位是"候选评估次数"

3. **改造 `scripts/run.py`**
   - 用 `ExperimentConfig` 替换顶部常量
   - 保持行为不变（验证：同参数跑出的结果一致）

4. **实现 logger 原子性（方案A）**
   - `experiment_logger.py` 改为先写临时目录
   - 全部成功后原子移动到目标目录
   - 加完成标记文件

5. **实现 candidate_budget 全局预算**
   - `evolution.py` 加全局计数器
   - 检查预算，达到后停止
   - 返回区分的 `stopped_reason`

6. **更新测试**
   - 配置验证测试
   - 映射完整性测试

## 好处

- **单一源头**：参数默认值只在 `ExperimentConfig` 定义一次
- **脚本简洁**：只写差异，不重复定义
- **类型安全**：IDE 补全、类型检查
- **可追溯**：`diagnostics.params` 直接从配置对象生成
- **关掉 PR #36 多个问题**：2.1（W/H改名）+ 2.2（配置完整）+ 1（logger原子性）

## 风险

- 改动面较大（涉及配置、演化主循环、两类脚本）
- 需要确保向后兼容（旧脚本仍能跑）
- 测试覆盖要到位
