# 曲率核多步漂移与内禀扩散时钟

## 1. 问题与已知证据

Issue #18 在相同晚期状态、donor 和随机源下证明，`gamma=1` 的整代曲率条件式比
`gamma=0` 更能降低一次 proposal 的二次过冲。Issue #24 把相同算子放入 20 配对
种子、1000 轮无接受轨迹后，candidate 的末 250 轮平均 loss 反而高 5.80%，只有
5/20 个种子改善。固定状态的一步排序没有转化为分叉轨迹的长期优势。

长期结果还显示 candidate 的每轮改单元格数降低 7.66%，正负收益步幅同时收缩。
因此失败可能混合了两个效应：

1. **时间尺度变化**：candidate 主要把同类扩散走慢，固定 1000 轮比较没有对齐
   状态空间内禀时间；
2. **漂移几何变化**：candidate 在相同状态区域改变了漂移与扩散的相对关系，即使
   对齐路径长度仍进入不同状态分布。

在写本设计前，对 Issue #24 输出做过一次事后改单元格时钟探索。candidate/baseline
累计改单元格数比为 0.9235；在每个种子的共同累计改单元格范围内，用 251 个等距点
比较末四分之一路径，聚合 loss 差由按轮数的 `+5.797` 缩小到 `+1.738`，配对改善
数由 5/20 变为 8/20。固定 loss 分段下又能看到非统一的条件漂移差异。这个时钟、
窗口和分段均在看到长期结果后选择，只能用于提出问题，不进入新的正式证据。

## 2. 查询空间诊断定义

每轮更新前后的计数查询向量分别记为 `q_t` 与 `q_{t+1}`，实际查询步为

\[
\Delta q_t=q_{t+1}-q_t.
\]

它包含最终落地的复制和变异，不使用更新器内部仅描述复制 mask 的近似量。计数残差
为 `e_t=target-q_t`。当前无噪、等权平方 loss 满足逐轮恒等式

\[
L_t-L_{t+1}
=\langle e_t,\Delta q_t\rangle
-\frac12\lVert\Delta q_t\rVert_2^2.
\]

分别记录：

- 残差平方范数 `||e_t||^2`；
- 查询步平方范数 `a_t=||Delta q_t||^2`；
- 线性收益 `<e_t,Delta q_t>` 与二次代价 `a_t/2`；
- 累计查询二次变差 `A_t=sum_{s<t} a_s`；
- 累计改单元格数 `H_t`，只作为已披露的事后近似时钟对照；
- 每个合成状态的 50 维整数查询计数 `q_t` 及其 SHA-256；审计从整数向量重新计算
  `Delta q_t`、残差、收益恒等式与两个时钟，不保存真实训练表或测试表。

这些量只在已有查询评价后计算和落盘，不消费随机数，不进入 donor、更新、停止、
参数调度或输出选择。

## 4. 主诊断：匹配查询二次变差

对每个种子分别构造 baseline/candidate 的 `(A_t,L_t)`。`A_t` 单调不减；若相邻
时刻二次变差相同，查询向量与 loss 也必须相同，压缩时保留最后一个重复点。定义
共同终点

\[
A_i^*=\min(A_{i,0}^{final},A_{i,1}^{final}).
\]

在 `[0.75 A_i^*, A_i^*]` 上取含端点的 251 个等距点，对两侧 loss 做分段线性
插值。每种子的主差异为这些点上 `candidate-baseline` 的平均值 `D_i^A`。报告：

- 20 个 `D_i^A`、均值、中位数、范围和改善/相同/变差种子数；
- 以种子为独立单位的均值 95% t 区间；
- 两侧最终 `A` 的比值；
- 已知按轮数末 250 轮差异 `D_i^round`，但不把两个时钟混为同一终点。

预先固定的诊断分类为：

1. `clock_efficiency_advantage_but_round_slowdown`：`D^A` 均值区间上界小于 0；
2. `drift_disadvantage_after_clock_matching`：`D^A` 均值区间下界大于 0；
3. `time_rescaling_material_residual_inconclusive`：区间包含 0，且
   `|mean(D^A)| <= 0.5 * |mean(D^round)|`；
4. 其它情况为 `mixed_or_inconclusive_multistep_effect`。

这个分类只回答固定有限轨迹上的机制，不证明两个高维 Markov 核存在严格时间变换，
也不提供算法优劣或默认切换依据。

## 5. 次要诊断

### 5.1 累计改单元格时钟

对 `H_t` 使用与第 4 节完全相同的共同范围、251 点和末四分之一规则。它用于复核
设计前已披露的事后线索，只作描述，不参与正式分类。

### 5.2 状态依赖漂移

用 baseline 全部更新前状态的 RMS 计数残差
`sqrt(||e_t||^2 / 50)` 构造等频十分位边界；candidate 使用同一组边界。每个种子、
每个区间至少有 10 次转移时，报告：

- 实际平均 gain、查询二次变差和改单元格数；
- `sum(gain)/sum(a_t)`，即每单位查询二次变差的净漂移；
- 正/零/负收益比例。

分段边界由 baseline 决定是为了覆盖其状态范围，不用于选择 candidate 的有利区间。
这些量只解释主诊断，不设置额外成功门槛，不使用 round 级样本量冒充独立重复。

## 6. 语义与复现门禁

正式分类前必须全部满足：

1. 新脚本读取的参考文件 SHA-256 与第 3 节一致；
2. 40 条新轨迹的旧字段除方向/因子/Gibbs/总墙钟外，与参考文件逐字段精确一致；
3. 40,000 次转移的 loss、gain、改单元格数、整数查询向量和向量哈希完整，主 RNG、
   Gibbs seed 与 endpoint 摘要逐种子一致；
4. 每轮收益恒等式最大绝对误差不超过 `1e-12`，累计时钟有限、非负且单调；
5. 40 条轨迹都跑满 1000 轮，全部失败种子保留，输出严格有限；
6. 正式运行要求 tracked 工作树干净，记录 commit、完整命令、环境、GPU 和公开输入
   哈希，并拒绝覆盖输出；
7. 独立审计从逐轮整数查询向量复算残差、实际查询步、收益恒等式、两个时钟、主
   差异、区间、状态分段和最终分类；
8. 针对性测试与完整 CPU/torch/CUDA 测试通过。

任一门禁失败时只报告实现或实验失败，不给出机制分类。

## 7. 决策边界

本阶段不实现自适应扩散时间、曲率调度、接受规则或新算子。若结果主要支持时间尺度
解释，后续仍需另立 Issue 定义不依赖真实数据的扩散时钟控制；若匹配时钟后仍有漂移
劣势，则下一算子必须改变状态依赖漂移，而不是只补偿轮数。若结果混合或精度不足，
应先扩大诊断能力，不事后扫描 `gamma/rho/tau/sweep`。

关联 Issue #27、#24、#18、#17、#16。

## 8. 正式结果（2026-08-04）

### 8.1 复现与审计门禁

正式重放基于干净提交 `0fca33a`，在 Conda `gsd`、CUDA 0、RTX 4090 上一次性
完成 20 个配对种子的 40 条 1000 轮轨迹。原 Issue #24 的 2400 个非计时字段逐项
精确一致；40 条轨迹全部跑满，条件 logit 护栏零命中，所有条件概率保持双向支持。

输出包含 40,040 个 50 维整数查询向量和 40,000 次转移。内置门禁与随后独立读取
审计都重新计算了向量哈希、残差、loss、gain、查询二次变差、收益恒等式和累计
时钟，最大恒等式误差为 0。独立审计还重新计算了匹配时钟统计、种子级区间、状态
分段和最终分类，均与正式输出一致。

### 8.2 主诊断

原按轮数结果被精确复现：末 250 轮 `candidate-baseline` 平均 loss 差为
`+5.7973`，95% t 区间 `[-1.5963, 13.1909]`，配对为 `5/0/15`。candidate 的
最终累计查询二次变差只有 baseline 的 `0.83261` 倍，20 个种子的比值范围为
`[0.78587, 0.89355]`；而累计改单元格数比为 `0.92352`。因此曲率核不只减少了
改单元格数，还系统性缩短了每次表更新在 workload 查询空间造成的位移。

在每个种子的共同查询二次变差范围内匹配末四分之一路径后，平均 loss 差变为
`-6.8990`，中位数 `-8.0246`，配对为 `13/0/7`。不过种子级标准差为 `17.3555`，
95% t 区间仍跨过 0，为 `[-15.0216, 1.2236]`；匹配终点差也只有 `9/0/11`，
区间 `[-18.1798, 7.9635]`。预注册分类因此是
`mixed_or_inconclusive_multistep_effect`，不能把负均值解释成已经证明的
单位查询路程优势，也不能把原同轮数劣势解释成纯时间重参数化。

作为已披露的事后时钟复核，匹配累计改单元格数后的平均差为 `+1.7379`，区间
`[-5.9601, 9.4360]`，配对 `8/0/12`，与设计前探索一致。它继续只作描述，不参与
正式分类。

### 8.3 状态依赖解释与边界

baseline RMS 残差十分位的前五个区间中，candidate 的种子级平均
`sum(gain)/sum(||Delta q||^2)` 均低于 baseline；后五个区间中有四个更高，一个
近似相同。比如 `[2.1354, 2.2539)` 区间为 `0.01963→-0.00269`，而
`[2.7724, 3.0854)` 区间为 `0.03971→0.07845`。这些分段是描述性聚合，低残差
区间还有少量种子未满足每箱至少 10 次转移的门槛，不能当作新的显著性检验；它们
只说明单位路程漂移随状态发生反转，与主诊断的高种子间异质性一致。

因此当前证据支持“曲率核改变了扩散时间尺度，并伴随状态依赖的混合漂移”，不支持
固定 `gamma=1` 的长期优势或默认接入。若继续改进，应另立 Issue 预注册只依赖公开
查询残差或内禀时钟的状态调度，并保持有限温双向支持；本阶段不事后扫描阈值，也不
实现调度、接受规则或默认参数变化。
