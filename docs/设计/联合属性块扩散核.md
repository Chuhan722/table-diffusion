# 联合属性块 Gibbs 扩散核：独立分解极限探针

## 1. 研究问题

现有残差驱动扩散核对每个 donor-recipient 不同属性分别计算单块方向，再独立抽取
Bernoulli 复制 mask。温度前沿已经说明：在“方向可加、块决策独立”的理论族内，
继续升温最终只会逼近正方向复制、负方向不复制的符号门控。这是单块核内极限，
不是整个扩散演化方法的极限。

本阶段只回答下一层问题：

> 当一次转移同时复制多个属性时，完整 hybrid 的合取查询方向与各单块方向之和
> 相差多少；利用这部分交互后，在相同随机扩散约束下，接受检查前的原始 proposal
> 是否稳定改善？

第一阶段只做 `test_300x10` 冻结状态上的精确枚举 oracle，不改默认生成器，也不把
该指数复杂度实现包装成生产算法。关联 Issue #12；PR #11 / Issue #10 负责独立
单块核内温度极限，两者的研究结论不能混写。

## 2. 完整 mask 方向地形

固定当前记录 `x`、donor `z` 和本轮旧残差场。令二者不同的属性集合为
`G={g_1,...,g_k}`，复制 mask 为 `M in {0,1}^k`。把 `M` 中的属性从 donor 复制
到 recipient，得到完整 hybrid：

\[
x^M=x^{M\leftarrow z}.
\]

沿用现有方向势能

\[
\phi_t(x)=\sum_j w_j\epsilon_{t,j}a_j(x),
\]

定义完整 mask 的精确残差方向：

\[
U_t(M)=\phi_t(x^M)-\phi_t(x).
\]

这里的“精确”是指对完整 hybrid 的一阶残差势能精确，不表示它等于整代平方损失
收益。多个参与记录合并后的真实 proposal 收益仍需按查询计数重新评价：

\[
L(S_t)-L(S')=(y-q_t)^T\Delta q-
\frac12\lVert\Delta q\rVert_2^2.
\]

对第 `g` 个单块 mask 记方向 `d_g=U(e_g)`，独立单块近似为

\[
A(M)=\sum_g M_gd_g.
\]

交互项定义为

\[
I(M)=U(M)-A(M).
\]

`I(M)` 同时包含合取查询造成的协同与抵消。空 mask 和所有单块 mask 理论上交互
均为零；实现把单块一致性误差作为常驻诊断，防止列映射或 hybrid 构造错误。

## 3. 两个扩散核与严格加性控制

历史复制率为 `0<eta<1` 时，完整 mask 参考核为

\[
q_0(M)=\eta^{|M|}(1-\eta)^{k-|M|}.
\]

现有独立核的理论 log-space 形式是

\[
q^{ind}_\beta(M)\propto q_0(M)\exp\{\beta A(M)\}.
\]

因为 `A(M)` 可加，它严格分解成逐块 logistic：

\[
p_g=\sigma(\operatorname{logit}\eta+\beta d_g).
\]

联合候选直接使用完整 hybrid 地形：

\[
q^{joint}_\beta(M)\propto q_0(M)\exp\{\beta U(M)\}.
\]

因此，当且仅当当前地形在所考察 mask 上可加时，两个分布严格相同。这个性质是
核心负控制：若实现连加性地形都不能退化到独立核，后续质量差异没有可解释性。

本阶段的 `beta=tau/s_0`。`s_0` 与现有探针一致，取该冻结状态第一份非零单块方向
矩阵的 RMS，固定后不逐 proposal 更新。理论独立核在 log 空间计算，不需要把
logit 截到 `[-30,30]`；探针额外报告它与当前截断 logistic 边缘概率的最大差，确认
差异只来自极端饱和下约 `1e-13` 量级的数值护栏，而不是另换 baseline。

## 4. 有限温度的扩散支持

只要 `q_0(M)>0`、方向有限且温度有限，联合核对每个 mask 都有正的数学概率。
它没有以下步骤：

- 不要求 `U(M)>0` 才允许转移；
- 不按方向对 mask 做 top-k、方向 argmax 或非冲突选择；
- 不读取完整真实表、训练/测试 TVD 或其他离线评价选择 mask；
- 不在 proposal 生成后逐候选检查收益。

实现用 log-sum-exp 归一化，并以共同 Gumbel 噪声抽样：

\[
M\sim\arg\max_m\{\log q(m)+G_m\}.
\]

这里的 `argmax` 是 categorical distribution 的 Gumbel-max 精确抽样算法，不是按
方向挑最大 mask。不同核共享同一组 `G_m`，只用于降低配对比较方差；每个核各自的
边缘采样分布仍严格是对应的 `q`。

## 5. 为什么必须同时做相同温度和匹配 KL

相同 `tau` 表示两个核对各自方向地形使用相同指数倾斜系数，但交互会改变能量方差，
所以二者相对 `q_0` 的 KL 未必相同。若联合核恰好更集中，仅看质量改善会把“使用
更多定向信息预算”误判成“交互建模有效”。

对任一有限地形 `E(M)`，Gibbs 路径满足

\[
\frac{d}{d\beta}KL(q_\beta\Vert q_0)
=\beta\operatorname{Var}_{q_\beta}[E]\ge0.
\]

因此可用一维二分求根匹配 KL。为避免某一地形的正温极限小于另一侧目标，探针对
每条参与记录、每个名义温度先计算两侧相同温度 KL，再取

\[
\kappa=\min\{KL(q^{ind}_{\tau/s_0}\Vert q_0),
KL(q^{joint}_{\tau/s_0}\Vert q_0)\}.
\]

然后分别求 `beta_ind` 与 `beta_joint`，使两侧 KL 都等于 `kappa`。这是一项对称的
归因 oracle：它会降低更集中的一侧，而不会给任何一侧追加超过名义温度的倾斜。
逐记录自适应温度暂不视为生产算法；它只用于判断在相同核偏移预算下交互是否仍
有可利用收益。

匹配误差、两侧有效温度范围和熵都必须随实验保存。若只有相同温度改善而匹配 KL
后消失，结论应是“联合地形改变了核强度”，不能声称独立分解形成了质量缺口。

## 6. 冻结状态配对协议

实验固定仓库原始无噪声小表配置：精确 50-query target、1-way marginal 初始化、
geometric donor 抽样、`rho=0.01`、`eta=0.5`。每个种子使用两类状态：初始状态和
历史 baseline 第 100 轮 best 状态。

每个冻结 proposal 的不变量为：

- 同一张当前合成表、查询答案、残差和 loss；
- 同一批 donor；
- 同一个记录参与 mask；
- 每条参与记录的所有核共享同一组 Gumbel 随机量；
- `mu=0`，隔离 donor 复制核；
- 不执行整代 generation acceptance，也不回滚或选择 best proposal。

各核独立生成一张完整 proposal，之后才统一评价：

- 原始精确收益、线性项、二次惩罚；
- 正/零/负收益率与逐 proposal 配对胜负；
- 改动单元格、改动记录数和单位改动收益；
- 总 KL、每活跃块 KL、相对参考核熵；
- 完整方向的期望值和实际抽中值；
- 完整方向为正、零、负的概率质量；
- `q_0` 下交互绝对值、RMS、非加性 mask 质量；
- 枚举状态数、墙钟和数值控制误差。

第一轮先做单种子小 proposal 冒烟；机制、加性控制和 KL 匹配无误后，才运行
3 配对种子 × 2 状态 × 200 proposal。三种子只提供方向性机制证据，不支持跨
workload 通用最优声明。

## 7. 复杂度与适用边界

一条记录若有 `k` 个活跃属性，精确枚举需要 `2^k` 个 hybrid。实现默认最多 16 个
活跃属性，正式小表命令进一步设为 12；超过护栏立即报错，不静默截断 mask。当前
10 属性小表每条记录最多 1024 个状态，适合作为 oracle，不能直接迁移到 nltcs 或
更宽表。

联合核仍受以下上界约束：

1. donor 没有提供的属性值与局部支持，任何 mask 都无法创造；
2. 未进入 workload 的高阶关系不会凭空出现在残差场；
3. `U(M)` 是旧残差场的一阶势能，整代有限步长仍有二次惩罚；
4. 多条记录同步变化时，线性计数变化可相加，但平方损失二次项会跨记录耦合；
5. 匹配 KL oracle 的逐记录求根与精确枚举都有额外成本。

所以可能出现三种有区分力的结果：

- 匹配 KL 后联合核稳定改善：独立分解确有可利用缺口，下一步另行研究 pairwise
  Ising、随机扫描 Gibbs 或小阶 interaction 的可扩展近似；
- 仅相同温度改善：主要是核集中度差异，应研究统一 KL trust region，而非宣称
  联合交互胜出；
- 两种比较都没有稳定改善：当前更可能受 donor 支持、workload 信息或整代步幅
  限制，不应继续堆联合核复杂度。

无论结果是哪一种，失败种子和完整原始输出都必须保留。

## 8. 隐私边界

本仓库仍是精确 target 的无噪声原型，不是端到端 DP。探针只使用 schema、公开
记录数、预定义查询、当前合成状态、donor 与已经提供的统计量残差。真实训练表和
测试表不得进入联合方向、温度、KL 匹配、停止或候选选择；本阶段也不运行离线
train/test 指标。未来即使 target 已经 DP 发布，联合核也只属于后处理，不能替代
上游查询选择、噪声机制、敏感度、accountant 和一致性处理。
