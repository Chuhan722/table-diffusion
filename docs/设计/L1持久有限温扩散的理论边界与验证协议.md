# L1 持久有限温扩散的理论边界与验证协议

## 0. 目的与结论层级

Issue #32 的平方能量实验已经说明：一个核可以严格降低它直接优化的能量，却不改善
同一 workload 的 normalized L1 或未测量高阶质量。Issue #38 因而先把训练能量改为
与项目主要误差口径一致的 normalized L1，再分别回答两个不能混淆的问题：

1. **优化问题**：给定精确 target 与固定 workload，持久有限温核能否以可证明的
   Markov 语义偏向较低 L1，并在有限预算内到达较好的训练状态？
2. **信息问题**：即使训练 L1 已经为零，这组查询是否足以决定未测量高阶统计？

本文件给出四组可以严格证明的结论：有限温支持与可逆遍历性、条件期望方向、平衡态
全局能量集中，以及 measured workload 对 held-out 查询的可识别边界。前两组证明
核的语义，第三组给出无限时间/高逆温极限，第四组说明任何优化器都无法突破的信息
边界。它们都不能替代有限预算下与现有生成器的配对实验。

## 1. 定义

单条记录的公开有限域记为

\[
\Omega=\prod_{g=1}^A\mathcal D_g,
\]

有序合成表状态空间为 `X = Omega^N`。`N` 是公开记录数，每个属性域
`D_g` 由公开 schema 给出。预定义 workload 包含 `m` 个布尔查询
`phi_j: Omega -> {0,1}`，计数答案为

\[
q_j(S)=\sum_{i=1}^N\phi_j(x_i).
\]

固定提供的 target 为 `y in R^m`。L1 训练能量定义为

\[
E_1(S)=\frac{1}{mN}\lVert y-q(S)\rVert_1.
\]

初始表只用于一次性得到有限正尺度 `s_0`；随后整条轨迹冻结该尺度。无量纲强度
`tau >= 0` 对应 `alpha=tau/s_0`。固定坐标 `c=(i,g)` 和其余状态后，完整条件分布为

\[
p_{\tau,c}(v\mid S_{-c})
=\frac{\exp[-\alpha E_1(S^{c\leftarrow v})]}
{\sum_{u\in\mathcal D_g}\exp[-\alpha E_1(S^{c\leftarrow u})]}.
\]

坐标按与状态无关且处处为正的概率选择；正式协议使用均匀随机扫描。每个微步从完整
合法域采样后立即更新表与查询答案，不执行接受、拒绝、回滚、早停或 checkpoint
选择。

以下定理均以 `s_0` 有限且严格为正、`tau` 有限、所有属性域有限非空为前提。
不同 seed 使用各自冻结的 `s_0` 时，每条轨迹分别满足定理，但同一个名义 `tau`
不代表跨 seed 完全相同的平稳分布；正式实验必须报告尺度分布。

## 2. 定理一：有限温核可逆、遍历且平稳分布唯一

### 定理

定义

\[
\pi_\tau(S)=Z_\tau^{-1}\exp[-\alpha E_1(S)].
\]

则：

1. `tau=0` 时每个坐标条件分布精确退化为公开合法域上的均匀分布；
2. 任意有限 `tau` 下，每个合法值的数学概率严格为正；
3. 每个固定坐标的完整条件重采样满足关于 `pi_tau` 的细致平衡；
4. 状态无关随机扫描是这些可逆核的混合，仍满足细致平衡并保持 `pi_tau`；
5. 若每个坐标选择概率严格为正，则有限表状态空间上的链不可约；当前值也在候选域
   内，因此每个状态都有正自环，链非周期；
6. `pi_tau` 是唯一平稳分布，任意初始分布最终收敛到 `pi_tau`。

### 证明

固定坐标 `c` 后，两个只在该坐标不同的状态 `S,S'` 具有相同的条件归一化常数，
所以

\[
\pi_\tau(S)p_{\tau,c}(S'_c\mid S_{-c})
=\pi_\tau(S')p_{\tau,c}(S_c\mid S'_{-c}).
\]

这就是固定坐标核的细致平衡。坐标权重不依赖状态，对等式按坐标求加权和即可得到
随机扫描核的细致平衡。有限 `alpha` 和有限能量使所有指数权重严格为正；依次修改
有限个坐标即可从任意表到达任意另一张表，因此不可约。选择当前值给出正自环，故
非周期。有限不可约链有唯一平稳分布，增加非周期性后从任意初态收敛。

这里的“严格正”是实数数学结论。float64 若发生下溢或舍入为零，程序必须 fail
closed；不能用截断后的实现继续引用本定理。

## 3. 定理二：相对无向参考扩散的期望正向驱动

### 定理

固定状态与坐标，把各合法值的候选能量记为 `e_v`，令

\[
M_c(\tau)=\sum_v p_{\tau,c}(v)e_v.
\]

则

\[
\frac{dM_c}{d\tau}
=-\frac{1}{s_0}\operatorname{Var}_{p_{\tau,c}}(e_v)\le 0.
\]

只要候选能量不全相同，不等式严格。对状态无关坐标分布求平均后，一整个随机扫描
微步的条件期望能量同样随 `tau` 单调不增。

### 证明

对指数族权重求导有

\[
\frac{dp_v}{d\tau}
=-\frac{1}{s_0}p_v(e_v-M_c).
\]

乘以 `e_v` 后求和即得负条件方差。

### 变分等价

当 `tau>0` 时，同一条件分布还是下面严格凸问题的唯一解：

\[
p_{\tau,c}
=\arg\min_{p\in\Delta(\mathcal D_g)}
\left\{\mathbb E_p[e_v]
+\frac{s_0}{\tau}\mathrm{KL}(p\Vert U_g)\right\},
\]

其中 `U_g` 是合法域均匀分布。拉格朗日一阶条件直接给出 Boltzmann 权重；KL 的
严格凸性给出唯一性。

### 不能推出的结论

该定理只比较**同一个状态、同一个坐标**下不同 `tau` 的条件期望。当前值可能已经
是该坐标的局部最低能量值，因此有限温采样后的期望能量仍可高于当前能量。它不能
推出：

- 每个样本步都下降；
- `E_1(S_t)` 是超鞅；
- 两条已经分叉的有限时间轨迹逐步排序；
- 固定 3000 微步必然优于初始表或现有生成器。

因此训练 L1 仍需正式配对实验；不能把本定理本身当作方法有效性结果。

## 4. 定理三：平衡态向训练能量全局最小集集中

记

\[
E_*=\min_{S\in\mathcal X}E_1(S),\qquad
\mathcal M=\{S:E_1(S)=E_*\},\qquad D=|\mathcal X|.
\]

### 尾概率界

对任意 `epsilon>0` 和 `tau>0`，

\[
\pi_\tau(E_1\ge E_*+\epsilon)
\le \frac{D-|\mathcal M|}{|\mathcal M|}
\exp\left(-\frac{\tau\epsilon}{s_0}\right).
\]

证明只需分别用 `(D-|M|) exp[-alpha(E_*+epsilon)]` 上界坏状态总权重，并用
`|M| exp(-alpha E_*)` 下界配分函数。

### 平均能量界

由 Gibbs 分布最小化自由能

\[
\mathbb E_\pi[E_1]-\frac{1}{\alpha}H(\pi)
\]

并与全局最小集上的均匀分布比较，可得

\[
\mathbb E_{\pi_\tau}[E_1]-E_*
\le \frac{s_0}{\tau}\log\frac{D}{|\mathcal M|}.
\]

因此先让固定有限温链充分混合、再令 `tau` 增大时，平衡态质量集中到训练能量全局
最小集。若精确 target 可实现，则 `E_*=0`。

### 适用边界

这是一条**平衡态/逆温极限**，不是实用有限时间保证。当前状态空间大小为

\[
D=\prod_g |\mathcal D_g|^N,
\]

上界中的 `log D` 仍可非常大；能量势垒还可能让混合时间随表规模或 `tau` 急剧
增长。有限、不可约、非周期只保证存在几何收敛常数，不给出有用的数值速率。

后续若要证明有限预算收敛速度，需要另立问题研究下列条件之一：

1. 计算或上界坐标间的 Dobrushin influence；若总影响严格小于 1，可尝试得到随机
   扫描 Gibbs 的收缩与混合上界；
2. 对共享随机坐标的两条链构造最大耦合或路径耦合，证明一次微步缩短 Hamming/
   workload 距离；
3. 对小状态完整转移矩阵直接计算谱隙，再检查谱隙随 `N`、workload 阶数和 `tau`
   的缩放；
4. 若改为退火而非固定温度，需要单独刻画能量势垒深度并预注册温度日程，不能从
   当前固定 `tau=1` 结果直接外推。

这些是后续证明路线，当前 Issue 不把尚未验证的收缩条件写成既定事实。

## 5. 定理四：measured workload 的信息可识别边界

前面三项只讨论训练能量。未测量高阶质量能否由训练 L1 保证，取决于查询本身是否
提供足够信息，与优化器名称无关。

把有限记录域 `Omega` 上的分布写成列向量 `p`。令 `A` 的每一行是一个 measured
查询在所有记录状态上的 indicator，held-out 查询 indicator 为 `h`，全一向量为
`1`。

### 可识别情形

若

\[
h=b\mathbf 1+A^\top a,
\]

则 held-out 期望由 measured 查询精确决定：

\[
h^\top p=b+a^\top Ap.
\]

对真实分布 `p_*` 和合成分布 `p`，还有

\[
|h^\top(p-p_*)|
\le \lVert a\rVert_\infty\lVert A(p-p_*)\rVert_1
=m\lVert a\rVert_\infty E_1.
\]

所以只有当 held-out 查询位于 measured 查询与常数的线性张成中时，训练 L1 才给出
明确的 held-out 上界。

### 不可识别情形

若 `h` 不属于 `[1^T; A]` 的行空间，则存在两个分布 `p_+`、`p_-` 满足

\[
Ap_+=Ap_-,\qquad h^\top p_+\ne h^\top p_-.
\]

证明：由线性代数基本定理，存在 `z` 使 `Az=0`、`1^T z=0`，但
`h^T z != 0`。从严格正的内部概率向量 `u` 出发，取足够小的 `epsilon>0`，则
`p_+=u+epsilon z` 与 `p_-=u-epsilon z` 都是概率分布，measured 答案相同而
held-out 答案不同。

查询矩阵为整数时可取有理零空间方向；放大到合适记录数即可得到两张有限表的精确
反例。对某个固定而不整除该分母的 `N`，至少仍有相应的近似不可识别结论。

### 可执行的三位奇偶反例

三个二值属性上，下面两个各含四条记录的经验分布：

- 偶校验：`000, 011, 101, 110`；
- 奇校验：`001, 010, 100, 111`。

它们的全部 1-way 和 2-way 边缘完全相同，但查询 `x1=x2=x3=1` 的计数分别为
`0` 和 `1`。因此即使 measured workload 包含**全部一阶与二阶查询**、训练 L1
精确为零，三阶统计仍不能由这些答案唯一决定。

这给出本项目最重要的理论停止边界：若 L1 核已经把 measured workload 优化到数值/
采样平台，而未测量三阶仍有差距，不能继续把全部差距归因于扩散算子。此时需要增加
信息渠道或进入查询选择/测量阶段，而不是无限调优化器。

## 6. 定理五：原始能量下降与有限温全支持不能处处兼得

固定状态 `S`，对随机扫描坐标权重 `w_c>0` 定义一步条件期望漂移

\[
D_S(\alpha)=\sum_c w_c\left[
\sum_v p_{\alpha,c}(v\mid S_{-c})E_1(S^{c\leftarrow v})-E_1(S)
\right].
\]

由定理二逐坐标求导可得

\[
D'_S(\alpha)
=-\sum_c w_c\operatorname{Var}_{p_{\alpha,c}}
\left(E_1(S^{c\leftarrow v})\right)\le 0.
\]

所以温度越低，随机扫描一步相对**当前状态**的期望漂移也单调不增。这一函数可以
通过枚举全部坐标与合法值精确计算，而不需要真实参考表。

再记

\[
L_S=\sum_c w_c\min_v E_1(S^{c\leftarrow v})-E_1(S)\le 0.
\]

若 `D_S(0)>0`、`L_S<0`，并且至少一个坐标的候选能量不全相同，则
`D_S(alpha)` 连续且严格递减，并存在唯一有限临界值 `alpha_*(S)`，使得
`alpha>alpha_*` 时一步期望下降，`alpha<alpha_*` 时一步期望上升。对应无量纲
临界强度为 `tau_*(S)=s_0 alpha_*(S)`。

但若 `S` 是单坐标局部最小，即所有单坐标替代值都满足
`E_1(S^{c<-v}) >= E_1(S)`，且至少一个被正概率选择的坐标存在严格更差替代值，
那么任意对所有合法替代值保持严格正概率的有限温局部核都有
`D_S(alpha)>0`。证明是每项能量差均非负，至少一项严格为正且权重严格为正。

因此以下两个全局要求在局部最小点不能同时成立：

1. 每个反向/上坡合法值始终具有严格正概率；
2. 原始训练能量在每个状态都构成一步超鞅。

这不是实现缺陷，而是方法边界。状态依赖温度可以在仍有净下降方向的区域保证负
期望漂移；到达单坐标局部最小后，若仍要保留真实扩散，就必须允许受控的正漂移，
或者改变状态空间、邻域/块结构、能量或要证明的 Lyapunov 量，不能声称原始能量
仍处处单调。

## 7. 理论命题到可执行验证的映射

| 数理命题 | 可执行证据 | 结论范围 |
|---|---|---|
| 完整条件概率 | 手算增量 + 整表重算 | 实现是否等于定义 |
| 可逆与唯一平稳分布 | 16 状态完整转移矩阵 | 小状态精确 oracle |
| 期望能量对 `tau` 单调 | 条件方差导数 + 有限差分 | 同状态、同坐标 |
| 平衡态集中 | 穷举 Gibbs 权重与尾界/均值界 | 无限时间平衡态 |
| 随机扫描漂移与临界温度 | 全坐标候选能量枚举、方差导数和二分根 | 给定状态的一步期望 |
| 局部最小点不可能性 | 严格局部最小的完整有限域反例 | 全支持与原始能量超鞅的冲突 |
| 平方模式不回归 | 固定状态、概率、选择、轨迹、RNG 对拍 | 重构兼容性 |
| 高阶不可识别 | 三位奇偶分布精确反例 | workload 信息边界 |
| 有限预算方法质量 | 新种子配对正式实验 | 经验结论，不是定理 |

单元测试不是一般定理的证明；定理由上面的推导给出，oracle 用于证明代码实现确实
满足定理的前提和公式。反过来，定理也不能替代正式实验对有限预算、成本和 held-out
质量的检验。

- baseline：Issue #32 的平方能量持久热浴，`tau=1`；

- 生成全部结束后才加载真实参考表。

训练 L1 是核直接定义的能量，只承担“目标是否对齐”的检查。独立主指标仍是未测量
3-way mean L1；同时报告未测量 4-way、平方 loss、支持集、条件熵、uphill 概率
质量和运行成本。具体 14/20、11/20 分类与阶段 II 的现有生成器同预算/同墙钟门槛

## 10. 本阶段能够与不能声称的结论

### 若实现与 oracle 通过，可以声称

- 代码实现了定义中的 L1 完整条件核；
- 固定有限温下具有唯一 Gibbs 平稳分布、细致平衡和真实双向支持；
- 同状态条件期望 L1 随 `tau` 单调不增；
- 平衡态在高逆温极限集中到 measured L1 全局最小集；
- measured workload 是否能约束 held-out 查询可由查询张成关系判定。

### 即使上述全部通过，也不能声称

- 3000 微步已经混合或到达全局最小；
- L1 会逐步下降或优于共同初始表；
- 降低 measured L1 必然改善未测量 3/4-way 或联合分布；
- 优于无向扩散等于优于现有生成器；
- 单一小表结果跨 workload 通用；
- 当前精确 target 原型已经满足 DP。

关联 Issue #38 与 Issue #32。

### 事后机制诊断：为什么目标对齐仍然失败

在独立 commit `d7ee057` 上，只用公开输入和已经冻结的轨迹进行了全坐标期望漂移
复算；它不读取真实表、不改变上面的分类。结果文件 SHA-256 为
`3bc7b4eabdffb1325254ed410649d36643feecc8c0272469223606ce0bfe684e`，再次复算
20 seed、40 组初始候选集通过。

在 `tau=1` 的共同初始表上，L1 随机扫描一步的精确平均期望漂移为
`+4.0776e-5`，20/20 个 seed 均为正；平均 `90.98%` 的坐标具有正条件期望漂移。
沿正式轨迹，seed 级平均条件期望漂移仍为 `+3.2701e-6`，20/20 为正，最终相对
initial 的 realized L1 变化为 `+0.0098433`。平方核的初始平均漂移则为
`-0.0111552`，20/20 为负。

由定理五的单调漂移方程求得，L1 初始状态的临界 `tau_*` 均值为 `4.390`，范围
`[3.770,5.681]`；平方核均值仅为 `0.239`。所以相同名义 `tau=1` 在两种能量各自
的 RMS 定标后并不具有相同的“相对当前状态下降”语义：它对平方核已超过初始漂移
门槛，对 L1 核却明显低于门槛。

这项事后结果只定位机制，不能把 `tau_*` 当成新的最优温度，也不能在 seed 60..79
上改温度重跑后替换正式分类。若继续研究，应另立 Issue，用新 seed 预注册基于
`D_S(alpha)` 的漂移约束温度或更大块邻域，并同时报告熵、uphill 质量、有限预算
质量与计算成本。定理五还说明：到达严格单坐标局部最小后，有限温全支持与原始能量
处处超鞅不可能兼得；后续设计必须明确如何处理这一边界。
