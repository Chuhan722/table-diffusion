# 尺度不变选择：无门控扩散演化的结构性 fitness 修正

状态：正式实验完成，nltcs 主判定 supports（§7）。
分支：`research/anneal-floor-swap`（堆叠于 PR #45）。

## 1. 问题：低温选择退化

rho=0.01 更正重跑（PR #45）确立的量化目标：无门、等预算、nltcs 上打平
历史门 L1 0.002728。诊断实验（`scripts/diagnose_no_gate_floor.py`，
dev seed 42、4000 轮、无门恒定）给出动力学图景：

| rho | 4000 轮终点 loss | 形态 |
|---|---|---|
| 0.1 | 1.85e7 | 平台（噪声地板，~300 轮即到） |
| 0.03 | 5.40e6 | 接近平台 |
| 0.01 | 2.88e6 | 仍以 -1.6e6/1k 轮下降（预算不足型） |
| 0.003 | 3.66e6 | 更慢 |
| 0.01, mu=0 | 2.94e6 | 与 mu=0.01 无差 |

结论：(a) 噪声地板随 rho 近似线性抬升，主导噪声源是**复制搅动**而非
均匀变异（mu=0 不改善——守恒 swap 方向因此放弃）；(b) rho=0.01 在
2000 轮预算内远未到达其固有地板——瓶颈不是噪声，是**净漂移速率**。

dev 扫描（`scripts/dev_rho_anneal_calibration.py`，nltcs、seed 42..44、
2000 轮）进一步定位：时间驱动 rho 退火（几何/两段式盲调度）只带来
3-5% 增益；而漂移场参数的增益是数量级的：

| 臂（均为无门 tol=inf） | loss | L1 |
|---|---|---|
| const rho=0.01（基线，alpha 2..10） | 3.33e6 | 0.003483 |
| + 两段退火 | 3.17e6 | 0.003432 |
| + ds8 | 1.43e6 | 0.002280 |
| + ds4 + alpha 6..20 | 0.95e6 | 0.001627 |
| + ds4 + alpha 12..40 | 0.71e6 | 0.001253 |

关键模式：**alpha 越陡越好、扫描范围内无拐点**。这不是"存在最优
alpha"的信号，而是选择结构存在尺度缺陷的信号。

## 2. 诊断：行内离散度收缩

geometric 抽样的 fitness 分量已有 winsorize+min-max 归一化（绝对尺度
固定），但联合分数 `log_A = λ·log f + (1−λ)·log s` 的**行内离散度**
无任何控制。种群同质化时（收敛后期成对距离集中），行内 spread(log_A)
收缩，softmax 的实际区分度 ≈ alpha·spread 持续衰减——固定 alpha 下
选择压力退化为均匀，漂移消失、只剩扩散噪声。调大 alpha 是一次性增益
补偿，把崩塌点后移，任何固定值都是权宜；递增调度（alpha_min→max）
则引入两个自由度的调参。

## 3. 机制：行内标准化（含第一轮审查后的保护）

`selection_scale_invariant=True`（默认 False 关闭）时：

```
logits = alpha · (log_A − mean_i) / max(std_i, min_spread)
```

其中行统计 `mean_i`/`std_i` 在 `exclude_self=True` 时**只在非自身候选
上计算**（审查修正：自身条目距离恒 0、分数在行内是极端值，参与统计会
扭曲其余合法 donor 之间的选择强度；自身概率本身在 softmax 后置零重
归一化，等价于从候选集移除）。

- 有效选择温度恒等于 alpha，与行内离散度的绝对尺度解耦——尺度不变
  性成为机制**内生性质**，不再依赖调参补偿；
- **低信号保护**（审查意见一.1）：`scale_invariant_min_spread`
  （默认 1e-3，dev 冻结）是标准差下限——放大倍数被限制在
  `alpha/min_spread` 以内；行内离散度低于下限时选择强度随离散度
  线性衰减，趋零时平滑退化为均匀（无信息 → 无偏好）。原实现的
  `+1e-8` 只防除零，不能阻止噪声级微小差异被放大成极端偏好；
- **集中度监控**（审查意见一.2）：启用时诊断逐轮记录
  `donor_top_share_history`（被选最多 donor 的占比）。dev 复核
  （nltcs seed 42、修正后 2000 轮）：top_share 峰值 2.2%、均值
  0.18%——alpha=16 在标准化空间下未出现"集中复制少数 donor"的
  坍缩；alpha=16 的含义：标准分空间中 1 个标准差的分数优势对应
  e^16 的相对权重，但由于行内分数近似连续分布、头部 donor 间差距
  远小于 1 个标准差，实际集中度由分布形状决定（实测如上）；
- 减行均值被 softmax 平移不变性吸收，保留是为了标准分语义自解释；
- numpy/torch 双路径同语义（新增一致性测试，容差 5e-6）。

方法边界（用户确认的扩散演化红线）：这是**选择核的分布调制**（改分
布），不读取任何候选评价、不引入接受/拒绝判定；变异与选行保持全盲。
审查意见一.3 的定位澄清：本机制只改进 donor 选择，无门制度下劣化
proposal 仍会被接受——"门是否冗余"不能由方法设计推出，只能由 2×2
配置对齐的实验判定（v2 判定 2），且结论限于测试过的配置。

## 5. 公平对照（防配置混淆，rho 教训）

有门臂在同配置下同样大幅受益（ds4+alpha 6..20：有门 0.78e6/L1
0.001654 vs 无门 0.95e6/0.001627）——**"无门越过有门 41%"的中间
表述不成立**，那是配置不对称的假象。配置完全对齐后：

- gate_si_a10：loss 0.62e6（低于无门 0.69e6），但主指标 L1 ~0.00145
  （差于无门 0.001224 约 18%）——门的贪心棘轮按平方 loss 接受，代价
  是 L1 误差分布形状；
- 诚实叙事：**分布动力学修正把两臂同等抬升；配置对齐后门在主指标上
  不带来收益（甚至略负），且机制更复杂**。无门主张 = 同水平、更简、
  无需候选评价，而非"碾压门"。

## 9. 局限与开放问题

- 行内标准化让每行的选择压力相同——忽略"某些行的 donor 池本来就更
  可分"的信息；替代方案（全局标准化、rank 选择）留作消融。
- loss vs L1 的分离（门按 loss 棘轮、L1 变差）值得单独机制分析。
- dev 只在 nltcs 单数据集定标；小表行为待正式实验。
- 与 PGM 剩余 3.4 倍差距的来源（样本空间量化 vs 优化质量）未分解。
