# 条件平方损失差只读监控

关联 #90。此路线与 #81 的L1经验规则并存，不替换L1、不修改默认生成核或停止策略。
首版提供独立统计组件及显式记录工具；报警只产生诊断，不选择或替代正常终表。

## 统计对象与条件

固定查询真值为 `theta`，验证向量为 `B = theta + xi`。给定全部学习输入与算法随机性：

- 参考答案 `r`、候选轨迹 `s_t` 和正权重 `W=diag(w)` 不依赖验证噪声；
- 验证各题噪声独立、均值为零且为高斯，验证标准差已知，或有可靠的逐题上界；
- 参考可以由学习卷决定，但建立后不能依据验证值更换参考、权重或未来候选；
- 最大观察次数 `K` 和总误报容许率 `eta` 预先确定。

只要求验证卷的条件模型成立，不要求学习卷保持原始高斯形式。
正确独立分裂后仅处理学习卷不因此破坏验证独立性；分裂**之前**裁剪、清洗、
基于共享噪声自适应选测或合并则不能直接套用本合同。
每题带有 `sigma` 字段并不证明这些条件。相关验证噪声的完整协方差首版不支持。

若从方差为 `sigma²` 的原始固定高斯观测作 `A=Y+e, B=Y-e`，
且独立的 `e` 也有方差 `sigma²`，则两卷各有方差 `2*sigma²`。
不能把分裂前标准差当作验证卷标准差；构造实验文件时可向上舍入并核对其平方上界。

## 风险差与有限次保证

监控的是加权**半平方**损失差，不是L1：

```text
D_t = ½ sum_j w_j [(s_tj-B_j)² - (r_j-B_j)²]
Delta_t = ½ sum_j w_j [(s_tj-theta_j)² - (r_j-theta_j)²]
E[D_t | 学习信息] = Delta_t
Var(D_t | 学习信息) <= V_t = sum_j [w_j (s_tj-r_j) sigma_Bj]²
```

使用精确标准差时方差取等号。平方项相减后关于验证噪声是线性的，因此在上述条件下
`D_t-Delta_t` 为高斯，不需要用“题数足够多”的中心极限定理，也不以跨题样本SE代替已知噪声方差。

每次分配不超过 `eta/K`，令 `c = Phi^{-1}(1-eta/K)`。
下界为 `D_t-c*sqrt(V_t)`，严格为正才报警“候选的真值平方风险高于参考”。
对预定轨迹的至多K次观察，由联合上界：

```text
P(至少一次在 Delta_t <= 0 时错误报警 | 学习信息) <= eta
```

不同观察可以使用同一份B、彼此相关，联合上界不要求观察之间独立。
同一比较重复三次仍消耗三次观察，不能将三次相同结果当作三份独立证据。
这只是相对固定参考的有限次误报控制，不保证最佳停时、足够检验功效、L1排序、
未测高阶效用或最终泛化质量。没有报警不等于没有变差。

误报容许率不是隐私epsilon/delta。数值程序只校验数组、参数和可表示性，不认证输入的
独立性、测量机制或端到端DP。原始训练/测试表仍只能用于生成后的离线评价；
验证卷必须来自允许使用的公开或已发布统计量，不能因“验证独立”就绕过信息边界。

## 数值与状态合同

`IndependentGaussianQuadraticMonitor` 使用计数单位：

- 参考/候选是 `[0, 2**50]` 内的整数计数；验证目标允许为任意有限实数；
- 标准差有限且非负，权重有限且严格为正，向量等长且非空；
- `0 < error_probability < 0.5`，最大观察次数为正整数；
- 固定量私有复制，不接受调用者在运行中原地改变模型；
- 输入/数值错误不伪造记录，成功观察才更新计数；预算耗尽明确拒绝。

风险差复用 `ExactGainOracle.from_answers` 和 `sparse_gain`，从实际验证目标和参考答案
计算，不从已舍入残差反推，也不相减两个巨大总损失。
方差按给定float64输入的有理数表示累加，平方根使用局部十进制上下文，并核对
返回标准误的平方不小于所累计方差。均值侧和阈值侧分别保守舍入。
非有限或不可表示的风险差/标准误/下界报 `numerical_indeterminate`，不把下溢方差当成零。

`zero_variance` 指这一次比较没有验证噪声贡献，包括两答案相同；
它不是跨题样本SE为零，也不表示整份验证卷无噪声。
正态逆CDF/尾概率仍由SciPy浮点计算，数值回归不等于形式化区间概率认证；
上面的概率结论是指定统计模型下的数学合同。

```python
from resevo.quadratic_monitor import IndependentGaussianQuadraticMonitor

monitor = IndependentGaussianQuadraticMonitor(
    reference=[10, 20],
    validation=[11.5, 19.5],
    validation_sigma=[3, 3],
    weights=[1, 1],
    error_probability=0.05,
    max_looks=20,
)
record = monitor.observe([12, 18])
```

这个数值调用本身不证明验证卷独立。建立多个监控实例、按B选择其中最有利者或重置预算，
不在单实例保证范围内。若以后用报警终止预先不依赖B的轨迹，可引用相应有限次保证；
若用B反馈调参、改菜单、换参考或引导第二阶段，则必须重新处理依赖关系。

## 只读生成记录工具

给定公开schema/N、带计数sigma的学习卷、同题同序验证卷：

```bash
PYTHONPATH=src python scripts/record_quadratic_monitor.py \
  --schema public_schema.json \
  --learning learning_counts.json --validation validation_counts.json \
  --rows 128 --rounds 300 --interval 10 --seed 7101 \
  --monitor both --error-probability 0.022750131948179195 \
  --output outputs/quadratic_recording
```

文件格式沿用已有公开schema和 `result_unit=records` 查询格式；
验证卷的sigma是验证卷自身的计数标准差或可靠上界。GPU加 `--backend gpu`。
输出目录必须不存在。`--monitor off` 不接收也不读取验证卷；
`l1`、`l2`、`both` 显式选择记录路线。L1对照保留
`sample_se>0`、`mean>=z*sample_se` 和连续次数规则，仍是启发式。

工具采用基础批量核、单位权重、显式uniform初始化、固定种子流，
不引入结构先验、纤维或新的停止规则。参考是第一个预定观察点上学习损失不超过
`½ sum(sigma_A²)` 的表。这只是仅依赖学习信息的参考选择启发式，
不是噪声地板定理，也不等同于重现整个历史自动停驱动。
观察预算采用预定轮数/间隔的上限，不依据验证结果减少预算以放宽阈值。

`observations.jsonl` 记录当前合成表计数及两种统计量；
参考表、首次报警表只作诊断。`terminal.csv` 仍是原轮数上限/原停止规则的当前表，
不按报警回滚或挑选。`summary.json` 明确区分未到参考点、只有参考点、已观察和关闭。
只有完成摘要与正常终表同时存在才表示本次记录成功；数值失败沿用已有失败现场出口，
不以参考/报警表冒充正常终表。

首次实验只检验统计校准与同轨迹诊断，不声称实际节省了单路运行时间。
L1与L2度量不同，离线评价分别列出原真值L1和平方风险差，不能把L1报警直接算作对L2假设的误报。
全面同信息同预算质量比较、生产自动停接线和纤维设计不在本步。
