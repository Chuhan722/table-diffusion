# 校准层常数的理论依据草稿，alpha 与 stay

回答两个问题。其一，熵校准里的 alpha 凭什么可以取 0.5，取别的行不行，会不会取错了整个方法就不收敛，结论分三条命题，命题一说方程永远解得出，命题二说账算得对，命题三说任意 alpha 属于开区间零到一都收敛，alpha 只影响速度常数不影响收敛性，因此 0.5 是速率甜点区里的居中取值，配套的敏感度实验见第五节实测证据。其二，参考分布 R 的形状与源保持概率 stay 凭什么这样设计，见第六节，形状由最大熵原理给出，取值方向由噪声正则机理给出，具体数值由敏感度扫描确认稳健。

## 一，记号与机制回顾

当前表的损失 L 为全体查询残差的平方和。一轮内把行划分成块，块 B 的候选结果 u 带增益 G_B(u)，增益是假设其他块都不动时该块单独换到 u 能带来的损失下降量。定义 M = sum_B max_u G_B(u)，即每块都拿自己最好结果时的账面增益总和。

熵校准解带约束的投影问题，min sum_B KL(P_B||R_B) s.t. sum_B E_{P_B}[G_B] >= alpha*M，解是指数倾斜族 P_B(u;beta) = R_B(u)exp(beta*G_B(u))/Z_B(beta)，全部块共享一个 beta。记 D(beta) = sum_B E_{P_B(beta)}[G_B] 为方向增益。

步长层在方向 P 定下后独立求解，速率化后得交互量 C，一步的期望损失满足精确恒等式 E[L'] = L - hD + h^2 C，解析步长 h* = D/(2C) 截断到可行域，期望下降 hD - h^2 C 在 h 属于零到 D/C 之间恒非负。恒等式的推导见 src/resevo/engine.py 模块注释与 stepsize.py，本文直接引用。

## 二，命题一，可达性，方程必有唯一解

命题。对任意 alpha 属于开区间零到一，校准方程 D(beta) = alpha*M 在 beta >= 0 上必有解，且当 D(0) < alpha*M 时解唯一。

证明要点。三步。

第一步，单调性。dD/dbeta = sum_B Var_{P_B(beta)}[G_B] >= 0，即 D 关于 beta 的导数是各块增益方差之和，这是指数族的标准恒等式，所以 D 单调不减，只要还有某块增益未退化成常数就严格递增。

第二步，值域。beta = 0 时 D(0) 是参考分布下的平均增益，可正可负。beta 趋于正无穷时每块概率集中到自己的最大增益结果，D 趋于 M。所以 D 的值域是从 D(0) 到 M 的半开区间。

第三步，中值定理。目标值 alpha*M 严格小于 M，若 D(0) >= alpha*M 则 beta = 0 已满足约束直接取零，否则 alpha*M 落在开区间 (D(0), M) 内部，由连续性与严格单调性存在唯一根。

这里的关键是目标值与 D 用同一套假设别人不动的口径，方程两边自洽，所以永远解得出，不存在目标定了却够不着的情况。取值真够不着的只有 alpha = 1 这个端点，那要求每块以概率一拿最大值，倾斜参数需要无穷大，这就是 alpha 必须严格小于一的原因。代码上 tilt.py 的 calibrate_beta_flat 用翻倍括根加布伦特法求这个唯一根，容差 1e-13。

## 三，命题二，两本账引理，M 虚高不记假账

命题。M 与 D 采用的假设别人不动口径只用于选方向，一步的真实期望下降由精确恒等式 E[L'] = L - hD + h^2 C 给出，块间同时移动的全部二阶效应被 C 捕获，任何收敛论证不需要 M 的双侧准确性，只需要单侧性质 M >= 残差可兑换增益的下界。

说明。方法里有两本账。第一本是选方向的账，M 和 D 都按单块独动口径计算，这本账在多块同时动时确实虚高，因为两块可能都想修同一条查询，各自的账面增益重复计数。第二本是定步长的账，E[L'] = L - hD + h^2 C 是把全部块按速率 h 同时演化后损失的精确条件期望，推导只用了残差对行更换的线性响应与损失的二次结构，没有任何近似，踩脚效应全部进了 C。

两本账的分工是，第一本只回答往哪边走，第二本回答走多远和真的能降多少。beta 由第一本账的方程解出，h 由第二本账的极小化解出，期望下降 hD - h^2 C 用的全是第二本账的量。所以 M 虚高不会导致下降量记假账，最坏情形是方向选得保守或激进了一点，由命题三兜底。

一个直接推论是探针的合法性。装表实验里的 J(beta) = hD - h^2 C 对每个候选 beta 都按第二本账计算，所以不同 beta 之间的 J 可比，J_used 与 J_best 的比值是当前 alpha 离单轮最优的真实距离，不受口径虚高污染。

## 四，命题三，收敛性，映射到近似方向神谕的 Frank-Wolfe 框架

命题。把每轮的块结构候选集视作可行移动集合，M 是本轮完全贪心方向的账面增益即精确方向神谕的值，校准约束 D >= alpha*M 恰是乘性近似方向神谕，近似比 alpha。在 Frank-Wolfe 类分析下，任意固定 alpha 属于开区间零到一，损失序列期望单调下降且下降量有与 alpha^2 成正比的下界，alpha 只进速率常数不影响收敛本身。

论证骨架。四步。

第一步，单轮下降下界。当解析步长 h* = D/(2C) 落在可行域内部时，期望下降等于 D^2/(4C)，代入校准约束 D >= alpha*M 得期望下降 >= alpha^2 M^2 / (4C)。步长被可行上限或行预算截断时，下降量退化为线性形式 h(D - hC) >= h*D/2 仍严格正，只要 D > 0。

第二步，M 压不低。M >= max_B max_u G_B(u)，只要残差未清零且候选集含正增益动作，M 就有由残差范数控制的正下界，这一步不需要 M 准确，只需要它不小于单块最优真实增益，而这由 M 的定义直接成立。

第三步，超鞅论证。抽样引入方差，但恒等式给的是条件期望，损失序列 L_k 满足 E[L_{k+1} | 历史] <= L_k - alpha^2 M_k^2/(4C_k)，损失有下界零，由超鞅收敛定理 L_k 几乎必然收敛，且下降量级数可和推出 M_k^2/C_k 趋于零。

第四步，与经典结果对照。凸情形下乘性近似神谕的 Frank-Wolfe 收敛速率是精确神谕的 1/alpha^2 倍常数放大，见 Jaggi 2013 与 Lacoste-Julien 2016 关于 approximate linear oracle 的讨论。本方法的抽样是有限种群离散移动，不落在凸框架内，上面的超鞅版本是自足的，经典结果只作类比定位。

推论。alpha 的角色是速率旋钮，取 0.9 方向激进接近贪心但踩脚项 C 变大步长被压小，取 0.1 方向保守接近参考分布单轮下降的保证变差，两端都只是常数变差不破坏收敛。0.5 是该权衡的居中取值，其接近最优的程度是实验问题不是理论问题，见下节。

## 五，实测证据，2026-09-21 扫描回填

三组数据全部来自 alpha 敏感度扫描，alpha 0.3 0.4 0.6 0.7 乘 nltcs plants adult 乘种子 1 共十二跑，口径与 3e-3 主线一致外加每 50 轮 16 点对数网格探针，信号值补种子 2 和 3。

1. J_used 比 J_best 的分位数，度量现行 alpha 离单轮最优的距离。种子 1 中位数按数据集乘 alpha 排列，nltcs 为 0.3 时 0.954，0.4 时 0.875，0.6 时 0.717，0.7 时 0.616，plants 为 0.882，0.945，0.758，0.805，adult 为 0.946，0.732，0.475，0.449。规律清楚，低 alpha 单轮效率高，高 alpha 单轮过贪，adult 0.7 时 91% 的探针轮最优 beta 比现行更保守。但终分与单轮效率解耦，nltcs 种子 1 恰是 J 比最差的 0.7 终分最好，说明单轮贪心效率不是终局质量的代理，固定 alpha 的角色是稳定速率旋钮而非逐轮最优器，与命题三的定位一致。
2. 四值终分对照，检验常数不敏感预言。adult 四值 0.030156 到 0.030248 对基线 0.030366 全部落在正负 1% 内，宽平台直接成立。nltcs 除 0.7 外全部更差，0.7 种子 1 好 2.7% 但补种子后三种子均值 0.004606 反比基线均值 0.004481 差 2.8%，属种子运气，排除。plants 的 0.3 三种子均值 0.011414 比基线均值 0.011858 好 3.7%，0.7 均值 0.011539 好 2.7%，但两者逐种子都只是二胜一负，且基线自身三种子极差达 14% 远大于 alpha 效应量，无稳定赢家。综合判读，宽平台成立，alpha 0.5 维持主线，plants 上 0.3 记为弱候选待拍板。
3. 折损率，真实逐轮下降除以期望下降 hD - h^2 C，检验恒等式在抽样方差下的居中性。ok 轮逐对统计，plants 0.3 时 899 轮中位数 1.001 均值 1.000，adult 0.3 时 1999 轮中位数 1.002 均值 0.989，adult 0.7 时 2699 轮中位数 1.001 均值 0.982，nltcs 因块数少方差大中位数 0.962。恒等式无偏得到直接验证，命题二成立。

## 六，参考分布 R 与 stay 的角色，2026-09-22 补

回答 R 的三个凭什么，凭什么是先验乘指数增益这个形式，凭什么源候选拿大头，凭什么大头取 0.99 这么紧。

第一，形式出身。熵校准解的投影问题 min sum_B KL(P_B||R_B) s.t. sum_B E[G_B] >= alpha*M 里，R 就是 KL 散度的锚点，解必然长成 P_B(u) 正比于 R_B(u)exp(beta*G_B(u))，这是最大熵推断与镜像下降的标准形式，属经典方法不需辩护。R 把多少质量放在源候选即不动上，就是给每轮更新画了多大的 KL 信任区域，stay 是信任区域半径的旋钮。

第二，对数赔率门槛，stay 的机理角色。块内非源候选 u 压过源候选 s 需要概率比过一，即 beta*(G_u - G_s) > log(R_s/R_u)，右边由 stay 主导，stay 0.9 时门槛约 log 9 约 2.2，stay 0.99 时约 log 99 约 4.6，再除以 beta 换算成增益单位。要点是 stay 以对数进入行动门槛，紧一档门槛抬升但不是线性暴涨。在噪声考卷下，噪声制造的假增益小而碎，抬门槛后过不去，真信号增益大仍能过，所以高 stay 等效于对候选动作做隐式显著性筛选，保守即正则。这与本仓已有三条独立证据链同源，早停比晚停提分，考卷清洗离线赢实跑输，距离签筒偏爱小改三连输，全部指向噪声目标下少学优于精学，紧 stay 受益是同一原理的第四个实例。

第三，收敛性与取值自由度。R 全支撑时命题一的单调性与值域论证原样成立，beta 解存在唯一，命题三的收敛框架只要求参考分布全支撑与近似神谕系数为正，不依赖 R 的具体形状，所以任意 stay 属于开区间零到一都收敛，取值只进速率常数与正则强度，与 alpha 的结论同款。故 stay 的具体数值是自由度，论文交代方式为敏感度分析。

第四，实测证据，2026-09-22 扫描。uniform 形状下扫 stay 0.8 0.85 0.95 0.99 四值乘三数据集种子 1，信号值补种子 2 和 3，合计二十二跑。结论三条。其一，0.85 到 0.99 区间无一档翻车，0.8 松侧 nltcs 多跑 300 轮反差 4.8%，松侧追噪与门槛机理一致。其二，紧侧一致受益，0.99 三种子均值 nltcs 0.004307 好 3.9%，plants 0.011458 好 3.4%，adult 0.030572 平，九种子七胜二负无一伤。其三，plants 四档全部 901 轮同停点，紧侧优势是同轮数下演化质量本身而非停轮效应，佐证受益来自门槛筛选而不是省轮数。

第五，保守两维不等价，与距离签筒的对照。距离签筒实验改 R 的形状，动行时按编辑距离打折偏爱小改动，锚定同 stay 下 nltcs 三种子全输均值差 8.6%，且训练损失反而更低，训练更好泛化更差是贴噪实证。两个实验合起来给出一个干净结论，少动行是良性保守，动作门槛整体抬高，噪声难凑够，动时偏小改是恶性保守，动作碎片化恰好贴合噪声的小而碎结构。设计讨论节可用这对正反例说明设计由原理与消融共同约束。

第六，论文叙述定位。一句话模板，参考分布的形式由最大熵原理给出，源保持概率的保守取向由噪声下的隐式正则机理给出，具体取值由跨数据集敏感度分析确认稳健。道理在先，实验作证。

## 七，待定问题

1. 高 alpha 后期 J_used 比 J_best 系统性下滑在三数据集都出现，自适应 alpha 或后期退火在单轮效率意义上有空间，但本次扫描显示单轮效率与终分解耦，立项前需要先想清楚目标函数是什么，属方法改动需拍板。
2. plants 上 alpha 0.3 三种子均值好 3.7% 记为弱候选，若将来主线重校可与 0.4 一起再验，当前不动。
3. 超鞅下界里的 M_k^2/C_k 趋零与实际停止判据的关系未写成定理，平台停与救援衰竭停目前是工程判据。
4. 命题三第四步的类比若要写进论文正文，需把候选集的凸包结构写清楚，目前只是定位性引用。
5. stay 0.99 已转正为加噪主线口径，2026-09-22 拍板，无噪声口径未验证 0.99，将来若跑无噪声战役需先补验或沿用 0.9。
6. 对数赔率门槛与噪声假增益尺度的定量关系未形式化，若能从计数噪声方差推出假增益分布的上尾估计，就能把 stay 的取值区间从敏感度实验升级成推导，属加分项不属必需。
