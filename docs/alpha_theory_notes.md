# alpha 取值的理论依据草稿

回答一个问题，熵校准里的 alpha 凭什么可以取 0.5，取别的行不行，会不会取错了整个方法就不收敛。结论分三条命题，命题一说方程永远解得出，命题二说账算得对，命题三说任意 alpha 属于开区间零到一都收敛，alpha 只影响速度常数不影响收敛性，因此 0.5 是速率甜点区里的居中取值，配套的敏感度实验见第四节实测证据。

最后更新，2026-09-21。

## 一，记号与机制回顾

当前表的损失 L 为全体查询残差的平方和。一轮内把行划分成块，块 B 的候选结果 u 带增益 G_B(u)，增益是假设其他块都不动时该块单独换到 u 能带来的损失下降量。定义 M = sum_B max_u G_B(u)，即每块都拿自己最好结果时的账面增益总和。

熵校准解带约束的投影问题，min sum_B KL(P_B||R_B) s.t. sum_B E_{P_B}[G_B] >= alpha*M，解是指数倾斜族 P_B(u;beta) = R_B(u)exp(beta*G_B(u))/Z_B(beta)，全部块共享一个 beta。记 D(beta) = sum_B E_{P_B(beta)}[G_B] 为方向增益。

步长层在方向 P 定下后独立求解，速率化后得交互量 C，一步的期望损失满足精确恒等式 E[L'] = L - hD + h^2 C，解析步长 h* = D/(2C) 截断到可行域，期望下降 hD - h^2 C 在 h 属于零到 D/C 之间恒非负。恒等式的推导见 src/resevo/engine.py 模块注释与 stepsize.py，本文直接引用。

## 二，命题一，可达性，方程必有唯一解

命题。对任意 alpha 属于开区间零到一，校准方程 D(beta) = alpha*M 在 beta >= 0 上必有解，且当 D(0) < alpha*M 时解唯一。

证明要点。三步。

第一步，单调性。dD/dbeta = sum_B Var_{P_B(beta)}[G_B] >= 0，即 D 关于 beta 的导数是各块增益方差之和，这是指数族的标准恒等式，所以 D 单调不减，只要还有某块增益未退化成常数就严格递增。

第二步，值域。beta = 0 时 D(0) 是参考分布下的平均增益，可正可负。beta 趋于正无穷时每块概率集中到自己的最大增益结果，D 趋于 M。所以 D 的值域是从 D(0) 到 M 的半开区间。

第三步，中值定理。目标值 alpha*M 严格小于 M，若 D(0) >= alpha*M 则 beta = 0 已满足约束直接取零，否则 alpha*M 落在开区间 (D(0), M) 内部，由连续性与严格单调性存在唯一根。

这里的关键是目标值与 D 用同一套假设别人不动的口径，方程两边自洽，所以永远解得出，不存在目标定了却够不着的情况。取值真够不着的只有 alpha = 1 这个端点，那要求每块以概率一拿最大值，倾斜参数需要无穷大，这就是 alpha 必须严格小于一的原因。代码上 tilt.py 的 calibrate_beta_flat 用翻倍括根加布伦特法求这个唯一根，容差 1e-13。

## 三，命题二，两本账引理，M 虚高不记假账

命题。M 与 D 采用的假设别人不动口径只用于选方向，一步的真实期望下降由精确恒等式 E[L'] = L - hD + h^2 C 给出，块间同时移动的全部二阶效应被 C 捕获，任何收敛论证不需要 M 的双侧准确性，只需要单侧性质 M >= 残差可兑换增益的下界。

说明。方法里有两本账。第一本是选方向的账，M 和 D 都按单块独动口径计算，这本账在多块同时动时确实虚高，因为两块可能都想修同一条查询，各自的账面增益重复计数。第二本是定步长的账，E[L'] = L - hD + h^2 C 是把全部块按速率 h 同时演化后损失的精确条件期望，推导只用了残差对行更换的线性响应与损失的二次结构，没有任何近似，踩脚效应全部进了 C。

两本账的分工是，第一本只回答往哪边走，第二本回答走多远和真的能降多少。beta 由第一本账的方程解出，h 由第二本账的极小化解出，期望下降 hD - h^2 C 用的全是第二本账的量。所以 M 虚高不会导致下降量记假账，最坏情形是方向选得保守或激进了一点，由命题三兜底。

一个直接推论是探针的合法性。装表实验里的 J(beta) = hD - h^2 C 对每个候选 beta 都按第二本账计算，所以不同 beta 之间的 J 可比，J_used 与 J_best 的比值是当前 alpha 离单轮最优的真实距离，不受口径虚高污染。

## 四，命题三，收敛性，映射到近似方向神谕的 Frank-Wolfe 框架

命题。把每轮的块结构候选集视作可行移动集合，M 是本轮完全贪心方向的账面增益即精确方向神谕的值，校准约束 D >= alpha*M 恰是乘性近似方向神谕，近似比 alpha。在 Frank-Wolfe 类分析下，任意固定 alpha 属于开区间零到一，损失序列期望单调下降且下降量有与 alpha^2 成正比的下界，alpha 只进速率常数不影响收敛本身。

论证骨架。四步。

第一步，单轮下降下界。当解析步长 h* = D/(2C) 落在可行域内部时，期望下降等于 D^2/(4C)，代入校准约束 D >= alpha*M 得期望下降 >= alpha^2 M^2 / (4C)。步长被可行上限或行预算截断时，下降量退化为线性形式 h(D - hC) >= h*D/2 仍严格正，只要 D > 0。

第二步，M 压不低。M >= max_B max_u G_B(u)，只要残差未清零且候选集含正增益动作，M 就有由残差范数控制的正下界，这一步不需要 M 准确，只需要它不小于单块最优真实增益，而这由 M 的定义直接成立。

第三步，超鞅论证。抽样引入方差，但恒等式给的是条件期望，损失序列 L_k 满足 E[L_{k+1} | 历史] <= L_k - alpha^2 M_k^2/(4C_k)，损失有下界零，由超鞅收敛定理 L_k 几乎必然收敛，且下降量级数可和推出 M_k^2/C_k 趋于零。

第四步，与经典结果对照。凸情形下乘性近似神谕的 Frank-Wolfe 收敛速率是精确神谕的 1/alpha^2 倍常数放大，见 Jaggi 2013 与 Lacoste-Julien 2016 关于 approximate linear oracle 的讨论。本方法的抽样是有限种群离散移动，不落在凸框架内，上面的超鞅版本是自足的，经典结果只作类比定位。

推论。alpha 的角色是速率旋钮，取 0.9 方向激进接近贪心但踩脚项 C 变大步长被压小，取 0.1 方向保守接近参考分布单轮下降的保证变差，两端都只是常数变差不破坏收敛。0.5 是该权衡的居中取值，其接近最优的程度是实验问题不是理论问题，见下节。

## 五，实测证据，待扫描完成后填写

计划引用三组数据，全部来自 alpha 敏感度扫描的旁路探针文件与曲线文件。

1. J_used 比 J_best 的分位数。探针每 50 轮对 16 点对数网格算 J，J_used/J_best 的中位数与低分位刻画现行 alpha 离单轮最优的距离。冒烟跑初步信号，nltcs 噪声卷前期比值约 0.97，中期约 0.92，后期降到约 0.61，后期最优 beta 比现行更温和，提示固定 alpha 在后期偏贪心，是否值得做自适应记为待定问题。
2. 四值扫描终分对照。alpha 0.3 0.4 0.6 0.7 乘三数据集乘种子 1，对照 0.5 基线 nltcs 0.004260，plants 0.012571，adult 0.030366，判读规则为全部落在正负百分之一内记宽平台成立，命题三的常数不敏感预言得到验证，某值显著更好则补种子确认后记为候选。
3. 折损率。真实逐轮下降与期望下降 hD - h^2 C 的比值，验证恒等式在抽样方差下的居中性，命题二的实证脚注。
